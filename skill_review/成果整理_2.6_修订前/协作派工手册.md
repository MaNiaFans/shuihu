# 水浒研究派工手册（2.5）

用户只需把一条委托交给有独立agent能力的工具。当前第十六回已经备好：

~~~text
请在 E:/水浒 工作，读取并执行：
E:/水浒/协作交接/第016回_一次委托指令.txt
你担任外部执行协调者，组织本回独立阅读、检校、修订及整稿复核，完成后交回 Codex 总编验收；不启动下一回。
~~~

后续回目由总编准备同名任务文件，再替换回号。执行者读[执行简令](阅读规则/shuihu-close-reading/执行简令.md)和本阶段必要条款；总编负责完整规则、版本与全局验收。两次全文阅读、先固定02后看01、首次完整复核04／05、原文证据与未知保留不省略。

## 执行协调者怎么派

先核已有产物、当前唯一写入者和任务范围。只把下表对应阶段的中性输入交给该角色，不把本手册、总编历史或整份任务包传给初始阅读者。各角色的短提示写明根规则绝对路径、简令、章节、允许输入／输出和停止点。

| 阶段 | 角色及输入 | 交付与下一步 |
| --- | --- | --- |
| 初读 | 新上下文A；简令、合同第二／三节、本回00资料 | 完整读后写01，固定前不看其他分析 |
| 独立观察 | 新上下文B；同样中性资料，另读合同第四节输入隔离段 | 独立完整读后写02，结束第一阶段 |
| 对照 | 协调者实际核01／02保存、覆盖和输入隔离，再向B给01 | B逐项对照事实、解释与原文，写03 |
| 修订 | A接收固定01／02／03、前回已验收05及必要全局差额；合同第四／七节 | 处理全部意见、逐项接续旧问题，写04／05 |
| 整稿复核 | B接收完整当前04／05及必要原文；合同第四／六／七节 | 首次完整复核，03追加证据和意见闭合；内容返工退A后查全部影响 |
| 总编验收 | 总编核实际文件、03证据及05变更 | 先G1—G6，再落实并回读全局表核G7，登记验收 |

一次委托的首次固定核验由外部协调者真实记录在08，最终由总编核验；不用用户逐阶段转发。外部协调者不得兼写01—05、修改07／全局／规则或自授验收。

执行端回报阶段、文件路径、覆盖、问题处理和未解决项即可。哈希与历史版本由总编管理；检校者已确定的单行机械差错由总编按合同直接收尾，不为它再开agent。

## 工具能力不足时

能开真正独立新会话但不能调度agent的，由总编把上表拆成对应的短任务给两个会话；不传彼此历史。网页无文件能力时交完整文本，由总编保存并比对，无需反复计算版本。同一会话不能冒充独立检校。额度错误立即保留停点，不靠换型号反复试；接任只续未完成阶段。
