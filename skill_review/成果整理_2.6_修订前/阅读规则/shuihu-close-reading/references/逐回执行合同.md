# 逐回执行合同（2.5）

总编必须完整读取本文件；普通章节角色先读执行简令和任务包指定的本阶段条款，遇规则冲突、规则维护或总编明确要求时再完整读取本文件。它规定可观察的执行要求，不声称能从一张表证明模型已经理解原文。检查对象始终是原文、充分的阅读产物与实际检校记录。

跨工具的输入、文件责任与阶段交接另依[跨工具协作协议](跨工具协作协议.md)。其中“执行协调者”只执行任务包内的调度，不替代本合同所称主协调者／总编的验收职责；各平台的独立新会话可承担阅读／检校角色，完整阅读和证据标准相同。

## 一、资料准备与阅读范围

主协调者在开始一回时核对以下输入：

- `00_正文.txt`：保持底本原字、标点、诗词、赞语、回末和注释序号，不为检索方便改写正文。
- `00_来源与范围.md`：底本文件、版本自载信息与校勘限度、原书起止行、局部行号映射、源文件与正文文件SHA-256、相邻边界的核对结果。此文件只放来源与切分信息，不夹入剧情解读或预期答案。
- 注释、前置引首等实际存在的附属材料另存，注明性质及来源；没有的材料明确记“不适用”，不造空文件凑数。
- 按人物检索、章节目录和边界识别只能帮助定位；切分后仍须由模型确认正文没有丢段、误收目录或附录。不得为核对边界读出下一回的详细故事，必要的邻接标题接触要登记。

当回阅读从头到尾按顺序进行。长文连续分段显示，必须检查工具输出是否截断；被截断的部分重读后才计入覆盖。长行必要时按字符区间显示，并保持可回查原行。发现缺页、乱码、原书与切片不符，先修复资料，再继续依赖该处的分析。

允许回读已读前回原文；不以先前摘要取代它。第一遍只使用当前证据截止回及更早原文，不以模型记忆补后事，不主动读含后回举例的工作流设计。现代注释若带后回信息，只可按资料接触情况说明，不能把后事写成本回已证实的事实。

## 二、两份独立阅读产物

阅读者产出01；检校者在看到01前产出02。两份都必须自己读完本回原文，并各自记录：

1. **执行说明**：角色、可得的agent标识、证据截止范围、实际读取的文件与原书范围、是否接触他人分析及后回信息。标识或模型信息不可得时写“不可得”，不得编造。
2. **连续覆盖表**：按原文顺序列出段落或场景的范围、具体内容及涉及的人／群体、笔记所在位置。范围合起来覆盖本回全部非空正文，包括诗词、过渡和结尾。一个场景可以涵盖多段；没有人物行动的段落也要说明其叙述用途或“本次未作进一步解释”。不得只列“已读1—末行”。
3. **完整经过**：保留人物提出、传话、等待、拒绝、执行、反应及结果等中间环节，标明倒叙、转述、未兑现承诺；不能只复述著名情节或最终结果。
4. **人物与关系**：本回辨认出的具名人物、称谓、无名者和群体；区分现场行动、仅被提及、典故或诗词名目、场外受影响者。写清谁对谁做了什么及证据，不能凭共现认定交往。
5. **细读与问题**：基于具体语言、动作、物件、身份、利益、情感或叙述形式展开的观察；写支持证据、限制与待追踪之处。允许“没有足够依据进一步判断”。

02可以比01紧凑，但必须保留自己的连续覆盖与实质观察，不能只写几个疑点或“同意初稿”。章节长度不同，内容密度随文本而定；不设最低字数、最低隐情数或必须挑错数，不用重复提醒凑篇幅。

### 人物不得混记的维度

| 项目 | 必须区分 |
| --- | --- |
| 身份 | 已确认同一人、候选对应、无法确认；同类称谓和无名群体跨场景不自动合并 |
| 在场 | 原文明示、上下文支持、仅被提及、明确不在、无法确定 |
| 行动 | 说、做、看、承受、被转述；没有台词不等于明确沉默 |
| 知情 | 亲见、听闻、推测、误信、未知；角色知情与读者知情分别记录 |
| 时间 | 叙述先后、故事内发生时间、某人获得消息时间；日期不明不补日历 |
| 关系与后果 | 行动方向、当时状态、已发生后果、尚未兑现的意图；受益不自动证明策划 |

对配角与无名者至少检查：参与了哪一环、能否拒绝、承受什么已写出的后果。原文不详的内心、伤亡、获利或动机保持未知，不用换位想象伪装成史实。

## 三、证据和解释

- 每个可核查事实有具体原文定位；每个关键解释有短引文与必要上下文。允许同一段共用出处，但出处必须支持其中全部主张，人物表也不能整表只挂一个宽泛回目。
- 引文照录，省略片段保持原顺序，不用拼接删掉否定、条件、估计或转述来源。引文位置与所据底本一致。工具能检查字符串，模型还须检查“这句话是否真的支持这个主张”。
- 分清叙述者明写、人物自述或转述、诗词评价、现代注释、外部评点与本项目分析。引用说谎者的话能证明其说过，不能自动证明话中内容属实。
- 保留原文明示心理。“可能”“想是”“听说”等确定程度不能在概括中升级；未记录的发言、缺席、动机和作者意图不能补写为确定事实。
- 重要推断要说明具体细节如何支持结论，并给出文本中的限制或合理替代解释；没有找到明确反证时如实说，不编造反证。依据不足就缩小结论或列为待解，不把事实错误简单降格为“猜想”。
- “作者没有说的话”优先写成文本效果和有证据的解释。人物行为复杂性、感情、幽默、伦理和叙事节奏都可成为分析方向，不预设一切都是权谋。

## 四、独立检校与修订

独立观察阶段须使用新上下文，初始输入只含规则、中性的来源资料、当回原文、必要的旧原文路径与输出02的要求。不能接收01、初读者消息、当前04／05、全局解释表或携带初读观点的历史对话。阶段完成并确认02落盘前，不派发对照任务。

独立性受损时，如实记录接触了什么、在何阶段接触；不得将受污染观察重命名为盲审。可保留这份二次复核，但正式独立步骤须由新上下文重新完成。环境不支持时保留“待独立检校”，不伪造完成。使用同一模型的不同上下文就按此报告，不冒称不同模型交叉验证。

重做时保留原02及其局限，新上下文写入未占用的 `02_独立观察_R02.md`（后续递增轮次）。主协调者在07登记每轮路径、实际哈希、失效原因和当前有效02；新检校者保存这份观察前不读旧02、03或07。新观察固定后才交给它本轮有效01及补记；之后可查看旧03、04／05，在03追加署明轮次和检校者的新意见。旧检校意见不删除，也不自动代表新轮次的结论。

01出现漏读或不实覆盖声明时，必须由阅读者实际补读，不能由02代偿。原01保留，另写 `01_补读更正_R02.md` 记录真实补读范围、遗漏内容、更正和已接触的他人观点；不能声称这份补记仍属未受影响的初读。旧覆盖无法核实时重读全回，另存 `01_复读_R02.md`。07明确本轮采用的01与必要补记，G1按实际累计阅读证据核验，G2／G3／G5按更正后的记录与最终稿复核。

03由检校者写，至少包括：

- 自己的全回覆盖与初稿的差异；独立发现但初稿遗漏的内容，或双方均应回查的段落。
- 对初稿全部事实及关键解释逐项对照原文的结果，不能只抽检初稿挑选的引文。尤其核对人物归属、动作方向、条件和否定、知情时间、来源声音、引文语义与反证。
- 编号意见：稿件位置、具体问题、原文证据、影响、建议修订和级别。级别为“阻断验收”“可保留分歧”“表达建议”；没有问题可以写未发现，但必须写明检查对象和范围，不强行制造异议。

默认由阅读者综合01、02及03写04，并将问题与修订理由写入05；需要交接时由主协调者指定其他执行agent，不将常规修订转回主协调者或交给检校者。每条检校意见均注明采纳、部分采纳或有据不采纳，给出实际修改位置或反证。不同意审稿意见时返回原文，不能仅以“观点不同”关闭事实问题。

检校者首次完整复核04／05与原文的对应关系，防止新错和漏项；后续内容修改须复核全部影响及依赖。本人在03追加实际检查对象、范围、证据和结论，总编核其对应的保存稿及版本。尚未检校的内容改动不能沿用旧通过；下述已定机械差错由总编核验接续，不追加虚构的检校者声明。

### 已验收成果的复用与专项复核

恢复先核旧07、03的实际范围、问题闭合和当前稿版本，不能只相信“完成”标签；也不能在这些证据有效时因换了上下文就重新生产01／02。旧G1—G6完整可信、稿件未变且没有新的实质错误时，沿用其结论。G7索引归并、过期状态说明或可界定的局部错误只处理具体差额；未知后效和有据分歧继续追踪，不当作阅读失败。

旧章派工前，主协调者在07登记：触发问题及证据、继续有效的既有材料和版本、拟改文件与必要原文范围、复核及停止条件。无具体新增问题不派旧章任务；已授权的新章不因管理补账自动暂停，仍保留旧章真实验收范围。

涉及内容判断的局部修订仍由指定执行者完成，先留历史，由另一上下文专项复核受影响内容及必要原文。检校者在03署名追加实际检查范围和版本路径，总编核对应保存稿；注明非新一轮02或全回独立检校，保留旧完整证据的效力与边界。不能借专项补造缺失的完整阅读或独立性；纯机械差错按第五节处理。

只有存在可核实的必要性时才扩大完整步骤，主协调者先登记依据：稿件大幅变化或问题无法局部界定时，须扩大复核至能确认覆盖全部影响的范围；无法以局部检查确认这一点时，须完整复核04／05及相关原文，但不自动重做01／02。只有原阅读覆盖或独立性无法核实时，才重做相应的阅读步骤，仍可信的另一份阅读不自动失效。正式重做01／02仍遵守前述全新上下文、顺序全文阅读和先固定后对照要求。是否需要重做必须先于新检校者派工决定，不能先派人，再用新人的独立通读要求反推必须重读。

03须累计提供实际检查范围、对两份覆盖记录的核对、内容检查结果及具体证据位置、意见闭合和保留分歧。首次完整对照和整稿复核不能只写“全文无误”或只检查修订清单；旧章专项追加则可明确引用仍有效的完整检校证据，只复核实际差额及依赖范围，不必重写或重查全部旧材料。05须给出拟更新全局表的具体条目、原条目编号、变更理由与原文依据；检校者一并复核，主协调者据此核查并落实跨回变更。

无文件或版本计算工具时，依[跨工具协作协议](跨工具协作协议.md)第五节保存完整交付并比较实际内容；总编在07建立原交付、检校记录与保存稿的对应关系。没有内容变化，不要求检校者为落盘或新指纹重新签一次声明；内容是否一致无法确认时仍待核验。总编不得代写03或将未经检查的稿件登记通过。

### 已定机械差错的收尾

检校者已明确指出单行指针、行号、路径或元数据的正确改法，且修改不改变任何内容判断时，总编可留历史、按已定改法修正、逐行核实唯一差异。在07列原检校意见、修正位置、差异及实际保存版本，记“总编机械核验完成”；G5该项关闭，G6由原内容检校与这份机械差异共同对应当前稿。无需另派agent重报版本或重签03，也不声称原检校者看过新保存文件。事实、人物身份、解释、引文含义、问题状态及全局结论的改动不适用此例外；修改范围有疑义时返回独立复核。

| G6 | 当前稿内容确与有效检校及已核机械差异对应，原始产物和历史保留 | 检校者记录实际检查对象和范围；改稿先留历史 | 总编核原交付、03检查对象、当前稿及差异，在07保存版本对应；不能仅凭哈希或作者声明放行 |
| G7 | 本回与既往问题、称谓身份、前情、未决分歧已经交接，相关全局表已更新 | 阅读者在05提交具体变更及依据，检校者复核跨回证据和未决项 | 核05与既有全局条目，解决归并冲突或保留分歧；实际更新并回读全局变更，在07登记位置 |

完整内容检查由阅读者和检校者承担；主协调者实际打开上述验收证据并核查相互对应，默认不重复全文研究或重读每轮整稿。发现覆盖缺口、证据与结论冲突、未闭合问题或跨回歧义时，查所需原文上下文，明确返工对象与复核范围；重大争议可另派专项复核，不能靠多数票或总编直觉放行。若证据不足以判定，保持未核验并补实，不能以节省主协调者阅读量降低标准。简要交接只作证据入口，不能替代两次全文阅读和完整内容检校。

任何一项未核验均不得预填通过。主协调者先核验G1—G6，再依据05更新全局交接并核验G7，最后登记“验收通过”；更新交接不等于提前宣告通过。纯文字润色建议或原文本身没有回答的问题不必阻断；遗漏行动、错认人物、无据事实、未读段落和伪独立审稿必须阻断。有实际内容分歧时保留两说及证据，不以多数票代替原文。

本回通过后，只有后续回目已在用户授权范围内才继续；连续授权无需逐回等待用户审批。新证据使已通过章节出现实质错误时，主协调者将其标为“需复审”，保留旧通过记录并说明原因，安排执行者返修相关章节和整合成品，再核验并更新全局追踪。

## 七、跨回追踪与最终完整性

问题编号沿用 `CH三位回号-Q两位序号`。每项保存触发原文、提出时的理解、候选解释、证据、下一步所需材料、最新状态及修订历史。身份或关系不确定不强行确认，后文无回答允许保持“未详”。

下一回的阅读者在通读且01保存固定后，再对照前回交接和全局问题，以免只寻找已经提出的线索。独立检校者在02固定后再读这些材料。前情核对可直接进入04／05修订准备，不强制单列备忘或等待总编逐份批准准备材料；本回02及03固定后才据它们形成正式修订。已有固定备忘复用其实际范围，不冒称接任者本人早已读取那些原文。

跨回检查按以下方式保留全部问题并控制重复：

- 入口是最近已验收05中的完整问题清单及其绑定的全局版本，由总编先核版本和G7实际落点。阅读者及检校者须逐项检查该清单；全局表的后续差额也须读到。无需每回从首行重读两张历史总表。旧05缺项、映射不明、版本变化范围无法确定时，补读相关全局条目及依赖；仍无法界定才扩大读取范围，不能直接称全部已核。
- 每回05维护完整状态清单，每个正式入口均有编号、简明题名、已答／未详状态和明确证据入口。无变化项可以一行续接其已验收结论和未详子项，无须重抄整段旧分析或逐题写无关情节。新题、变化、疑点、合并、未决分歧须展开原文依据、旧新差额和后续材料；不得用“其他均无变化”省掉编号或待解子项。
- 无变化的证据入口应能直接定位到已验收结论或最后实质变化，不能仅链到上一回的“同上”而使追溯链无限增长。新稿须核对入口仍覆盖该题全部未详子项；发生实质变化则更新直达入口。人物表同理保留身份、关系、受影响者及未知边界，新发生的变化完整展开。
- 对新文学判断或前情疑点首先定点回读所需旧原文；已有可信结论可绑定版本复用，不能因拿到旧摘要便宣称本次原文复核。检校者仍完整检查当回04／05及相关原文；跨回的未变旧结论沿有效证据复用，变化部分须检查内容支持。
- 总编落实G7时，实际写入新／变化条目及完整状态清单的版本入口，回读所写差额并核无遗漏；无需向全局表再次追加全部未变旧题的长段。可以用脚本核编号覆盖、链接和哈希，判断有没有新证据以及原句支持什么仍由模型完成。

最终发布“本底本全书完整人物档案”前，要逐回核对材料与版本、角色对应、场外事件和关系链，并独立复审。旧试读只能按其真实记录认定；补核可以补充证据，不能把事后观察冒充先前独立观察。缺失章节、无法确认的身份与重要遗漏须在覆盖说明中明示，不能通过换个完成标签隐藏。
