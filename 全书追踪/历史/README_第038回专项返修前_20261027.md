## 故事读到了哪里

开篇从洪信放走妖魔，引出此后人物出场的神异框架。接着，高俅发迹与王进出走把故事带入现实中的权势和生计；王进授艺史进，史进离乡寻师，又把叙事交给鲁达。

鲁达救金氏父女，打死郑屠，被迫出逃，随后出家成为鲁智深。他一路救人、惹事、寻找安身之处，直至东京与林冲结交。读这一段，可以同时看见他的热心、机警、粗暴和对周围人的影响。

林冲的故事从妻子遭高衙内侵扰开始，继而被陷害、刺配，途中又遭谋杀。鲁智深救命、柴进接济，都曾为他缓解困境；草料场的纵火密谋最终使他杀人出走。到了梁山，求得容身之所仍要经过王伦设置的门槛。

杨志与林冲相遇后，故事转入另一条求出路的线：他想恢复官职，卖刀杀人后刺配大名府，又凭武艺获得梁中书赏识。与此同时，刘唐报信，晁盖、吴用等人聚集，谋取生辰纲。第十六回把押送与劫夺两条线合到黄泥冈：财物被劫，杨志绝望寻死，故事在他能否生还的悬念中收束。

第十七回接写杨志临跳止步，逃亡途中结识曹正、鲁智深，最终夺下二龙山。押送随员同时串供诬杨，梁中书、蔡太师将追查压力逐层传至何涛；何清在回末声称掌握线索，具体所指仍待后文。

第十八回揭出何清代抄客店文簿、认出晁盖的线索，官府随之捕获白胜起赃。宋江在茶坊获悉缉捕消息，抢先报晁；朱仝、雷横夜捕时各有救人之意，使晁盖脱身。追查却仍经邻舍勘问、庄客受刑和白胜再讯推进，新的捕令指向石碣村，旁人的受牵连处境继续留在案中。

第十九回写石碣村迎敌与梁山火并。吴用、刘唐先转移家财老小，其余五人与渔人迎战，何涛被擒、割耳后放回。众人经朱贵上梁山，晁盖先感恩礼遇，吴用却从神色和未定座次中看出拒纳；王伦最终送银逐客，林冲在七人配合下杀王，随后拒绝首位。本回到新主尚未宣布时停住。

第二十回写晁盖正式居首、十一头领落位和阮家安顿。林冲遣人接妻，查访传回妻、岳父死讯与锦儿婚居；山寨击败黄安、劫得商货，客商失财和俘军刺字役使与庆功并存。官府更替后继续筹剿，刘唐送书百金到郓城，宋江收书和一条金、退余金，分别处理朱雷人情，以回书帮助刘唐复命；月夜别后，宋江又被未名来者叫住。

第二十一回从宋江为阎家助丧、供养母女写起，接着写张文远与婆惜相好、阎婆强留、唐牛儿解围失败。遗下的招文袋使梁山书信落到婆惜手里，索物谈判升级为两刀杀人。宋江焚信，阎婆到县前告凶；唐不知命案而因旧怨打夺，使宋走脱，自己被拿。

第二十二回写命案进入县衙，张文远推动检尸追捕，知县有意保宋却刑讯唐牛儿。出籍执凭挡住勾追父弟，朱仝独入地窨劝宋逃，雷横识反话保全宋家；人情和钱物平息上告，唐最终杖配。宋清随兄投柴，名声与书信带来盛迎衣食；夜廊中宋醉踩火锨，病汉从怒揪转为闻名跪拜。

第二十三回揭出病汉是武松，并补写柴庄待慢的原因。宋江陪伴远送，武松主动结义、辞银后受；回乡途中，他在冈前酒家索饮、拒劝，读县榜确认有虎后仍怕受笑而上冈。搏斗经历躲闪、折棒、近身拳脚和补打，猎户、乡夫验虎后传报迎送；武松将赏钱散给受罚猎户，获任阳谷步兵都头，寻兄目标仍未完成。

第二十四回写武氏兄弟相认、同住与搬离，武松拒绝嫂嫂试探后奉差离城。王婆以做寿衣安排潘金莲与西门庆相会，事后又借告发相逼；武大仍被瞒住，卖果养父的郓哥在茶坊受打，提篮寻人。寻兄已经完成，消息将怎样传开仍待后文。

第二十五回写郓哥找到武大传话，二人约计捉奸，武大被西门庆踢伤。病中求照料的条件经潘金莲转报，接成王婆设计、西门供毒、潘亲手实施的谋杀；清尸、办丧和酒银嘱托继续遮掩死因，何九叔受压收银后仍疑，揭尸看视时倒地吐血，所见与后效停在回末。

第二十六回接写何九叔转醒、何妻提出留证办法；武大入殓火化，骨银与记名纸仍被保存。武松公差归来，见灵才知兄死，访何问郓、向县求告，遭拒后设席逼供，杀潘金莲与西门庆祭兄。四邻受拘署名，王婆被绑押，回末停在武松将向四邻说话。

第二十七回接写武松托四邻料理家产、首告作证；县府改状周全，武松受杖刺配，王婆受剐。押解路上，两公人与武松互相照应，到了十字坡却饮药倒下；武松泼酒装倒、制住店妇，随后与张青、孙二娘相认。英雄相交之际，两公人仍躺在剥人凳上，救治结果与张青要说的话都尚未展开。

第二十八回里，武松拒绝张青杀害两名押解公人的提议，坚持将他们救醒；他与张青结拜，重新戴枷赴孟州。到牢城营后，他拒绝差拨索取人情，施恩向父亲说情使眼前的杀威棒暂时寄下，又安排酒食照顾。武松追问恩情来历并举石显示气力，在还未听明具体事由前承诺帮忙；回末施恩开口，所求内容暂未交给读者。

第二十九回，施恩讲出自己在快活林经营获利、被蒋门神夺路打伤，请武松助拳；老管营促成二人结义。父子因怕武松醉酒误事假托延一天，武松却坚持每逢酒家喝三碗。到蒋家酒店后，他以装醉、挑衅引出蒋，先将柜中妇人和前来阻拦的酒保扔入酒缸或打倒，再在路上击倒蒋门神。蒋求饶并应听三件事，但条件尚未揭出。

第三十回揭出武松提出的三项条件：蒋门神交店、请人陪话并离开；施恩重开买卖，后又称店被蒋带人夺回。张都监先厚待武松、许婚，随后武松因寻贼被绑，箱中搜出银器而屈招入牢。施恩父子、康节级和叶孔目从不同位置周旋，武松最终被刺配；途中在飞云浦反击后返回孟州。张宅赃器如何入箱、玉兰知道多少，正文尚未交代。

第三十一回写武松回孟州，在鸳鸯楼杀张都监、张团练和蒋门神，也杀害后槽、女使和其他家中人物；现场所写人数、他的转述与官府验报的分类并不完全相合。武松逃出城后被四人活捉，因张青、孙二娘认出而获释；张青荐他往二龙山，孙二娘用头陀遗物助他改扮行者。路上武松杀道童，与一名先生交战，回末只写一人倒下，身份留待下回。

第三十二回揭出岭上交战倒下的是道人。武松在酒肆打店主、孔亮后被庄客捆打，宋江认出他并解救；两人叙旧、在岔路分别，叙述随后交代武松投二龙山入伙。宋江途经清风山被擒，燕顺认名后解救；王英掳来刘高的妻子，宋江请求、燕顺下令放人。妇人归寨后对军人和丈夫的讲述，与山上实际释放经过不同。

第三十三回写宋江独自到清风寨投花荣，住将近一月。元宵看灯时被刘高妻指认为清风山贼头，拷打后花荣下书被撕，带人救出；他以两箭和第三枝箭的威吓退众。宋江夜避清风山，在五里路头再被捉；慕容彦达差黄信，黄信用掷盏计拿住花荣，两人同解青州。

第三十四回接写黄信押解宋江、花荣，林中被截。黄信战十合后弃众逃回，花荣自破囚车、救出宋江；刘高被拿上山后，花荣在厅上杀他，花荣家眷仍在镇里。秦明出城交战，中计被擒，拒绝落草而被劝留醉卧；次日见瓦砾场和妻子首级，回山责问，闻计、受许婚后归顺。他单骑劝黄信入伙，回末两路军马杀到栅门，还没有交战。

第三十五回接上栅门。黄信开栅，两路人马进镇。宋江下令杀刘高一家，王矮虎带走刘高妻子，上山后燕顺杀了她；花荣妹子嫁给秦明。众人烧寨投梁山，对影山吕方、郭盛比戟，花荣射断绒绦。村店里石勇递来家书，宋江从信中读到父亡，急辞同伴独归；回家才知父亲仍在、信是假死讯。夜里庄被围住，本回未写脱身。

第三十六回从围庄的火把写起。赵能、赵得要拿宋江，宋江开门出官。县里散禁，州府按赦减罪，仍将他脊杖二十、刺配江州。路上梁山要留他，他不肯入伙，也护住两个公人。揭阳岭酒店药倒三人，李俊提议查看公文、店主取来差批才确认宋江，随后救人。到揭阳镇，宋江赠卖药教头五两银，引来另一大汉搦拳来打，结果留待后文。

第三十七回接写宋江躲拳，教头先出手相护，随后自报薛永，才认出受助者是及时雨宋江。三人受禁店威吓而借宿穆庄，从父子夜话中发现追打者正是庄主之子，遂挖壁逃到江边。张横留船欲害，李俊先来索分货、识出宋江后才跳船相救；穆家兄弟由李俊介绍姓名，赔罪、依宋请求放回薛永。宋江到江州入营，一百杀威棒暂寄，独拒节级常例钱；无名节级已在厅上发怒，宋江正前去相见。

第三十八回揭出点视厅发怒的节级正是神行太保戴宗：营众因与宋江交好而一哄散走拒打，宋江以吴学究试探止棍，回房取吴用书信到城内酒肆相认。小牢子李逵在楼下闹借钱，上楼识宋江后谎称赎大银骗取十两银去小张乙赌房，输光后强抢赌资、打翻赌众；宋江追到代还赌银，并将十两原银改作伤者将息钱。三人上琵琶亭饮酒，李逵嫌碗小、连骨嚼鱼汤、泼酒保、啖羊肉，又去江边拔竹笆篾放走一整舱活鱼、打散渔人；鱼牙主人张顺岸上交手力怯，诱李逵上船入江心翻船淹得他翻白眼，闻戴宗喊话与宋江报出营内有张横家书后停手，踏浪单手托李逵上岸，哨船赠四尾大金鲤。回末二八卖唱女娘唱曲打断李逵卖弄话头，被他两指点额昏死，酒店主人拦住四人要去经官告理。

| [第七回](阅读成果/第007回.md) | 鲁智深倒拔杨柳，与林冲结交；高衙内侵扰林妻，林冲被引入白虎堂。 | 林冲认出高衙内后收手，与他的官职依附有关；妻子和锦儿的行动也推动了故事。 |

| [第九回](阅读成果/第009回.md) | 鲁智深救下并护送林冲；林冲在柴进庄上较棒，随后进入沧州牢城。 | 救助靠持续护送、钱物和书信逐段实现；暂时受到照顾，并未解除他的囚犯身份。 |
| [第十回](阅读成果/第010回.md) | 林冲得到李小二照应，转守草料场；风雪使他避居山神庙，听见纵火密谋后杀敌出走。 | 风雪、倒塌的住处和庙门位置共同促成转折；他曾想安稳生活，得知密谋后才走向决裂。 |
| [第十一回](阅读成果/第011回.md) | 柴进再助林冲脱身，朱贵接引他上梁山；王伦要他取得投名状。 | 避难之地也有排斥和利益顾虑；让林冲留下的条件，把危险转移给了过路人。 |
| [第十二回](阅读成果/第012回.md) | 林冲与杨志相斗；杨志辞去梁山邀约，求官不成，卖刀杀人后刺配大名府。 | 杨志仍珍视家门和仕进；本领、名声、金钱与官府手续分别影响他的出路。 |
| [第十三回](阅读成果/第013回.md) | 杨志斗武获用；梁中书筹办生辰纲；故事转至郓城，雷横在庙中拿人。 | 公开比武怎样把本领变成职位；生辰纲与郓城人物开始为两条故事线搭桥。 |
| [第十四回](阅读成果/第014回.md) | 晁盖设法救下刘唐，得知生辰纲消息；刘唐追雷横索银，与吴用相遇。 | 救人依靠认亲、说情和银钱；刘唐不甘付银，又使刚缓和的局面生出冲突。 |
| [第十五回](阅读成果/第015回.md) | 吴用以买鱼为由接近三阮，逐步说动他们入伙；公孙胜来向晁盖献策。 | 三阮各有生活与家庭处境；吴用通过相处和试探，确认彼此愿意承担的风险。 |

## 把人物放回经历中理解

**鲁智深的救人，既有热心，也有安排。** 第三回先让金氏父女离开，再去找郑屠；第九回暗中跟随林冲，救下后还继续护送。这些动作使他的“义气”有了具体内容。第四、第五回留下的冲突，又提醒读者看见他的粗暴及旁人的损失。第十七回又补叙救林后被追捕、烧园逃亡及十字坡获救的经过，直到他与杨志在二龙山获得新的去处。把这些放在一起，人物才不会只剩“鲁莽”或“仗义”两个标签。

**林冲的变化需要沿事件去读。** 第七回他因对方身份收手，第八、九回仍设法在刺配处境中活下去，第十回得知对方继续谋害才杀人出走，第十一回又为容身受到王伦刁难。第十九回他主动支持新来豪杰，在逐客时杀王，随后又拒首位；这些行动要和吴用的筹划、现场协力及林自己的条件分别相接。第二十回他拥晁、促成新位次，又因新主愿安家而派人接妻，却只收到查访带回的死讯。每一次反应都有当时的压力和期待，把经历连起来，比先给他定一种不变的性格更清楚。

**杨志的本领与失利，可以同时成立。** 第十三回他凭斗武获用，第十六回又能说出押送路线和药酒的危险。但他用骂打催赶负重的军汉，队伍内部不断冲突；吴用一方则通过试饮和假争执，让押送者误判余酒安全。第十六回把能力、带队方式、身体疲劳和欺骗连在了一起。到第十七回，他不愿以金印身份再投王伦，却愿夺取二龙山安身，去处与选择随失纲继续变化。

**具体的小动作，是这些故事的重要部分。** 锦儿奔走传信、李小二夫妇照应和探听、军汉因担重热渴而求歇，都实际改变着主角所处的局面。书里的英雄故事因此包含了许多人的劳动、选择与代价。

这些是依据第一至二十回已有详细解读作出的阶段归纳。未交代的人物后况继续留待后文，不预填全书结论。
