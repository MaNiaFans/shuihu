# 第六十回：礼俘收芒砀，失主变梁山

公孙胜用阵势和法术困住项充、李衮，宋江再用解缚、把盏和免留人质的礼遇，使两个俘虏回去劝动樊瑞。芒砀山的人马钱粮随三人并入梁山，旧寨烧毁。紧接着，一匹没有送到的献马、曾头市的夺马与辱歌，却引出晁盖坚持亲征、夜袭中毒箭身亡。开篇诗把两端并列：“虽收芒砀无家客，殒却梁山主寨身。”所得与所失一起改变了梁山；宋江在哀悼中被推上主位，随即把扩大的山寨重新分兵授职。（本L8、20—28、30—44、62—84／原L6656、6668—6676、6678—6692、6710—6732）

<a id="story-array"></a>
## 阵势先困住人，礼遇再带回人

公孙胜向宋江、吴用解释，所献的是诸葛孔明“摆石为阵的法”：四面八方分成六十四队，等敌人冲入，看七星号旗变成长蛇阵；他作法使敌前后左右无路，再逼向坎地陷坑，由两边埋伏的挠钩手捕捉。宋江听罢传令，安排呼延灼、朱仝、花荣、徐宁、穆弘、孙立、史进、黄信八将守阵，柴进、吕方、郭盛暂摄中军；陈达负责磨旗，朱武带五个军士在近山高坡看阵报事。阵图从一开始就有诱入、断路、传号和擒拿的具体分工。（本L14／原L6662）

巳牌时分，梁山军摇旗擂鼓搦战，樊瑞、项充、李衮率三千余人下山。樊瑞是濮州人，幼年学作全真先生，又有一身武艺，惯使流星铜锤；介绍他的《西江月》甚至把他比作“北方真武”，赞其“伏怪除妖”。这段先把他写成强手，接下来才显出能力的缺口：“虽会使神术妖法，却不识阵势。”他以为对方摆阵正中自己计策，命项、李见风起就带五百滚刀手冲入，自己马上执锤仗剑，念咒起风。（本L16、18、20／原L6664、6666、6668）

梁山军先分开让入，又用强弓硬弩截住后队，项、李只带四五十人深入，其余退回本阵。宋江在坡上见二人已入，便令陈达招动七星旗，阵势随即变作长蛇；朱武随着二人东奔西走指旗，公孙胜拔剑作法，使风在他们脚跟边乱卷。二人眼中天昏地暗，四边皆是黑气，后面的随从也看不见了。他们急于找路回阵，一声地雷后双双跌入陷坑，挠钩手将其搭起绑住，解上坡请功。公孙胜的法术并未替代军士的行动，而是与号旗、弓弩、陷坑连成了擒人之势。（本L20／原L6668；“搨”释跌，注L1／原L6744）

擒住二将之后，宋江挥军掩杀，樊瑞退回山上；“走不迭的，折其大半”。这里有芒砀部众实际承受的损失，不能因后来归附就写成一场没有代价的招降。随二将深入的四五十人，在迷阵中只写不见了，结局没有逐一说明。（本L20／原L6668）

<a id="story-surrender"></a>
两名俘虏被军健解到帐前，宋江却立刻叫解绳，亲自把盏，称自己早想礼请三人同聚大义，只因临敌才不得不用此手段。这是宋江对交战的解释；解缚、不杀、敬酒和相邀，则是两人眼前实际受到的待遇。他们拜伏，称久闻及时雨大名，如今被擒而反获礼待，愿以死报恩；又说樊瑞少不得他们，请放一人回去劝降。宋江答“不必留一人在此为当”，把二人一起放回，约次日等消息。（本L22／原L6670）

礼遇的力度正在这个多走一步的动作里：项、李只求释放一个，宋江连人质也不留。二人随即保证，樊若不从，就擒来献上。宋江又留酒食、给新衣好马，使小喽啰拿枪牌送他们回寨；叙述明写二人一路“感恩不尽”。到山下，守寨小喽啰惊迎；上山后，二人先说自己“逆天”，再把宋江义气讲给樊瑞听。樊瑞听完，答应次晨下山投拜。实际发生的是伙伴传话后的归服，没有走到二人所许的擒樊一步。（本L22、28／原L6670、6676）

三人当夜收拾，天晓到宋营拜伏。宋江扶起延坐，毫无相疑之意，三人才倾心吐胆，继而请众头领到芒砀山寨杀牛宰马、饮宴劳军。席后樊瑞拜公孙胜为师，宋江作主教公孙胜传“五雷天心正法”。数日内，众人搬走钱粮、行李与牛马，收聚人马，烧毁寨栅，跟着宋军回梁山。这次收服同时改了组织归属、物资去向和樊瑞的师承。（本L28／原L6676）

樊瑞先被赞为能伏怪除妖，作战时却被称会“神术妖法”，归附后又受传“正法”。这些名称随他的归属与师承发生变化，显示本回不仅较量谁的本领高，也在重新安排谁的力量属于山寨秩序。这个理解有措辞和拜师过程支撑，并非樊瑞或公孙胜自己说出的一套理论。（本L18、20、28／原L6666、6668、6676）

<a id="story-mare"></a>
## 一匹未送达的马，变成全寨受辱的消息

回军到梁山泊边、正要过渡时，戴宗已经先报归讯。芦苇岸边，一个赤发黄须的大汉向宋江下拜；宋江下马扶问，才知道他叫段景住，涿州人，绰号金毛犬。段自称以到北边盗马为生，今春在枪竿岭北盗得一匹照夜玉狮子马，浑身雪白、高大异常，原是大金王子坐骑，日行千里。他久闻宋江之名，想献马表“进身之意”，却在凌州西南曾头市遭曾家五虎夺去；搬出“梁山泊宋公明的”名号，对方仍有恶言，他只好逃来告知。（本L30、32—34／原L6678、6680—6682）

马尚未交给宋江，段就先用宋的名号保护它；献礼没有完成，求入伙的行动却转成一次报信。大金王子的原主身份、夺马经过和对方当时说了什么，此处都出自段的自述；马的千里脚程也没有在本回实测。现代注释只把他所说的“北边地面”释为当时金国地界，不因此替他添出别的政治身份。（本L30／原L6678；注L3／原L6746）

宋江看段“一表非俗”，心中暗喜，先带他上山商议。晁盖与众头领迎至聚义厅，樊瑞、项充、李衮和众人相见，段也参拜，山寨摆宴庆贺。人员接连增加，宋江遂命李云、陶宗旺监工，添造房屋和四边寨栅。段再谈马的好处，宋才派戴宗到曾头市探其下落，命其快回。这一步侦察，使后来出兵的消息不只来自一个求进身者。（本L36、38／原L6684、6686）

戴宗三五日后回报：市上共有三千余家，曾家府的曾长者原是大金国人，五子为曾涂、曾参、曾索、曾魁、曾升，号曾家五虎；又有教师史文恭、副教师苏定。当地聚五七千人马，造五十余陷车，扬言与梁山势不两立，要尽捉山寨头领；玉狮子马现由史文恭骑。他还转述曾家教市上小儿唱的歌：“扫荡梁山清水泊，剿除晁盖上东京。生擒及时雨，活捉智多星。”歌中对晁盖用“剿除”，对宋、吴用“生擒”“活捉”，辱骂已点到全寨主要人物。（本L38、40／原L6686、6688）

这些家世、户数、兵数和扬言，首先是戴宗的探报。后来白昼交锋确实见到七将、陷车和史文恭骑玉狮子，却不能因此把探报每句话都视为另有独立证实。曾长者本回没有现场动作，戴所报小儿唱谣与后文村民善战的铺陈，也不等于每个居民都参加了伏击。（本L38、40、48、52／原L6686、6688、6696、6700）

<a id="story-expedition"></a>
## 晁盖坚持亲征，林冲不断提出另一种走法

晁盖听完大怒，誓言不捉此辈不回山。宋江劝他是山寨之主不可轻动，请自己去；晁盖则说：“不是我要夺你的功劳”，只是宋江下山多次、厮杀劳困，自己替他走一遭，下次仍由宋去。宋苦谏不从。晁点五千军、二十头领随征，其余与宋守寨，连他本人共二十一头领。（本L42、44／原L6690、6692；随征与夜入分组见文末附录）

金沙滩饯行时，一阵狂风把晁盖新制的认军旗从半腰吹断，众人失色。吴用认为不祥，劝改日；宋江也说于军不利，不妨停候。晁盖却以“天地风云，何足为怪”反驳，主张趁春暖出兵，免得曾家养成气势。他并非没有说出军事理由，只是坚决要亲自去办。宋江拦不住，待他渡水后悒怏回寨，又派戴宗探前线消息。（本L44／原L6692）

晁军在曾头市相近扎寨，次日看地势。野水、高岗、弯曲河港、密柳与隐伏寨栅先把难攻之势写足；接着骈文连壮汉、小儿、僧道、妇人都写得善战，以“铁壁铜墙”概括。林中随即冲出曾魁率领的七八百人，曾魁称梁山为“反国草寇”，要解官请赏。林冲出马交锋，曾魁自料不敌，退入柳林；林冲勒马不追，回营建议次日到市口搦战，察虚实再议。（本L46、48、50／原L6694、6696、6698）

次日，梁山五千军在开阔平川列阵，曾家七将一字摆开，史文恭持方天画戟、弯弓插箭，骑的正是玉狮子。曾涂推出陷车骂阵，扬言要把头领逐个活捉、装车送东京碎尸。晁盖怒而挺枪直取曾涂，众将怕他有失，跟着一齐掩杀。曾军步步退村，林冲、呼延灼紧护晁盖；林见路途不好，急忙收兵。两边都折了人马。（本L52／原L6700）

众将回寨劝晁宽心，说此次尚未输给对方，宋江过去也曾失利后得胜。晁却仍“郁郁不乐”。他亲征时先解释自己并非夺功，未打开局面又明显忧闷，可以看出亲自办成此事对他颇有压力；更深的疑忌则未由原文明说。林冲提出察虚实、不追林中、路坏即收兵，都是把行动限制在所能掌握的范围内。随后连续三日，晁军每日叫战，曾头市却不出来。（本L42、50、52／原L6690、6698、6700）

<a id="story-monks"></a>
## 夜袭的捷径，怎样一步步封住了退路

第四日，军人引两个和尚到中军。二人跪称自己是曾头市东边法华寺监寺，常被曾家五虎索财侵扰，熟悉对方出没，愿领梁山劫寨；若除掉曾家，“当坊有幸”。晁盖大喜，置酒相待。林冲先问其中是否有诈，和尚就以出家人不妄语、梁山仁义不扰民、曾家未必赢得大军等话来反驳。其受害叙述和对梁山的赞誉，为一条危险的夜路同时提供了道德理由与身份担保。（本L54、60／原L6702、6708）

林冲没有只说一句不可信便罢。他另提半军由自己等人入内，晁盖在外接应；晁以“我不自去，谁肯向前”拒绝，命林冲留半军在外，自己领十将、二千五百人随和尚进去。插在此前的诗已用“间谍”“秃奴”评价两僧，并责晁盖无先见。读者先获得了这一负面框定，晁盖却仍沿着自己相信的捷径往前走。（本L56、58、60／原L6704、6706、6708）

当晚众人先吃饭，马摘铃、军士衔枚，随僧悄行到法华寺。晁进寺发现没有僧众，继续追问；和尚说其他人被曾家薅恼，已经归俗，只剩长老、几个侍者在塔院。他又说曾家有四寨，弟兄只屯北寨，拿下北寨其余便不足虑，二更还早，应等三更。原文先写更鼓整齐，过半更却无更点，和尚便说：“军人想是已睡了，如今可去。”这里是带路者推想敌军睡去，并非叙述确认敌军真睡。（本L62／原L6710）

出寺不到五里多，两个和尚在黑影中不见了。前军面对杂路与无人家，不敢再进；军士慌起来，报给晁盖，呼延灼立即叫回旧路。走不到百十步，四面金鼓、喊声、火把骤起。众将领军夺路，才转两个湾，又撞出一股人马，当头乱箭，一箭中晁盖脸上，晁倒撞下马。呼延灼、燕顺死战冲前，刘唐、白胜从背后救他上马，众人杀出村口；林冲等率外军接应，才抵住，混战至天明各归营。（本L62／原L6710）

和尚以受害归俗解释空寺，又在断更后推称军人想已睡去；每一次异常都被转成可以继续前行的理由。其失踪和伏击紧接发生，再与插诗相参，足以判断本回把他们写作诈诱者。两僧的真实法名、寺职、谁授意及怎样联系伏兵却没有展开；塔院长老、侍者和归俗僧众，也只存在于他们的说明中。后文上山追荐的附近寺僧与大圆，须各按自己的出现经过理解。（本L54—62、74、86／原L6702—6710、6722、6734）

## 从中箭到遗言，箭名与射手仍隔着一层

林冲回来点军，三阮、宋万、杜迁在水里逃得性命，随欧鹏回帐的入袭军只剩一千二三百。二千五百人的队伍受到重创，但失散、被俘、死亡如何分布，原文没有分算。众人看晁，箭在面颊；拔出后血晕，箭上有“史文恭”字。林冲取金枪药敷贴，叙述才揭明“原来却是一枝药箭”，晁中毒已不能说话。林冲命三阮、杜迁、宋万五人用车先送他回寨。（本L64／原L6712）

前线余十五头领商议收兵，认为急切取不得曾头市，也回认此祸应了折旗之兆；呼延灼却说须等宋江将令。将士都无恋战之心，当晚伏路小校又急报敌军四五路杀来。三面山火照明、四下喊至寨前，林冲率众拔寨撤走，曾军追杀五六十里才摆脱，又折五七百人，正文明确写“大败输亏”。他们退到半路，才遇戴宗传令，教先回山另作良策。林冲撤军在先，军令到达在后，不能为了使统属显得整齐而倒置。（本L64、70／原L6712、6718）

回山后，晁盖水米不能入口，浑身虚肿。宋江守床啼哭，亲自敷药、灌汤散，众将守视。三更病势沉重，晁转看宋江，嘱道：“贤弟保重。若那个捉得射死我的，便叫他做梁山泊主。”说罢瞑目而死。（本L72／原L6720）

夜间中箭只写“一彪军马”“当头乱箭”，没有展示谁张弓射出中脸之箭；箭上姓名和药箭毒性，则有直接叙述。晁临终说的是“射死我的”，没有点名。到后来劝位时，宋江转述成“如有人捉得史文恭者，便立为梁山泊主”，使复仇对象在人物话语中落实到史文恭。这些层次都要保留：箭名不能直接代替现场辨认，转述差别也不足以推出另有凶手或宋江参与谋害。（本L62、64、72、76／原L6710、6712、6720、6724）

<a id="story-succession"></a>
## “权居”保留承诺，也立即形成统领

晁盖一死，宋江哭得“比似丧考妣一般”，发昏后被众将扶出主事。吴用、公孙胜劝他先理大事，随后沐尸、衣巾装殓、停于聚义厅，合造棺椁、设灵帏神主。自宋江以下头领皆带重孝，小头目喽啰也戴孝巾；那枝箭作为“誓箭”供灵前，附近寺僧被请来追荐。宋每日领哀，叙述说他无心管理山寨。哭泣、救治与丧事都有具体动作，不因后来接位就能倒说全是表演。（本L74／原L6722）

林冲、公孙胜、吴用等与众头领商议拥立宋江。次晨林冲领众请宋出来，由吴用、林冲开话，以寨不可无主和宋名声远播相劝。宋以未报晁仇和遗言辞位；吴用再提出先“权且尊临”，以后另议。宋答应暂居，又说拿住史文恭的“不拘何人，须当此位”。即时统领与未来捕仇者的承位条件，便这样同时保留。（本L76／原L6724）

李逵在旁突然说，宋做“大宋皇帝”也好。宋厉喝，称再乱言先割其舌；李还反问，自己又不是请他当社长，请做皇帝为何要割舌？吴用以他不识尊卑缓和，赶紧把话题拉回主事。这段让权位的话题骤然越过寨主范围，又被压回当前秩序；它展示李逵愿把宋推到的高度，尚不足以说明宋内心全部政治打算。（本L76／原L6724）

<a id="story-order"></a>
宋焚香后坐第一把椅子，吴用上首、公孙胜下首，左右分别以林冲、呼延灼为首，众人参拜就座。他请众兄弟同心“替天行道”，以人马增多为由分驻六寨，聚义厅改为忠义堂，再逐项分派关隘、小寨、文书、赏罚、钱粮、工造、后勤、酒店耳目和北地买马。（本L78、84／原L6726、6732）

第41回曾明确晁盖第一、宋江第二、吴用第三、公孙胜第四；这里则明定忠义堂宋权居、吴第二、公孙第三。旧席次没有因此在过去失效，新阶段也已出现可核实的次序变化。各寨又有自己的排列，不能将多个“第一位”拼成一张原文没有给出的全书最终功次表。（41本L90／原L4576；本L84／原L6732）

新秩序不只是换把椅子。樊瑞、项充、李衮分别受命守第一、第三关，先前的归附转为守关责任；段景住从献马求进身，变成与杨林、石勇共同管北地收买马匹的人。李云监房屋、陶宗旺管城垣，又接住前半回扩建的任务。六主驻点共有四十三头领，其他关寨及各管事另列；山下酒店则明说“原拨定”“已自定数”，是在新号令中确认旧安排。详细职司集中见附录。（本L38、84／原L6686、6732）

任命之后，叙述写大小头领“尽皆欢喜，人心悦服”，都“拱听约束”。宋虽保留“权居”的名义和未来条件，已在本回实际分兵授职并取得全寨服从。这一层与尚未兑现的捕仇承诺须同时看，不能为了强调其中之一而抹掉另一层。（本L76—84／原L6724—6732）

<a id="story-lu"></a>
## 守丧暂缓复仇，斋席另起招人之谋

异日宋江聚众，要为晁盖报仇、再攻曾头市，吴用以庶民居丧尚不可轻动为由，劝待百日之后，宋依从，留寨每日作功果追荐。此处已经实行的是暂缓出兵，百日后是否发兵还没有发生。（本L86／原L6734）

大名府龙华寺僧大圆游方到济宁、经过梁山，被请上寨做道场。吃斋闲谈，宋问北京风土人物，大圆提起河北玉麒麟。叙述写宋江、吴用听后“猛然省起”，随后二人说起卢俊义，称其河北三绝，棍棒天下无对，若得此人便不惧官军。这些是宋、吴看重其战力的评价，卢本人没有在本回展示武艺，更没有同意入伙。（本L86／原L6734）

吴用说早已留心，只是一向忘了，稍用一计就能教他上山。宋江则问：卢是大名府第一等长者，怎肯落草？接着追问如何“赚得本人上山”。“长者”既可称德高年长者，也可敬称有地位、财力的人，此处不能单由称呼替卢认证品德；宋的疑虑正落在他原有的身份与生活位置。与此同时，“计”“赚”已表明梁山要主动把他引来，具体手段和他的选择尚未展开。（本L86／原L6734；注L5／原L6748）

回末只写吴用叠两个指头说计，读者却还没有听到计策内容；“北京城内，黎民废寝忘餐”是将来的预告，具体事件、责任与损害均未出现。开篇的收人与失人已经发生，末尾又把添一员虎将的欲望放在眼前。晁盖之仇、主位承诺与这次赚卢之计，仍各有尚待后文落实的部分。（本L88／原L6736）
