# 第五十二回：李逵打死殷天锡，柴进失陷高唐州

<a id="arrival"></a>
## 朱仝上了山，杀童的仇却没有就此消失

朱仝终于说出上山的条件：“若要我上山时，你只杀了黑旋风，与我出了这口气，我便罢。”他要的是李逵偿命，实际得到的却是两人暂不相见。李逵把杀小衙内推给“晁、宋二位哥哥将令”，又惹得朱仝要拼命，柴进、雷横、吴用只得再次劝住。朱仝又说，有黑旋风，自己死也不上山；柴进这才提出把李逵留在自己庄上，让朱仝随吴、雷回山。原来的索杀没有实行，留李在庄却成为他当下接受的处理办法。（本回L14／原L5760；三个劝者承接51回L84／原L5707）

这场怨恨有不能略去的前因。上一回，雷横引朱仝离开孩子，吴、雷又把他引出城，李逵展示孩子头须、指他入林见尸；到柴庄后，柴进说明宋江密书及故杀幼童、先绝归路的安排，吴、雷当面承认“皆是宋公明哥哥将令分付如此”。这些已发生的环节，足以把安排的命令责任指向宋江，吴、雷实际参与，李逵承担杀童执行责任。信全文和逐道暗令没有展示；本回李逵并称晁、宋，也不能据此补出晁盖事先批准杀童的现场。（51回L68—84／原L5691—5707）

朱仝接着担心知府移文郓城，拿他家小。吴用说宋江“多敢”已经接来，还是估计的口气，朱这才“有些放心”。柴进置酒，当日临晚送朱、吴、雷离庄，派庄客备三骑马相送。吴用临别又警告李逵不要“胡乱惹事累人”，说等“半年三个月”、朱仝性定再接他，还说多半也会请柴进入伙。这些只是暂留与以后接人的打算。（L14／原L5760）

出了沧州地界，送行庄客骑马返回，三人到朱贵酒店遣人报山。晁盖、宋江率大小头目迎到金沙滩，众人回聚义厅叙旧。朱仝再次问家眷，宋江才明确告诉他，妻儿早已接来多日，奉养在宋太公歇处；又使人引他去见。朱仝亲见一家老小、细软行李俱在，妻子说，有人持书称“你已在山寨入伙了”，家人才收拾星夜上山。朱仝“大喜”，出来拜谢众人，随后与雷横在山顶下寨，山寨连日庆贺新头领。（L16／原L5762）

这里既有家人得到安置的实事，也有替朱仝预先决定去处的力量：接家信中的“你已在山寨入伙了”，走在他正式到寨之前。朱仝见家小的欢喜有清楚对象，不能因此说他已经认可杀童。叙述先写到寨安家，再换线回写沧州的后果；两地事件如何逐日对应，途程没有交代。（L14—18／原L5760—5764）

沧州知府至晚不见朱仝抱儿归来，派人寻了半夜；次日有人发现林中死童，报知后，知府亲往查看，痛哭，备棺烧化；再下一日发文缉拿朱仝。郓城已经申报朱妻挈家在逃，各州县又出赏捕人。小衙内的死没有在朱上山后消失：父亲承受丧子之痛，朱仝背上追捕，家属迁逃；此处官府尚未追明吴、雷、李等人的责任。（L18／原L5764）

<a id="chaitang"></a>
## 柴进相信铁券与官司，李逵只相信先打

李逵在柴庄住了一月，忽有人持急信来。柴进读信大惊，说明叔叔柴皇城住高唐州，被知府高廉的妻舅殷天锡逼夺花园，气病将死，又无儿女，自己必须亲去听遗嘱。李逵主动要同行，柴进答应，收行李、选十数好马、带几个庄客，次日五更启程。到叔宅，他把李逵和从人留在外厅，自己进卧房。病状赞写柴皇城“连朝水米不沾唇”，药也难下，已经逼近死亡。（L20、22／原L5766、5768）

柴进在榻前恸哭，继室出来劝慰，再向他追述事情。新知府高廉兼掌本州兵马，是东京高太尉的叔伯兄弟；殷天锡又倚姐夫高廉的势。有人献勤，告诉殷柴家园亭造得好，殷便带三二十人径入查看，看中后就要柴家搬走。柴皇城以先朝丹书铁券抗辩，又去扯他，反被推抢殴打，从此卧床、不食，服药无效。柴进让婶母继续请好医士，若有官司，便回沧州取铁券，告到官府乃至御前；继室赞他比叔父会理论。夺宅前情与亲缘背景在这里出自继室的叙述，医治也仍只是请治的安排。（L24／原L5770；“卖科”见注L1／原L5834，“门户”见注L3／原L5836）

柴进出房把详情告诉李逵和从人。李逵跳起来，说要教殷吃几斧再商量；柴进认为本地理论不通，还可去京师找更大的权力，依“明明的条例”和他打官司。李逵只道：“条例，条例！若还依得，天下不乱了！”他要“前打后商量”，若对方告官，连官一并砍。柴进笑着提起朱仝不容李逵，指出城中不同山寨，先叫他坐在房里，等看头势、用着时再相请。此时柴进劝阻了动武，虽留下借用李逵的余地，却没有发出杀殷的命令。（L26／原L5772）

侍妾忽来报急，柴进入内。柴皇城含泪自称被殷殴死，托侄亲赍书上京拦驾告状，替他报仇，说罢气绝。柴进痛哭，继室怕他昏晕，劝先商后事。柴进要星夜派人回家取誓书，先依官制备棺椁、铺灵位、穿孝服，宅中大小举哀，请僧做功果。李逵在外听见哭声，只管生气；他问从人，众人都不肯说，因而不能把卧房内的临终遗言算作他亲耳所闻。（L28／原L5774）

<a id="trial"></a>
## 殷天锡被打死，柴家仍遭抄禁夺产

叙述转到“第三日”，殷天锡带三二十闲汉，携弹弓、川弩、吹筒、气球、拈竿、乐器，城外游玩回来，带酒“佯醉假颠”，到柴宅叫管家人出来。柴进身披重孝相见，说明叔病不便搬，如今已死，愿等“断七了搬出去”。他已经作出让步；殷仍只限三日，威胁枷号、打一百讯棍。柴进再举龙子龙孙与铁券，殷先索看，听说券还在沧州，竟说“便有誓书铁券，我也不怕”，喝令左右打柴。（L30／原L5776）

李逵在门缝里看着，听见喝打，便冲出揪殷下马，一拳打翻。随从要抢救，先被打倒五六个，其余一哄逃走；李再提起殷，拳头脚尖一齐上，柴进劝不住，殷当场被打死。原文写的是喝令殴打、左右正待动手，尚未写柴进已被打伤；杀殷也实际用了拳脚。插诗以“惨刻侵谋”与“天宪竟难逃”评价殷的结局，同时称李“猛恶”，没有把这场暴力写得温和。（L30—34／原L5776—5780）

柴进只叫苦，把李叫到后堂，判断抓捕者很快会来，让他回梁山，自己应付官司。李逵知道“我便走了，须连累你”，柴仍说有铁券护身，催他速走。李取双斧、盘缠，由后门离去。不久二百余持刀杖枪棒者围宅，柴进主动出来，愿往府中分诉，却先被捆；众人搜不到“行凶黑大汉”，只把柴押去。（L36、38／原L5782、5784）

高廉正为妻舅之死忿恨，开口便问柴何敢杀殷。柴报世宗嫡派及太祖铁券，说自己来探叔病，殷逼搬又喝打，“庄客李大救护”才打死人；被问下落，又称李惊慌逃去。高廉认定庄客不得主人令便不敢杀人，又指柴故纵逃走，命牢子痛打。柴再说李救主误打，提誓书保护；高问券在哪里，听说还须取来，便以抗拒官府为名加刑。柴被打得皮开肉绽，才“只得招做”“使令庄客李大打死殷天锡”，戴上二十五斤死囚枷，下牢监收。（L38／原L5784）

必须把两件责任分开：柴在杀人后确实催李逃走；杀人前则有劝阻，现场又劝不住李。刑讯后的指使供词不能倒过来证明他事先发令。柴所说“误打”是堂上减责说辞，也不能取代李连续拳脚的实写。高廉把主仆关系当成指使的当然证据，借刑讯把它做成了供词。（L26、30、36、38／原L5772、5776、5782、5784）

殷尸验葬之后，殷夫人要为兄报仇，教丈夫高廉抄柴皇城家私、监禁人口，占住房屋园院。叔父已死，侄儿入牢，宅中人口和财物又整体被控制。杀死夺屋者并没有止住夺产；具体被禁者的姓名、柴家各人的去向，没有逐人交代。（L38—40／原L5784—5786）

铁券在这条线上不断被援引，却没有带到面前；更关键的是，殷已经公开说有券也不怕，审案者又正是他的姐夫。柴的失败不能只解释为没带券书，也不能替他保证券一到便能翻案。柴仍设想上京诉告，叔父也如此托付；眼前的权势侵害已有实据，中央究竟会怎样回应则尚未展现。（L24、26、28、30、38／原L5770、5772、5774、5776、5784）

<a id="reconcile"></a>
## 山寨先迫李逵行礼，再为柴进出兵

李逵连夜逃回梁山，朱仝一见，持朴刀直奔过来；李也拔斧迎斗，晁盖、宋江和众头领劝住。宋先对朱说，杀童“不干李逵之事”，是吴用为请朱上山定的计策，要朱顾同心、勿教外人耻笑；转向李，叫他赔话。李以自己曾出力、朱未有功为由拒绝。宋这才说“却是你杀了小衙内”，又用军师严令、朱年长、自己的情面来劝，甚至说自己拜李也行。李被央逼不过，声称只是哥哥逼迫，撇斧拜朱两拜，朱“方才消了这口气”，晁盖便命设和解宴。（L42／原L5788）

宋的归责随调停对象转动：先替李减责，再承认他的执行责任，又以军令、齿序与兄长情面促成行礼。它没有推翻51回已核的宋令安排；达成的是当下能够共处的礼节和解。李没有说杀童不当，朱的消气也只落实到这场冲突。原先把李留庄的办法维持不住，山寨只好重新协调。（51回L84／原L5707；本回L14、42／原L5760、5788）

李随后报告高唐事，称殷夺园并“殴骂柴进”，自己杀了他；宋立即担心柴受累。吴说等戴宗回便明白，又解释自己早因怕李惹祸，派戴去召李，料找不到就会去高唐寻。小校正报戴回，宋迎到堂上询问。戴先到柴庄得去向，再到高唐打听，由“满城人传说”得知黑大汉杀殷、柴下狱、人口家私被抄，并判断柴性命危急。他没说入牢亲见；读者此前已由叙述知道刑讯与抄禁的实况。晁盖责李到处惹事，李则以皇城伤死、殷又夺屋喝打柴进为自己辩护。（L44—46／原L5790—5792）

晁盖说柴进素来有恩于山寨，愿亲去救；宋以晁是寨主、不宜轻动为由替行，自称与柴“旧来有恩”。旧日柴确曾接纳逃难的宋江兄弟，供衣食、留住庄上，这使宋的旧恩之说有可回查的前事；当前出兵仍不等于救援已经成功。吴用提醒高唐城虽小，却人稠、军广、粮多，分前军五千、中军三千，共二十二头领出发。（本回L48／原L5794；22回L50／原L2663、23回L18—20／原L2720—2722）

前军十二人为林冲、花荣、秦明、李俊、吕方、郭盛、孙立、欧鹏、杨林、邓飞、马麟、白胜；中军十人为宋江、吴用、朱仝、雷横、戴宗、李逵、张横、张顺、杨雄、石秀。欧鹏此前中飞锤、获救乘车回山将息，51回新增八面安歇，本回则已承担前军任务；这是新的行动材料，仍未给治疗过程或完全伤愈的明文。（本回L48、56／原L5794、5802；48回L66、68、76／原L5293、5295、5303；[51回安置的已核依据](../第051回/05_追踪与交接_接任R02.md#delta-q48-02)）

<a id="battles"></a>
## 单挑连胜，救援军却接连败于两种法术

军容赞写梁山旗角、枪叉、弓弩、火炮齐备，马将争强；到了高唐，高廉得报，反把来攻视为自己建功的机会。他兼掌军民，命百姓上城守护，各级军官分领人马出城；三百梯己军士称“飞天神兵”，从各地精选精壮好汉，以披发、葫芦、八卦装束、铜面具和滚刀等写出异样威势。百姓奉令守城和军士出战，是动员实际波及的两类人。（L50—54／原L5796—5800）

高把神兵列中军，军官周围成阵；梁山前军到，两边先用弓弩射住阵脚。林冲出马叫阵，高带三十余军官到旗前骂叛贼；林反骂害民强盗，并说要杀到京师，把高俅碎尸。高令于直先战，不到五合，于心窝中蛇矛，翻身落马；高再叫人报仇，温文宝持枪出阵。秦明请林稍歇，林收矛相让；十合余，秦故露门户诱枪，挥棍削去温半个天灵，温“死于马下”，坐骑跑回本阵。于直中矛落马与温的明写死状，各按原文保留。（L56／原L5802）

单挑优势随即被怪风打断。高廉拔太阿剑念诀，黑气升腾，飞砂走石，惊马乱窜，梁山诸将不能相顾，只得回走。高指神兵先冲，官军随后掩杀，前军离散，五千人“折了一千馀人”，退五十里扎寨；这里没有再分列死、伤、失散的数目。官军也收兵入城。（L58／原L5804）

宋、吴中军到来听报，吴说“想是妖法”，认为若能回风返火便可破敌。宋打开天书第三卷，找到相应法门，记下咒诀，五更造饭后再攻。高廉出阵前命将校不必强挑，只等牌响合力擒宋，有重赏；宋则让诸军勿惊，自称已有破法。高再挥剑起风，宋抢先念诀指剑，风果然倒向高军。宋正待乘势冲杀，高急敲聚兽铜牌，黄砂里却出来猛兽毒虫。（L60—64／原L5806—5810）

兽赞把狻猊、狮子、獬豸、貔貅、豺狼、虎豹、野猪、恶犬、蟒蛇铺成一片冲阵威势；“如龙”“吞象”是赞中的形容，并没有另演现场吞象。宋军惊呆，宋本人撇剑拨马先走，头领簇拥逃命，军校各寻道路；高仍使神兵在前、官军在后，追杀二十余里。第二次败阵不能说成天书毫无用处：回风已经成功，接下来挡不住的是另一重铜牌兽群。（L62—66／原L5808—5812）

这也只增加了天书的一次具体阅用。42回授书时的同观限制、禁泄和功成焚书尚有各自边界，四句天言也没有因高廉姓高就获唯一解释；本回未将“逢高不是凶”直接回扣到高廉或高唐，更未把眼前两败和柴困变成已经脱险的结果。（42回L38—46／原L4637—4645；本回L60—68／原L5806—5814）

<a id="ambush"></a>
## 空寨伤了高廉，柴进仍在牢里

宋到土坡下收兵立寨，叙述说又有军卒损折，却喜众头领都在。吴用料高廉今夜还会劫寨，建议少量留人、大队退旧寨。宋命杨林、白胜留守，两人实际领三百余人离寨半里，伏在草坡里；其余人马回旧寨休息。一更风雷暴雨大作，雷公、电母等赞语把风雨写得猛烈，高廉步行率三百神兵吹风唿哨，杀进寨里，见空便回。（L68—74／原L5814—5820）

杨、白一喊，高廉怕中了计，众神兵四散；伏兵乱放弩箭，一箭中他左背。梁山人冒雨追杀，因人数少不敢深入，高得以带人走远。雨散星现，原文连写“草坡前搠翻射死拿得神兵二十馀人，解赴宋公明寨内”；战中有杀伤、有擒获，而这句话既可把几个动作连读，也可把二十余较紧地连到“拿得”。不必替它硬算每一类人数。随后宋江把“拿来的中伤神兵斩了”，伤俘被处死是明确的，被斩人数则未单列。（L74／原L5820）

杨、白回报风雨，宋、吴却说主寨只隔五里，那里并无雨风。营中众人据此说是妖法，议论云雨从邻近水泊摄来、作用只在近地；两地天气的不同已经写出，具体摄取成因仍是人物解释。杨林又自述高背上中了自己一弩箭。宋赏杨、白，另分七八处外围寨护住大寨防劫，并派人回山取援。（L74／原L5820）

高廉回城养箭疮，令军士日夜守备，暂不交战，待伤好再捉宋。宋仍忧心：一个高廉已破不了，若别处援军来合击，又怎么办？这时外援尚是他设想的风险。吴用于是提出须请一人，否则柴进难救、高唐难取；宋问姓名，回末只以“须请通天彻地人”预告，没有把人说出，更没有请到或破法的结果。（L76—80／原L5822—5826）

引首诗说“必须妙算出机先”，本回也确有从逞勇到失算、再用伏击争回一点主动的变化。李逵拳脚能杀殷，林、秦能胜单将，宋能反风，杨、白能射伤高，却都还没有把柴进从牢里救出。故事也留下朱家、亡童父亲、柴宅人口、守城百姓、损折军卒和被斩伤俘各自的处境；“众头领都有”的庆幸，不能代替这些人的遭遇。（L6、18、38—40、52、56—80／原L5752、5764、5784—5786、5798、5802—5826）
