# 第五十一回：救人的恩义，怎样变成断路的强迫

<a id="marriage"></a>

上一回已经简写扈三娘与王英成婚，以及酒宴中朱贵酒店报来的郓城客人；本回回到**同一场婚宴和同一位来客**，把经过展开。此后，雷横因护母杀人，被朱仝舍身救走；朱仝仍盼着还乡做良民，却被这份救命恩情牵入另一场安排。两人的上山之路，都与“义”有关，选择的余地却很不一样。〔[第50回L48—52](../第050回/00_正文.txt#L48)、[本回L28—30](00_正文.txt#L28)〕

梁山先陪李应饮宴，犒赏三军和大小喽啰，为孙立、孙新、解珍、解宝、邹渊、邹润、乐和、顾大嫂拨房安顿。次日宋江向王英重提清风山时许下的亲事，请宋太公出席，自己引扈三娘到筵前。他称三娘已经认自己的父亲为义父，又说王英虽有武艺，却不及她；如今众头领为媒，便在这个吉日结为夫妇。宋太公在席承担义父的位置，正文没有另给他一段主婚发言。〔[本回L28](00_正文.txt#L28)〕

这次展开比上回多了一句要紧的反应：“一丈青见宋江义气深重，推却不得，两口儿只得拜谢了。”婚成在上回已有答案，本回新增的是她怎样面对这个安排。叙述承认她所见的“义气深重”，同时写出“推却不得”；众人越称宋江“有德有义”，她越处在一个难以当众拒绝的位置。这里已有当场反应，不能一概说她毫无反应可知；但也没有她主动择偶、爱慕王英或全盘认同的表白，王英本人是否满意同样未写。她何时得知父家被杀、兄长逃走，本回仍未交代。〔[本回L28](00_正文.txt#L28)；亲族前情见[第50回L32—34](../第050回/00_正文.txt#L32)〕

酒宴中，小校报说过路客人被山下喽啰拦住，其中一人自称郓城县都头雷横，朱贵已留他吃分例酒食。晁盖、宋江、吴用下山相迎，朱贵将人用船送到金沙滩。雷横说明，自己奉县差到东昌府公干，回来经过路口，被讨买路钱，报出姓名才获接待。宋江亲拜、众头领相见，一连留住五日。晁盖问朱仝近况，雷说他已做当牢节级，颇得新知县喜欢。〔[本回L30](00_正文.txt#L30)〕

上回晁宋一听“恩人”来便以为将入伙，本回却写宋江婉劝之后，雷横以“老母年高”推辞，表示送母终年以后再来。再三挽留无效，众人赠他一大包金银，送过水路，让他回县。这一次，他确实可以拒绝，而且带着馈赠离开。后来他携母逃到梁山，是案件逼出的另一种处境。〔[第50回L50](../第050回/00_正文.txt#L50)、[本回L30、56](00_正文.txt#L30)〕

回寨后，晁盖、宋江请吴用议山寨职事；吴用此前已同宋江商定，次日由宋江逐项宣布。四方酒店兼卖酒肉、接引入伙者，关寨与水陆出入口各有守把，另分钱粮、造船、筑城、衣甲、屋宇、筵宴、文书与军政。新来的人被纳入日常运作：孙新、顾大嫂接店，乐和、时迁各助一店，二邹、二解守关寨，李应与杜兴管钱粮，扈三娘与王英共同监马。欧鹏也被列入大寨八面安歇之人，这是伤后新安置，尚不能据此说他已康复。叙述称“山寨体统，甚是齐整”，紧接的诗又说“从此山东遭扰攘”，内部组织的齐整与山外承受的扰动同时入眼。完整分职见文末附录；任命、驻处和已经完成工程，并不是同一件事。〔[本回L32—36](00_正文.txt#L32)；欧鹏旧伤见[第48回L66、68、76](../第048回/00_正文.txt#L66)〕

<a id="lei-stage"></a>
## 从勾栏看唱，到枷下杀人

雷横回郓城，先见母、更衣，再持回文到县里销差，照旧按日听候使唤。一日，本县帮闲李小二遇他，介绍东京新来的白秀英，说她曾来参见雷都头，只因雷公差在外没有见着，如今勾栏说唱，观众很多。雷正闲着，便随他去看。此处只确认一个郓城县帮闲，不能凭“李小二”同名，就认作旧日沧州酒店中的那个人。〔[本回L38—40](00_正文.txt#L38)〕

雷坐到左边首位，李小二却在人群中离开，另找酒喝去了。台上先演笑乐院本；随后白玉乔自报东京籍、年迈靠女儿的歌舞吹弹谋生。白秀英登台拜四方，敲锣、拍界方、念诗，宣布说唱《豫章城双渐赶苏卿》，说唱相间，满棚喝采。雷的观看与随后的形容文字都承认她“色艺双绝”，尤其写声腔、节奏、吹弹的高低轻重。这份技艺是本回先让人看见的事实，不因她后来的仗势行为而消失。院本演员、看客与白氏父女共同构成谋生、卖艺的场面，双渐、苏卿则只是演出中的人物。〔[本回L40—42](00_正文.txt#L40)；“青龙”“院本”等词见[本回注释](00_注释.txt#L5)〕

唱到精彩处，白玉乔止住节目催赏，白秀英托盘先到雷面前。雷摸袋才发觉没带钱，答应明日一并赏；她要首座先出“标首”，他脸红，反复说三五两也舍得，只恨今日忘带。白秀英讥为空许，白玉乔又用“城里人村里人”“三家村使牛的”羞辱他，观众跟着起哄。有人认出雷，喝止说这是本县都头，白玉乔仍回以“驴筋头”。雷终于跳下揪住他，拳脚打到“唇绽齿落”，众人解拆劝回，观众一哄而散。〔[本回L44](00_正文.txt#L44)〕

雷不久前刚受金银，又已回家换衣，忘带钱并不等于他根本没有钱，也没有证据说他原先蓄意赖账。可他打伤白父是明写的行动，不能因后面知县偏私便删成无辜受陷。被众目围观的失措、报出都头身份仍遭侮辱，使冲突一层层升高；这些解释了暴怒怎样发生，并没有取消拳脚造成的重伤。〔[本回L30、38、44](00_正文.txt#L44)〕

<a id="lei-case"></a>

叙述此时揭出，白秀英与新任知县早在东京便有来往。她见父亲重伤，乘轿入衙，告雷殴父、搅散勾栏，又说他“意在欺骗奴家”。伤人、散场有前文实事，蓄意欺骗则是她的控诉。知县命写状、验伤、指定证见；县中与雷交好的人去说情，却抵不过白守在衙内促办。雷遭捉拿、责打、取招，枷出示众，白又要求把地点定在勾栏门口，知县照办。状、伤、证和招供并没有缺席，私情却介入了怎样处置与怎样羞辱人的过程。〔[本回L46](00_正文.txt#L46)〕

禁子与雷同为公人，本不肯剥衣捆绑地“掤扒”他。白从茶坊把他们叫来，威胁去告知县，随后许赏钱；禁子只得对雷说“没奈何且胡乱掤一掤”，把他捆在街上。白所称知县命他们掤扒，是她当面的说辞；正文直接展示的官命是枷示及移到勾栏门首，赏钱也只说将赏，未写已经交付。〔[本回L46](00_正文.txt#L46)、[注11](00_注释.txt#L21)〕

雷母恰来送饭，见儿子受辱，哭着骂禁子只认钱财。禁子低声解释，自己也想容情，却怕白与知县相好，“一句话便送了我们”。老人遂亲手解索，质问何来原告亲监被告的道理。白听见来骂，双方对骂不休；白先一掌打得老人踉跄，又赶上连续耳光。雷见母亲正挨打，“一时怒从心发”，提枷击中白脑盖，当场致死。叙述称雷“大孝”，诗又以“只因窘辱雷横母”压缩死因：这确实是眼前殴母触发的暴力，并非已叙明的预谋；但雷先前殴打白父、此刻亲手致死，也都要保留。雷母在冲突中有送饭、质问、解索、回骂的行动，并非只在旁落泪。〔[本回L48—52](00_正文.txt#L48)〕

众人将雷押县首告，知县会集相官、拘唤里正邻佑验尸，雷全部招承。其母保领回家听候，禁子被监，雷入牢。禁子在两面压力下作了执行者，此刻又成为被拘的人，后续处分未写。白玉乔则伤而未死，丧女之后继续催成文案，要雷偿命；他不是女儿死后便从案件中消失的引子。〔[本回L54](00_正文.txt#L54)〕

<a id="zhu-release"></a>
## 朱仝承担的，是他自己选择的风险

当牢节级朱仝见雷被发下来，起初也没有办法，先安排酒食，叫小牢子扫净房。雷母六十余岁，来求他看在旧日弟兄情分上救儿，直说儿若有好歹，自己的性命也休了。朱先应承负责饮食，若有方便便救；想了一日，又托人去知县处使用人情。知县虽爱朱，却恨雷杀了白秀英，白玉乔又紧催偿命，疏通仍不成。六十日限满断案，主案押司先持卷赴济州，朱才取得押送雷的机会。照料、思索、说情失败，都在私放之前。〔[本回L54](00_正文.txt#L54)〕

朱带十数小牢子出县十余里，遇酒店便叫众人喝酒，独带雷到僻处，借解手开枷。雷先担心连累，朱才说明自己的打算：知县已把文案做死，解州恐怕必偿命；自己故放应不至死罪，又无父母挂念，家私尚可赔偿。他说“这里我自替你吃官司”，让雷快回家接母星夜逃难。关于将来罪罚，这是朱的风险判断，州里并没有先行判雷死刑；承担的意愿与估计的边界应同时看见。雷拜谢，收拾细软，带仍活着的母亲投梁山入伙，原来送母终年后再来的打算，至此被局势改变。〔[本回L56](00_正文.txt#L56)〕

朱把空枷丢进草中，向小牢子假说雷逃；众人提出去雷家捉，他故意拖延半日，估计人已走远，才领众回县出首。知县本想出脱朱，白玉乔却要向上司告其故放，知县只得申报济州。朱家派人去州里使钱，仍被判二十脊杖、刺配沧州牢城；家间人送衣物盘缠，又先赍发两名防送公人。朱确有家财与人情资源，也确实挨杖、失职、远配，不能说救雷毫无代价。随押小牢子是否受罚，没有交代；朱的承担不能替所有旁人抹平风险。〔[本回L58](00_正文.txt#L58)〕

<a id="cangzhou"></a>

到沧州，知府见朱仪表、美髯，先有“八分欢喜”，除枷留府听使唤，不把他发入牢城营，两名公人得回文离去。朱在厅前候命，府中各类公役处的人情往来及他的和气，使众人都喜欢他。知府追问放雷缘由，他仍答只是疏忽，又说原告执定要招作故放；即使知府问是否见雷孝道、为义气而放，他也不承认。读者已见他开枷、拖延，知道这是官前的应答，不能照收为事实。他得到较宽的处遇，仍是刺配之人，府中人叫“朱都头”不等于恢复了原职。〔[本回L60—64](00_正文.txt#L60)〕

四岁的小衙内就在问话时从屏风后出来，主动要朱抱，双手扯长髯，反复说“我只要这胡子抱”。知府先制止，随后准朱抱出去耍。朱带他看街景、买糖果，孩子回来向父亲复述；知府问钱从何来，赐酒三锺，侍婢捧瓶果斟酒，并准以后孩子想玩便让朱抱去。叙述也明说朱“只要本官见喜”，愿意在孩子身上花费。讨好上司是他的现实用心，孩子先主动亲近和此后的实际陪伴也同样存在；不必将其写成纯粹亲情，也不必因花费有目的，就否定一切照料。〔[本回L62](00_正文.txt#L62)〕

半月后到七月十五，侍婢奶子传夫人的吩咐，让朱抱孩子看河灯。此处知府是明写的生父，“夫人”则只有府内称谓和传命，不据此补定为生母。小衙内穿绿纱衫，头角拴珠子头须，被朱驮在肩上，初更到了地藏寺。寺中钟幡、香食、僧人荐魂、银钱孝服和放灯，把救拔亡魂的斋会铺成眼前热闹场景；这些僧俗人群没有被写成劫童帮手，也没有一份谁目击抱走的证言。〔[本回L64—66](00_正文.txt#L64)〕

<a id="invitation"></a>
## “相请”遭拒以后

朱背孩子绕寺到放生池，小衙内爬在栏干上看耍。雷横从背后拽他袖子，求借一步说话。朱吃惊，让孩子下来坐等，说去买糖，嘱不要走动；孩子催他快来，还想去桥上看灯。朱转身跟雷到静处，没有真的去买糖。一个照看中的孩子，就这样被留在等候里。〔[本回L68](00_正文.txt#L68)〕

雷拜谢救命，说明携母投宋江，并称宋还记朱“旧日放他的恩念”，晁盖众人也感激，故派吴用同来。这里有确切的旧事：第22回朱仝凭熟知地窨而私下放宋，雷横则配合不拘其父；后来宋家书信将家中无事概述为朱雷气力。两人的具体贡献不宜混成一模一样。本回宋念恩的说法由雷转述，并非宋在沧州当场说出。〔[第22回L22—28、36](../第022回/00_正文.txt#L22)、[第32回L40](../第032回/00_正文.txt#L40)、[本回L70](00_正文.txt#L70)〕

吴用随后现身，说已来多日，今夜才候到朱，奉众人之意请他上山同聚大义。朱“半晌答应不得”，继而明确拒绝：自己因义放雷，已经受配，还盼一年半载挣扎还乡，“复为良民”；眼下的话若被外人听去，又会惹事。他的还乡只是愿望，并无届期回乡或获赦文书。雷以服侍他人非大丈夫相劝，朱立即斥道：“你不想我为你母老家寒上放了你去，今日你倒来陷我为不义。”他主动救雷，并没有授权雷替自己选定此后的归宿。吴用口头告辞，朱仍托二人转达问候，一同出来。〔[本回L70](00_正文.txt#L70)〕

<a id="forced-road"></a>

朱回来，孩子已不见。雷先以“多管”猜是伴当听朱不肯而抱走，答应一起找；朱急说孩子是知府的性命，嘱托在自己身上。雷吴不在寺中寻，却把他引向城外下处，一再说“包还你小衙内”、不过是伴当没分晓。朱追问姓名，雷还称不认得，只听叫黑旋风李逵，吴确认。朱听到江州杀人的李逵之名，失惊赶路。这些“误抱”“不识”的说辞，后来被共同安排的披露照亮，不能当作无意误会。两人都说带来“两个伴当”，本回只有李逵被点名见行，另一人未明，不另补分工。〔[本回L72](00_正文.txt#L72)〕

出城二十里，李逵先行礼，说孩子“有在这里”，却将珠须指在自己头上；继而自称把麻药抹在孩子口里驮出城，如今“睡在林子里”。朱入林亲见的，是孩子倒地、头劈两半、已经死去。上回预叙已经用“大斧落时，杀倒幼童稚子”的意象，本回正叙却没有直接演出下药、抱走和劈杀：麻药、驮运来自李的口述，尸体与死亡由朱亲见，不能补成朱看见一斧落下，也不能写成药死。诗“只为坚心悭入伙，更将婴孺劈天灵”，则直指拒绝入伙与杀幼相连。孩子的死是确证的具体损害，不能只写成朱上山前的一次失误。〔[第50回L52](../第050回/00_正文.txt#L52)、[本回L72—76](00_正文.txt#L72)〕

朱大怒奔出林，三人已不见原处；李远远拍着双斧叫阵，朱奋不顾身追去。李却“急赶急走，慢赶慢行，不赶不走”，反复挑衅，把他一直引到天明及一座大庄。调节距离的动作支持有意引路的判断。朱见军器，先猜是官宦之家；柴进出现后，他还不识姓名，开口仍求帮助捉李送官。互报名、知是小旋风之后才随入后堂，并没有一进庄就接受梁山安排。〔[本回L78—82](00_正文.txt#L78)〕

柴进先称祖上陈桥让位、丹书铁券可庇护藏人，又说明宋江密书让吴用、雷横、李逵在庄安歇，礼请朱上山；见朱拒绝，便“故意教李逵杀害了小衙内，先绝了足下归路”。吴雷从侧阁出来拜罪，承认“皆是宋公明哥哥将令分付如此”。这两层相接的证言，足以将杀幼写成有安排的强逼，并将命令责任指向宋江，不能淡化为李逵一人临时发狂。同时，本回没有密书全文、每道口令或晁盖事前批准的展示；柴自称铁券使人不敢搜，也不是已经发生过的搜查试验。〔[本回L84](00_正文.txt#L84)〕

朱回答：“是则是你们弟兄好情意，只是忒毒些个！”“好情意”是他的复杂答语，不能移作吴雷赞杀子的自白，也不能据此说他已经认同。柴一力劝，他虽说“我去则去”，李一出来，他仍起身要拼性命，须柴、雷、吴三人苦劝才止。最后他提出，若要上山，须依一件事；吴用答应几十件也可，条件内容却留到回末。此回止于被逼后的有条件转向，朱没有正式登山，也没有与李和解。孩子尸身如何处置，知府、夫人何时得讯以及官府怎样追责，都还未写；回末高唐州的刑法、土坑预告也不能抢作已发生的后果。〔[本回L84—86](00_正文.txt#L84)〕

<a id="understanding"></a>

这回最刺目的变化，是救命之恩被转成替救命者决定去处的理由。朱救雷先给饮食、想办法，最后自己承担刑罚；雷当时也担心连累。等雷回到朱面前，却以大丈夫、同聚大义劝他放弃还乡生活，朱说“不义”，梁山一方仍用孩子性命替他作决定。称呼、拜礼与旧恩都在，受邀者的拒绝却不再被允许产生结果。〔[本回L54—58、70、84](00_正文.txt#L54)〕

开篇婚宴同样让“义气”与难推并存，末尾则把压力推进到不可挽回的杀害。两处并非完全相同：三娘的反应、身处关系与朱的明言拒绝各有具体文本，不能用一套内心揣测抹平。但它们都提醒读者，众人的仁德称颂，应放回实际由谁作主、谁能拒绝、谁承受后果的场面里看。〔[本回L28、70—84](00_正文.txt#L28)〕

白秀英与小衙内也各自占有具体生命位置。白先有技艺，又借私情动用公权、殴打老人，最后被雷杀；她的施暴与遇害不互相抵销。小衙内则四岁，有扯胡子、吃糖、看桥上河灯的愿望，没有参与江湖恩义争论的选择。放生池、超荐亡魂的斋会紧挨着杀幼情节，读来形成强烈反差。府吏、公人、禁子、婢奶、僧俗人群也各处不同位置：有人传命，有人执行，有人受牵连，没有证据便不把他们统统归成同谋。〔[本回L40—54、62—76](00_正文.txt#L40)〕

本回的赞语也不是一个整齐声音。回首长诗总赞时雨、保义，兼预述后来的功名；山寨诗赞分职又写山东扰攘；白死诗归因殴母，杀幼诗则直接说逼入伙；柴进的贵胄好客赞词之后，出现的是他帮助劝服被断归路的人。把这些声音连着读，才能保住人物行为与称誉之间的张力，而不是拿一句“有德有义”替全回作结。〔[本回L4—26、32—36、50—52、74—84](00_正文.txt#L4)〕
