# 第五十九回：借来的朝廷威仪，救出的人与杀掉的人

为救史进、鲁智深，宋江带七千人马来到华州，却发现坚城不能急攻。吴用等来一条降香消息，转而控制朝廷使者，借真正的御赐物件和仪仗装扮假太尉，把贺太守引出城杀死，再配合两路进兵救囚取财。救援也使少华山四位头领及其人马钱粮迁入梁山；但史进随即想立功报效，初战芒砀山便折损一半，拟议求援时援军已经赶到。这一回既写梁山组织救援的本领，也让礼数、强迫、杀伤与求功后的失败同时显现。（[本L18—62、64、112—114／原L6537—6581、6583、6631—6633](00_正文.txt#L18)）

<a id="story-rescue"></a>

前回鲁智深访史进，本还想邀少华山四人入伙。得知史进因救画匠王义、行刺贺太守而被囚，他不肯听武松回梁山请大兵的劝告，独自进城，反被贺太守诱入后堂捉住。王义之女玉娇枝被强夺的前情，也正是这场救援不能丢掉的受害者线索；本回虽杀贺、救出史鲁，却没有交代她脱离强占或父女团聚。（[58本L64—80／原L6490—6506](../第058回/00_正文.txt#L64)；[59本L54、62／原L6573、6581](00_正文.txt#L54)）

开回的鲁智深仍不服罪。贺太守指他想用禅杖打轿、要为史进报仇，鲁则抗辩“洒家又不曾杀你”，继而在刑讯威胁下报出梁山花和尚身份，警告宋江得知便会下山。这个警告没有使贺退让，反让他大怒：拷打一回、钉大枷、押入死囚牢，禅杖戒刀封进府堂，同时申闻都省，请示发落。鲁此刻受刑入牢已经确定，朝廷如何判处尚未下来；被救时也没有单写两件兵器怎样取回。（[本L14、24、54／原L6533、6543、6573](00_正文.txt#L14)）

消息先由喽啰传上少华山。武松忧心同行二人折了一人，不知如何回见众头领；听说戴宗到山下，便下山迎接，带他上山与朱武等三人相见，说明鲁不听劝而失陷。戴宗原是宋江因不放心而随后差来探听的，如今立即决定返梁山报救。武松留下专等，催他早去急来；戴宗吃过素食，施神行法，三日回寨，向晁盖、宋江具报。这条消息链把武松的等待、戴宗的奔走和山寨的调兵接在一起。（[58本L66、76／原L6492、6502](../第058回/00_正文.txt#L66)；[59本L16—18／原L6535—6537](00_正文.txt#L16)）

宋江闻两兄弟有难，当即分三军出发。前军花荣、秦明、林冲、杨志、呼延灼领一千甲马、二千步军，开路叠桥；宋江、吴用、朱仝、徐宁、解珍、解宝为中军，二千马步军；李应、杨雄、石秀、李俊、张顺押后二千，主掌粮草。行至半途又使戴宗先报，朱武等三人备酒牲等候。鲁的独往与这次七千人的组织行动，在紧接的诗里形成对照：“计拙不能成大事，反遭枷锁入幽囚。”诗评责其轻率，故事则开始展示援救所需的多层配合。（[本L18—22／原L6537—6541](00_正文.txt#L18)）

到少华山后，朱武告诉宋江，华州城广濠深，急攻很难，须得里应外合。吴用没有立即拿出成计，先议看城；宋江巴不得天明就去，他却指出城中囚着“两只大虫”，守方必有提防，应乘月夜窥看。宋江、吴用、花荣、秦明、朱仝五骑午后下山，初更到城外高坡，见城池高壮、堑濠深阔，远望华山。二月中旬的明月、华岳峰洞与传说被铺写得雄奇，坚城却仍让他们“无计可施”，只得回山再议。（[本L24—28／原L6543—6547](00_正文.txt#L24)）

转机来自探消息的无名喽啰：朝廷殿司太尉将携御赐金铃吊挂，由黄河入渭河，到西岳降香。吴用这才说“计在这里了”，秘密吩咐李俊、张顺。李俊指出不识地境，需要引路，杨春主动相帮。三人先夺十余只大船；次日宋江、吴用等八头领带五百余人抵渡口，花荣、秦明、徐宁、呼延灼埋伏岸上，宋、吴与朱仝、李应在船，李俊等藏船滩头，等了一夜。水手的本领还需要向导、船只、岸军与等待；那些被夺船只的原占有人没有出场，后来的归还范围也未逐一落实到他们。（[本L28、54／原L6547、6573](00_正文.txt#L28)）

<a id="story-hostage"></a>

次晨三只官船到来，黄旗写着奉旨降香太尉宿元景。宋江看到“宿”字，想到玄女的“遇宿重重喜”，心中暗喜；这是他把眼前人物与旧天言相接。随后借宿的仪物救人，确实给首句提供了有限的对应候选，其余三句的所指仍未揭明。实际迫使宿元景停船的，首先是拦截与通名。吴用站在船头报出“梁山泊义士宋江”的名号，客帐司和二十余虞候却以朝廷命臣的身份拒绝私见。宋江仍躬身请见，话锋转到若不肯见，恐孩儿们惊了太尉。朱仝一招枪上号旗，岸军弓箭齐出，船工吓得钻入船梢，客帐司这才慌忙入报。（[本L30、38—54／原L6549、6557—6573](00_正文.txt#L30)；[42本L40—42／原L4639—4641](../第042回/00_正文.txt#L40)）

宿元景出来后仍不愿登岸，李应又一招号枪，藏船齐出。李俊、张顺持尖刀跳上官船，先把两个虞候弄下水；宋江喝止，两人随即下水，把落水者送回，又展示在水面往来如履平地的本领。两名虞候在此被用来示威，也确被救回，伤情没有写。宋江一边称贵人、喝退手下，一边坚持太尉须到山寨告禀，并向西岳神灵起誓无损害之心；叙述却明说“不容太尉不上岸”“不得已随众同行”。称请、称借的礼貌，始终有武力作后盾。（[本L32／原L6551](00_正文.txt#L32)）

花荣、秦明先陪太尉上山，宋江又命将全部随员、御香祭物和仪仗收上，只留李俊、张顺带百余人看船。聚义厅上，真太尉居中受四拜，宋江跪陈自己被官司所逼、权借水泊避难，“专等朝廷招安，与国家出力”，又称两兄弟无事被贺陷害，请借仪从与金铃去赚华州。这是他的游说说辞，不能据此抹去鲁此前欲刺贺的行动。宿担心事露连累自己，宋答让他回京全推宋江；宿看众人难以推托，“只得应允了”。宴谢和敬礼都实有其事，强制也并未因此消失。（[本L38—40／原L6557—6559](00_正文.txt#L38)）

众人随即改装：一个俊俏喽啰剃须穿太尉衣服，宋江、吴用扮客帐司；解珍、解宝、杨雄、石秀先扮虞候，花荣、徐宁、朱仝、李应扮四衙兵，其他喽啰执仪仗、抬祭物。朱武、陈达、杨春留下款待真正的太尉及随员；秦明、呼延灼与林冲、杨志分两路取城；武松预到西岳门下待号，戴宗先去通报。稍后石秀带刀去庙门帮武松，戴宗补入虞候之列，位置随着计划推进而改变。（[本L40、48、52／原L6559、6567、6571](00_正文.txt#L40)）

<a id="story-fake"></a>

假仪从不先报州，直奔岳庙。戴宗已报观主和职事，庙众依使者礼仪迎接，抬香亭、扶假太尉上轿。假宿虽相貌近似，却“言语发放不得”，于是装病围靠褥，隔远受拜，“只把手指，并不听得说甚么”。吴用一面借病免去应答，一面反问本州何以不迎奉旨大臣；观主答已使人报州，推官随后带五七十做公人及酒果来到。（[本L42—44／原L6561—6563](00_正文.txt#L42)）

推官的信任有一整套真凭证支撑：旌节、门旗、牙仗都是东京内府所造，吴用又假意进出禀复，令他远拜假太尉。推官解释，前路虽有文书，却无近报；贺太守因少华联梁山将攻城，每日提防，不敢擅离，故先差自己来，随后再到。吴用声称“太尉涓滴不饮，只叫太守来商议行礼”；推官又取酒给客帐司及亲随把盏。吴用借假太尉之口不断催贺前来，推官则继续履行接待和回报的职务。（[本L44／原L6563](00_正文.txt#L44)）

吴用再度假禀，持钥开匣，从香帛袋取出金铃吊挂，用竹竿叉起展示。黄金五彩、龙凤珠宝、红纱灯笼的铺陈，随后落实到内府作分高手的制造；注释释“作分”为作坊。叙述问“不是内府降来，民间如何做得”，正说明这些华丽物件为何能为假身份作保。吴用收物上锁，再交出中书省公文，推官与公人见过物件文凭，回州报请。故事未写预先联络好的城内同谋；眼前确实展开的，是利用接待奉旨使者的流程，把防城的太守诱出。观主、人夫等所做的是接待公务，不能据此替他们确认预知伏杀。（[本L44—48／原L6563—6567；注本L1／原L6643](00_正文.txt#L44)）

<a id="story-killing"></a>

观主供素斋，执事布置岳庙；宋江看过金门玉殿、供设威仪，又到正殿拈香再拜、暗暗祈祷。贺太守带三百余带刀公吏抵庙时，吴用以“闲杂人不许近前”止住随从，诱太守独自向前。贺拜见假太尉，吴用仍问不远接之罪；贺答无近报，吴用一喝“拿下”，解珍、解宝便掣短刀、踢翻、割头。太尉的威名和问罪的口气被用来拆开太守与护卫，真正杀人的却是梁山头领。（[本L48—52／原L6567—6571](00_正文.txt#L48)）

宋江紧接着命“兄弟们动手”。三百余随从惊呆，花荣等向前攻击；一半抢出，又遇武松、石秀从庙门杀入，喽啰四下赶杀，原文写“三百馀人不剩一个回去”。后来到庙者也被李俊、张顺杀掉，身份与人数未列。宋江急收御香吊挂下船，赶到华州时，城中已经两路起火；众军杀入，先救史进、鲁智深，再开库取财装车。后来宿元景到城所知，还包括城中军校死百余、马匹尽被掳去。这些死者与先前的三百余随员分属不同场景，不能漏掉，也不能扩大成全城军校尽死。（[本L52—60／原L6571—6579](00_正文.txt#L52)）

回少华山后，众人归还祭物仪仗，给太尉一盘金银，随员不分高低都得金银，再设送行宴，送到河口交割船物，叙述强调“一些不肯少了”。履约的对象很明确，不能延伸成一切杀伤劫取都已补偿。宿元景入华州后，命推官申报宋江途中劫御物、诱杀知府，自己又到庙焚香，把吊挂交云台观主，星夜回京奏事；他没有就此隐去案情，朝廷是否免责仍无结果。贺死后的玉娇枝，也没有因另一条救援成功便获得明确后况。（[本L54、60／原L6573、6579](00_正文.txt#L54)；[58本L70、76／原L6496、6502](../第058回/00_正文.txt#L70)）

宋江送走太尉，再与少华四人商议收钱粮、烧寨栅，带人马粮草归梁山。归途“秋毫无犯”是这一程的行为，不能覆盖此前华州的杀人劫库。戴宗先报，晁盖与众头领下山迎接、设庆筵；次日史进、朱武、陈达、杨春各以己财宴谢。牢中被救的是史进、鲁智深，迁泊答谢的四人则是史、朱、陈、杨；朱武等三人此前还承担接待、向导和留守，并非四人一同从牢里救出。（[本L54、62／原L6573、6581](00_正文.txt#L54)）

<a id="story-recruit"></a>

几日后，朱贵来报芒砀山新聚三千人，为首樊瑞号混世魔王，项充、李衮为副，三人结义、打家劫舍，竟商量吞并梁山。樊瑞呼风唤雨、用兵如神，先只是朱贵“听得说”的消息。宋江闻言发怒，欲亲下山，史进却以四人新到、“无半米之功”为由，请带本部前往，宋江大喜允之。史进刚获救，四人又迁寨受援而宴谢，如今急于以军事贡献确立位置；这有主动求功的意味，却不是明写宋江强令他们冒险。（[本L62—66／原L6581—6585](00_正文.txt#L62)）

四人三日到芒砀，伏路喽啰已上报。叙述先点汉高祖斩蛇旧迹，再逐一展出四人英姿：史进赤马、三尖两刃刀与雕青；朱武双刀、神机名声，陈达点钢枪与膂力，杨春大杆刀、守住阵门。张良、范蠡、姜维、左车都是赞诗比拟，声势写得很足。接着项充、李衮步行下山，二人都使团牌，项充有二十四飞刀、手执标枪，李衮有二十四标枪、左牌右剑，认军旗各标绰号。最初转报说兵器插在牌上，后面的正面介绍又说背插；照文本保留即可，不必硬还原成同一种器具装配。（[本L66—110／原L6585—6629](00_正文.txt#L66)）

<a id="story-defeat"></a>

真正开打却极短。项、李“并不打话”，喽啰筛锣，两人舞牌滚入阵，史进等挡不住，后军先逃。史进前军抵敌，朱武等中军呐喊而各自逃生，军马“人亡马倒”，败退六七十里。史进险中飞刀；杨春转身迟，伤的是战马，他弃马逃命。点军折一半，未分死、伤、溃散各数。此前长篇英雄赞不能保证此战有效，四骑与军阵反被两名步战对手冲散，对方本领由此成为实际难题。（[本L112—114／原L6631—6633](00_正文.txt#L112)）

史进等正在商议差人求救，花荣、徐宁带约二千人已到。花荣说宋江不放心、好生懊悔，特遣二人相帮；这份心情由花荣转述，援军则确实先于本次求救派出。两军合营，次晨正欲再战，宋江又与吴用、公孙胜、柴进、朱仝、呼延灼、穆弘、孙立、黄信、吕方、郭盛带三千人到来。听完损兵经过，吴用主张先扎寨再议，宋江却性急到山下。天晚见山上青灯遍布，公孙胜判断有行妖法之人，建议退军，次日献阵捉二人；宋江听从，令退二十里安营。次晨虽写公孙胜献阵，阵名、布置、执行都未展开，樊瑞亦未正面施法；项、李归山和魔王下拜仍是回末预告。（[本L114—116／原L6633—6635](00_正文.txt#L114)）

回看华州一段，最突出的本领是把真物件、真礼制流程变成假身份的支撑。吴用不只善于说谎，还懂得让推官亲见凭证、带话回州，让各环节按照既有职务运转。可是使太尉应允的不是单纯说服，而是“不容”与“只得”；推官和庙众的公务又为伏杀铺路。宋江既郑重拜谢、兑现还物，也下令围杀众多随从。礼数、信用与杀伤在这里同时成立，不能用一面取消另一面。（[本L30—54／原L6549—6573](00_正文.txt#L30)）

诗评也没有把这些事整齐地归入一种评价。开篇称“英士”“佞臣”，责天使尸位，劫宿后的诗称“暂假威名救困亡”；事毕却反问“太守何辜独被灾”。这一问没有撤销贺此前刑讯和强夺的事实，“独”也没有列尽已经死去的其他人，却让成功救人的结局留下不平整的伦理声音。随后史进求功而败，更把胜利后的扩张接到损失上：梁山能及时援助、吸收新众，也必须面对新成员和军卒已经承担的代价。（[本L6—12、14、34—36、52—64、112—114／原L6525—6531、6533、6553—6555、6571—6583、6631—6633](00_正文.txt#L6)；[58本L70、76／原L6496、6502](../第058回/00_正文.txt#L70)）
