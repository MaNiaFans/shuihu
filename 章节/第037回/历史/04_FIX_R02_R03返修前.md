# 第三十七回

揭阳镇上，宋江已经把五两银子给了那个使枪棒的教师。叙述者说这一给「不合」。人丛里钻出一条大汉，搦起双拳来打他。大汉的理由说得很明：枪棒是到他的镇上逞强；「我已分付了众人休采他」；宋江拿银子赏人，灭了揭阳镇的威风（L20）。这道不让人赏钱的禁令是大汉下的。教师没有下过。宋江回他：银子是自己赏的，不干你事。大汉揪住他，骂贼配军。拳劈脸打来，宋江躲开；大汉再追一步，宋江正要放对，还没对上。教头从人背后赶到，一手揪住头巾，一手提住腰胯，把大汉兜翻，刚要爬起又补一脚。两个公人劝住的是教头，不是帮着打宋江。大汉起来只丢下一句「使得使不得，教你两个不要慌」，望南去了。拳没有打中。

宋江这才问教头姓名。教头自报河南洛阳人氏，姓薛名永；祖父在老种经略相公帐前做军官，得罪同僚，不得升用，子孙靠枪棒和卖药过日子；江湖上叫他病大虫薛永。老种经略相公只在这番自述里。薛永反问，宋江自己说姓宋名江，祖贯郓城县。薛永问的是「莫非山东及时雨宋公明么」。宋江承认。他下拜，宋江扶住，要少叙三杯。薛永先收拾起枪棒和药囊，才同宋江去邻近酒肆。三杯没有喝成。酒肆里酒肉都有，酒家不敢卖：刚才厮打的大汉已经使人来分付，卖了就把店子打得粉碎。这个传话的人没有出场。薛永说自己去把房钱算清，一两日间到江州相会，让宋江先走。房钱后文没有写付清；江州之约也没有按这句话发生。宋江又给了他一二十两，两人相辞，各自走了。

宋江和两个公人再找店。一家说「小郎已自都分付了」。连走几家，话都一样。市梢几家打火小客店也不留，说小郎不许安着这三个人。店家拒绝的是宋江一行；他们不敢拒绝的是小郎。太阳落到昏晚，三人走上大路，前后都没有店。

林后小路上有灯，不在正路。公人点了出来。宋江说没奈何，明天多走三二里也不打紧。不到二里多，是一座大庄院。庄客先问他们是谁，听宋江说是配送江州、错过宿头、明早给房金，才进去禀太公，出来传请。太公让他们住门房，给了晚饭。庄客点灯、端三分饭食，吃完把碗收进去。两个公人提议：这里没有外人，把行枷除了，快活睡一夜。宋江同意。净手时他看见屋后一条村僻小路，先看在眼里，没有说要走。他还夸这个太公难得。话没落，太公已经带着三个庄客，打着火把在打麦场上到处照看。宋江从门缝里看见，对公人说太公像自己父亲，样样要亲自照管。父亲没有来。这次巡看发生在门外叫门之前，不像是已经在搜他们。

门外叫开庄门。进去五七个人，为首的拿朴刀，后面的拿稻叉、棍棒。宋江认出，提朴刀的就是镇上要打他们的那个大汉。太公叫他小郎，问他和谁厮打。他叫太公阿爹，先问哥哥在不在。太公说哥哥喝醉了，睡在后面亭子上。小郎要去叫醒哥哥，一起赶人。太公不让他立刻去，逼他把缘故说完：使枪棒卖药的不先来见他们弟兄；「被我都分付了镇上的人，分文不要与他赏钱」；一个囚徒出尖，赏了五两；他自己要打，反被卖药的揪翻、踢了一脚，腰还疼；酒店客店他已经封了；又叫赌房里一伙人到客店把卖药的抓来，打了一顿，吊在都头家里；明天捆成一块抛进江里。只没追上两个公人押的囚徒。抓人、吊打是他讲给父亲的话，不是当场看见的。都头是谁，只有「都头家里」这一句。抛江是他宣布的打算。太公骂他短命，说人家用自己的银子，不干你事；挨打是自找的，又不曾伤重；哥哥知道了不肯干休，那就是害人性命。他要儿子睡觉，半夜别去敲门打户、激恼村坊，也积些阴德。「不曾伤重」说的是儿子自己，不是宋江。小郎不听，拿朴刀进庄。太公跟着进去。他有没有把门房里的三个客人点破，正文没有写。

宋江听完，认定再住下去就是送命。他说，便是太公不肯说破，庄客也不敢瞒。这是他的判断，门里没有人已经来告发。两个公人同意快走。宋江不走大门，说掇开屋后的墙；走到那一步，叙述写成挖开一堵壁子。公人挑包裹，他自己提着卸下的行枷。三人趁星月走小路，慌不择路，一个更次，到了芦花和浔阳江边。

背后喊「贼配军休走」，火把和胡哨赶上来。前面是大江，侧边一条阔港。宋江说早知如此，不如当时留在梁山泊。这是他站在江边的后悔，不是这一夜又走了一趟梁山。芦苇里摇出一只船。他叫梢公，先许十两，嘴里说的却是背后有强人打劫，不是配军。梢公听见银子多，把船拢岸。一个公人把包裹丢进舱，一个用水火棍把船撑开。梢公听见包裹响，心里暗喜，船已经到了江心。滩上十数个火把，为首两个大汉各挺朴刀，随从二十余人。他们叫船拢来。宋江求梢公不要拢，愿意再加银子。

梢公不回答岸上，只往上水摇。岸上说不拢来就都死。他自称张梢公。火把里一个长汉认出张大哥，说弟兄要捉这三个人。梢公把他们说成自家亲眷、衣食父母，请回去吃一碗板刀面，又说这个主顾自己接了好几日，不能让给岸上。人就这样留在船上，没有交上岸。亲眷和「好几日」对不上刚发生的事，是说给穆家听的。板刀面像请客，意思要到后面才揭开。长汉是这两个为首者里的哪一个，是兄还是弟，此处还没有分开。宋江悄悄对两个公人说：难得这个梢公救了三命，又替他们分说，不可忘了恩德。把梢公当成恩人的是这一句，说话的是宋江。正文没有另写公人附和。

船离岸以后，岸上的火把还在芦苇里亮着。宋江说好人相逢，恶人远离。梢公唱起湖州歌，说自己不怕官司不怕天，昨夜华光来趁，还夺下一金砖。华光只在歌里。宋江和两个公人听得酥软，宋江想他是唱着玩。梢公放下橹，骂两个公人平日诈害做私商的人，逼他们选板刀面还是馄饨，然后自己解释：板刀面是艎板底下的快刀，一刀一个剁下水；馄饨是脱光衣服自己跳江。宋江这才说明自己是没奈何犯了罪、迭配江州的人，求他饶三个。梢公自称狗脸张爹爹，说半个也不饶。宋江把包裹里的金银财帛衣服都许给他。他不收这笔买命钱，摸出板刀。宋江对天说，因为不敬天地、不孝父母，犯下罪责，连累了两个公人。两个公人说，罢了，三人死在一处。三个人抱在一起，正要跳。

上水又来一只快船。船头一条大汉横着托叉，船梢两个后生摇橹。大汉第一句不是救人。他喝问谁敢在当港行事，「船里货物，见者有分」（L52）。这是来要一份。梢公认出李大哥，问他去做买卖为什么不带上自己。大汉也认出张大哥，问船里有没有油水。梢公这才改口：自己几日没路，又赌输了；岸上的人把三头行货赶进船，是两个公人解一个黑矮囚徒，说迭配江州，项上却没有行枷；赶来的是镇上穆家哥儿两个，定要人；自己见有油水，没有还。大汉听到这里才问：莫不是我哥哥宋公明。宋江觉得声音熟，在舱里叫救命。大汉说真个是，「早不做出来」。

宋江钻出来看的，是自己所乘这只船的舱面。船头上横托叉的人还站在来船上。叙述者这才点名：混江龙李俊；摇橹的是出洞蛟童威、翻江蜃童猛。童威、童猛没有自己的话。跳过船来的是李俊，不是宋江换到李俊那条船上（L52、L58）。李俊说自己在家坐立不安，撑船出来是赶私盐，遇见受难是意外。张横呆住，问这个黑汉是不是山东及时雨，然后下拜，怪他何不早通姓名。停手、下拜都在认出来之后。宋江问这人是谁。李俊说是结义兄弟，小孤山下张横，绰号船火儿。宋江和两个公人都笑了。笑是释然还是别的，正文没有再写。两只船并排摇到滩边，才从舱里把宋江和两个公人扶上岸。

李俊让张横仔细认：天下义士只除非山东及时雨、郓城宋押司。这串「郓城宋押司」是李俊的介绍。郓城两个字，宋江自己报过；薛永当面问的只是「山东及时雨宋公明」。张横在沙滩上再拜，求恕罪。他问为什么被配来。李俊把宋江犯罪的事说了一遍，正文没有引。江上那两句「没奈何犯了罪」「不敬天地，不孝父母」，不能当成这遍案情的原文。

张横接着讲一个还没出场的弟弟。一母所生，自己是长的；弟弟浑身白得像雪练，能在水面行四五十里，水下伏七日七夜，人叫浪里白跳张顺。四五十里、七日七夜是他的话，旁边注的是「游」，人并没有到场验证。他又倒叙扬子江边的旧私渡：赌输了就做私渡，张顺扮成客人，半江里先把兄弟撺下水做样子，向每人要三贯，吓够了送到僻处上岸，再分钱去赌。按这番自述，那些客人是被多要了船钱，然后活着上岸。宋江说，可知有人来寻这私渡。李俊等人笑。张横又说弟兄如今改了业：自己在浔阳江做些私商，张顺在江州做卖鱼牙子。他要寄书，自己不识字。李俊说去村里央门馆先生写，留下童威、童猛看船。信这时还没写。

走不到半里，火把还亮着。张横说穆家弟兄没走。李俊要叫他们来拜。宋江说使不得，这两人赶着捉自己。李俊还是招手、胡哨。人伴奔到面前，看见李俊、张横和这三人站在一起，只说认得镇上那个出银子、灭了威风的人，不认得宋公明。李俊对他们用的介绍是「山东及时雨郓城宋押司公明哥哥」。两兄弟扔下朴刀下拜，自己说的是闻名已久、刚才冒渎、犯伤了哥哥。他们没有自己报出那串官称。「犯伤」是谢罪的话。镇上那一拳被躲开了，宋江身上没有写伤。

姓名是李俊代报的：兄穆弘，没遮拦；弟穆春，小遮拦；揭阳镇一霸。镇上动手、封赏、夜归要叫人的，是弟弟穆春。穆弘当时醉在后亭，不要写成他在镇上打出了那一拳。回目写「没遮拦追赶及时雨」，只是题面，不能代替这个次序。江边开口的长汉，仍然不单扣在兄或弟头上；张横已经说，追来的是穆家两兄弟。李俊又说这里有三霸：揭阳岭上岭下是他和李立；镇上是穆家；浔阳江边做私商的是张横、张顺。李立不到场。张顺被算进私商一霸，和他「如今做卖鱼牙子」是两个人的两种说法，都先留着。宋江请他们放了薛永。穆弘笑问是不是使枪棒的那厮，叫穆春去取，并请宋江到庄上赔罪。取人的命令这时才下。抛江没有执行。

两个庄客去看船。童威、童猛被请到庄上。另有人先回报，杀羊宰猪。五更到庄，请出来相见的是穆太公，也就是夜里留宿、又劝不住小郎的父亲。正文没有另写一句「这就是你们挖开墙壁的那座庄」，连起来靠的是这一家父子。天明，穆春把薛永取到。他能赴宴，也能后来送行；挨打之后伤成什么样，没有写。席上说了各自经过的许多事，一句都没有引。当晚留下。次日宋江要走，穆弘不放，陪他去镇上看了一遭市村景，又住三日。宋江怕违了限次，坚意要行。限是几天，没有写。当日送路宴，次日早晨告别。他改口让薛永先在穆弘处住几时，再来江州相会。穆弘答应看顾。所以薛永没有在这一回到达江州，原先那句一两日也没有照办。穆弘取出一盘金银给宋江，另给两个公人一些银两，都没有写斤两。

张横在庄上央人写了一封家书，请宋江带给张顺。写的人没有姓名，信里写了什么也没有引。信放进包裹，没有交到张顺手里。张顺本人始终没有出现。

众人送到江边，另叫一只船，装上先头行李，重新安排行枷，上船饯行，洒泪分开。李俊、张横、穆弘、穆春、薛永、童威、童猛回到穆家庄，再各自回家。薛永刚被答应留在穆弘处看顾，收束又把他算进各自回家的一群。送行之后他究竟睡在哪里，没有再落笔。

送宋江去江州的梢公非比前番，张起帆，早早到了岸。这不是张横。宋江依前戴上行枷。两个公人取出文书，直到府前，正赶上府尹升厅。知府姓蔡，双名德章，是蔡京的第九个儿子，江州人叫他蔡九知府。叙述者说他为官贪滥、作事骄奢，又说江州钱粮大、人烟盛，太师特地叫他来。蔡京不在场。蔡九看见宋江一表非俗，问枷上为什么没有本州的封皮。两个公人说，路上春雨淋漓，水湿坏了。正文写过卸枷、提枷、再戴枷，没有写这场雨，也没有出面拆穿。知府接受了，让快写个帖，送到城外牢城营，改由本府公人押下去。

原两个公人把宋江交到营里。府里的公人拿文帖，押着宋江，并同原来的公人出衙喝酒。宋江给了府公人三两来银子。讨了收管，他进单身房。那公人先向管营、差拨说了方便，然后回府。是一个还是几个，原文先说府公人，后说那公人，没有另写死。原来的两个公人交还包裹，道谢，自己说虽然受了惊，却赚得许多银两，到州衙讨了回文，往济州去了。这一回的句子里只叫他们两个公人，不再另起名字。

宋江再自己送银子。差拨十两。管营处加倍的银两，再加人事。营里管事的和军健也有茶资，所以没有一个不欢喜。加倍紧挨着十两，没有写成一个新的整数。到点视厅除了枷。管营已经收了贿赂，仍按他说的太祖武德皇帝事例，要新配的人先吃一百杀威棒，命左右把宋江背起来。宋江说路上感冒风寒，还没好。管营看见他面黄肌瘦，把这顿棒权且寄下，又因为他是县吏出身，派到抄事房做抄事，当即立了文案。棒是寄下，不是已经打下，也不是写成以后再也不打。是真病，还是为了避这一顿，叙述没有分开。

囚徒见他有面目，买酒来贺。次日他回礼，以后又请差拨、牌头喝酒，常常送管营礼物。住了约半月，满营都欢喜他。叙述者先放一句世情看冷暖，再写具体的一天。差拨提起前日说过的节级常例，已经一旬之上还没送。那场前日的话没有写出来。宋江把两边分开：差拨要钱可以再取；节级要的话，一文也没有；等他下来自有话说。差拨警告那人利害、手脚了得。宋江又把话说活：也许送一些，也不见得；也许他有不敢要的道理，也不见得。不敢要的理由没有讲。

牌头进来报：节级已经在厅上发作，骂新配军为什么不送常例钱。骂是牌头转述的。差拨说连他们也要被怪，起身走了，说不要见他。宋江离开抄事房，走向点视厅。节级没有姓名，没有外貌，对话也没有开始。叙述者说，不是这场相见，有分教江州变成虎窟狼窝，十字街头变成尸山血海，直教归水浒、上梁山；究竟怎么相见，且听下回分解（L78）。虎窟、尸山、水浒、梁山都挂在预告后面，不是这一回已经发生的事。
