# 第六十一回：吴用智赚玉麒麟，张顺夜闹金沙渡

吴用这一回赚卢俊义，先让他相信留在家中必有大祸，再让东南远行成了避祸的办法。等卢走近梁山，劝说便逐层换成诱战、夺车、驱赶和水上逼降。卢的武勇始终得到展示，他却不断失去对人车、道路和身体处境的控制；本回最后写到张顺翻船、卢落水，还没有写他答应入伙。[本L34—40、88—122／原L6787—6793、6841—6875](00_正文.txt#L34)

## 从北京的卦摊到梁山的水面

<a id="story-go"></a>
### 要办细事，先得约束同行的李逵

龙华寺僧人说起玉麒麟，吴用便向宋江请行，声称凭口舌说卢俊义上山，如同“探囊取物”，只少一个粗心大胆的伴当。李逵立即应声。宋江认为放火、杀人、打家劫舍才合他的性子，这次是“做细的勾当”，更担心大名府做公的人多，认出他便会送命。李逵却先听成众人嫌自己丑，坚持要去。吴用于是提出三约：从当日起断酒，扮道童而听指挥，从次日起不说话。李逵最难忍闭嘴，提议口衔一文铜钱；那还是他想出来的办法，随后又说即使被拿，也要用双斧砍许多头，众人笑劝都未能使他退意。当日设宴，次早金沙滩送行，宋江仍再三嘱吴用别让李逵有失。[本L8—10／原L6761—6763](00_正文.txt#L8)

担心很快有了实在的缘故。二人投宿北京城外，李逵在厨下做饭，一拳打得店小二吐血。小二到房里向吴用投诉，称自己没有替那“哑道童”烧火，便挨了打。吴用慌忙赔话，拿十数贯钱给他将息，又埋怨李逵；伤者此后的恢复没有交代。进城前，吴再警告李逵别把自己的性命也送掉，另定摇头便不可动的暗号，李逵答应。[本L12／原L6765](00_正文.txt#L12)

两人的装束也服务于这场伪装：吴用戴乌纱头巾、穿白绢道服，手拿铃杵；李逵挽丫髻、着短褐，挑着“讲命谈天，卦金一两”的招牌。北京先以高城深壕、军械旗帜、钱粮商货和歌台梵宇铺陈出来，继而交代盗贼四起、梁中书统军镇守。城门下四五十军士簇着把门官，实际盘问和看文引的是军士。吴用自报“姓张名用”，交出假文引；军士说李逵眼像贼，李刚要发作，见吴摇头便低了头。吴再解释道童又聋又哑、有蛮力、是家生孩儿，借假身份替他的异状开脱，随后入城。[本L14—22／原L6767—6775](00_正文.txt#L14) “文引”是通行证明，“家生”指奴仆所生子，这两条注释解释的是说辞的含义，并没有把李逵的真实身世改掉。[注本L1、3／原L6883、6885](00_注释.txt#L1)

<a id="story-divination"></a>
### 高价与退银，让卢从质疑转为求教

吴用入城摇铃，唱甘罗与子牙、彭祖与颜回、范丹与石崇命运有别，归到“八字生来各有时”，接着又说要问前程先付一两银。五六十小儿跟着看笑。他在卢家解库门前走去又回来，街上的喧哄终于传到厅内。卢正在看主管收解，先问当直何事；当直报说算命者收费奇高、道童相貌步态惹笑。卢却由高价推知“既出大言，必有广学”，命当直去请。传话、问明主人、带道童入门之后，吴让李逵坐鹅项椅等候，自己转前见卢。[本L24—30／原L6777—6783](00_正文.txt#L24)

叙述在这里说“天罡星合当聚会”，又以《满庭芳》盛赞卢俊义的仪表、义胆、豪富、临敌本领和报国志。这些赞语先替他定下英雄的声调，实际会面却从他的礼遇与求知开始。吴继续假称张用，自号谈天口，说能推生死贵贱；卢请他到后堂小阁，茶后叫当直取白银一两压命，报出三十二岁及自己的生辰八字，强调“君子问灾不问福”，要问眼下行藏。[本L30—34／原L6783—6787](00_正文.txt#L30)

吴排铁算子、拍桌叫怪，断卢百日内有血光，家私不保，死于刀剑。卢起初并不信，笑着拿豪富家世、祖宗亲族的名节，以及自己谨慎取财作反驳。吴立刻变色，退还原银，起身便走，责他只爱阿谀、不受忠言。卢这才把反驳收回，说前言是戏，请他指教。吴又把凶言加重为百日内尸首异处、命定难逃，等卢问可否回避，才给出例外：去东南巽地一千里外，虽有惊恐，却“不伤大体”。卢愿以厚报相酬。[本L34／原L6787](00_正文.txt#L34) 巽为东南，是本回注释所明定的方位。[注本L7／原L6889](00_注释.txt#L7)

吴再说命中有四句卦歌，写在壁上，日后应验便知其灵。卢叫取笔砚，依吴口授亲自写在白粉壁上：

> 芦花丛里一扁舟，俊杰俄从此地游。
>
> 义士若能知此理，反躬逃难可无忧。

写者是卢，给词者是吴。卢还想留先生过午，吴以耽误卖卦为辞，带李逵回店结清宿饭钱，收拾行李出店。这时他才告诉李逵“大事了也”，要星夜回寨“安排圈套，准备机关”，迎接早晚会来的卢俊义。所谓预言的后面，已经明写有人主动准备它将出现的场面。[本L34—40／原L6787—6793](00_正文.txt#L34)

<a id="story-household"></a>
### 看得出危险的人，没有决定出行的权力

卢算卦后“寸心如割，坐立不安”，次晓召主管议事。为头的李固是东京人，早年来北京投相识不着，冻倒卢门前，被卢救活留养；因勤谨、会写会算，五年内升成都管，掌里外家私，手下有四五十行财管干。卢又特地问另一个未到的心腹，燕青随后登场。燕是北京本地人，父母早亡，由卢家养大，约二十四五岁；卢还请高手为他刺遍体花绣。叙述逐项写他吹弹歌舞、文字游戏、方言与行业市语、川弩射猎和射赛本领，又用《沁园春》赞其英武、聪慧与艺苑声誉。[本L42—48／原L6795—6801](00_正文.txt#L42) 射猎所得的“虫蚁”在这里是小鸟雀；“小乙”是对排行第一年轻男子的俗称，不能按字面读作射虫或排行第二。[注本L9—21／原L6891—6903](00_注释.txt#L9)

众人到厅，李固左立、燕青右立。卢把东南千里选成泰安州东岳庙：一去烧香消灾，二躲灾，三兼做买卖、看看外方景致。他命李固备十辆太平车装山东货物，随自己走；燕青当日接库房钥匙，留家看守，三日内便动身。李固先劝别听卖卦的转回说话，在家不必怕；卢回答命中注定，不能逆他。[本L50／原L6803](00_正文.txt#L50)

燕青的反对更具体：去泰安须经梁山，官兵都近不得；“倒敢是梁山泊歹人”假扮阴阳人，要赚主人落草。他明说昨夜不在家，否则可以盘倒那先生。这是据路程、局势和主人转述作的判断，恰与读者已见的骗局相合。卢却把话转到自身武艺：谁敢骗他，梁山贼如同草芥，正好捉来显扬本事。[本L50／原L6803](00_正文.txt#L50)

贾氏从屏风后出来，说已经听了多时，劝丈夫别撇下大家业，冒险到虎穴龙潭做买卖，宜在家清静。叙述交代她二十五岁、嫁来五年，夫妻“琴瑟谐和”；此刻她的意见仍被“你妇人家省得甚么”挡了回去。卢以“宁可信其有”及术士祸言为理由，坚持主意，禁众人再说。燕青又转而求陪行，愿以所学棒法护送，留下李固；卢解释自己不省买卖，须靠李固分劳，燕只做桩主，另有人管账。李固再称脚气走不得多路，卢认作推故，以“养兵千日，用在一朝”相责，威胁再拦便尝拳头。李吓得面如土色，众人散去。劝阻失败之后，执行并不等于心服。[本L52—56／原L6805—6809](00_正文.txt#L52)

<a id="story-caravan"></a>
### 商旅仍有安排，捉贼却要所有人同担风险

李固忍气筹好十车、十脚夫和四五十拽车牲畜，装扎行李货物。第三日，家中烧神福给散，卢逐个分嘱大男小女，当晚先叫李固带两个当直出城，贾氏看着车仗流泪。次日五更卢沐浴换衣、取器械、辞祖先香火，戴毡笠，悬钢刀，提棍棒；赞棒诗把这条棒比作无牙爪的秃尾龙，给出他携技出门的气势。临别他许多则三个月、少则四五十日回来，贾嘱小心、常寄信；他又嘱燕青尽心看家，不要去三瓦两舍打哄，燕答不敢偷闲。[本L56—66／原L6809—6819](00_正文.txt#L56)

出城后，卢让李固带两伴先寻干净客店、做饭等车队，自己与数个当直押车随后。行四十余里午食，再四五十里宿食，次早继续；他见山水而欢喜，觉得在家哪里见得到这些景致。这里有车脚夫的劳作与等候，也有主人实际安排宿食、借重李固生意本领的一面，并非整段旅途都只剩恐惧。[本L68／原L6821](00_正文.txt#L68)

数日后，另一家客店的小二提醒，不到二十里就要经梁山边口。他说宋公明虽不害来往客人，仍须悄悄过，不要惊动。卢偏取出衣箱包袱里四面白绢旗，向店家讨竹竿竖起；旗上诗自报名姓，写“一心只要捉强人，那时方表男儿志”。小二起初问是否与宋大王有亲，得知他要捉宋，便求低声，免连累自己，又说即使万人也近不得。卢反骂他们和贼一路。小二叫苦，众车脚夫惊呆，李固跪地求主人顾惜众命。[本L70—76／原L6823—6829](00_正文.txt#L70)

卢却以鸿鹄自许，用燕雀贬低对手，说平生本事不曾遇到“买主”，今日正可“发卖”。他还说车上已备一袋熟麻索，打算自己砍倒强人，让众人缚上车，宁抛货物也要押贼首进京请功；最后更说，不肯去的便先杀。四车在前插旗、六车随后，李固众人哭着“只得依他”。卢装朴刀上杆棒，催车向梁山而去，个人的扬武愿望由此成为全队无法退出的危险。[本L76—78／原L6829—6831](00_正文.txt#L76)

<a id="story-land"></a>
### 步斗仍健，人车却离他越来越远

巳牌近林，哨声响起，前后各四五百喽啰截路。卢让车仗停旁边，车夫躲到车底叫苦，他仍叫众人等自己搠翻强人再来绑。李逵持双斧跳出，形貌骈写和黑旋风诗极力渲染其凶猛。他问卢可认得“哑道童”，卢这才“猛省”。李明告中了军师计，请上山坐交椅；卢反要宋江下山投拜。[本L78—88／原L6831—6841](00_正文.txt#L78)

接战有清楚的接力。李逵不到三合便走，入林东闪西躲，逗得卢追深后不见；卢要回身，鲁智深持铁禅杖出现，称奉哥哥将令来迎接，短战又退；武松持双戒刀从喽啰中出来，卢舍鲁转斗武松，武也不到三合退去。卢大笑这些人不足道。刘唐继而在山坡喊出“哥哥定下的计策”，卢攻刘，穆弘来帮，李应又从背后加入，三人丁字脚围斗。叙述明说卢“全然不慌，越斗越健”，但山顶一锣，三人各卖破绽一齐退走；卢汗出不再赶，回林边找车，人伴、头口和十辆车都不见了。这里先后接战的是李逵、鲁智深、武松、刘唐、穆弘、李应六人，进退又受计策和锣号控制，不能把这些退走直接算成诸将战力不及卢。[本L88／原L6841](00_正文.txt#L88)

夹诗说他“暗里机谋不自由”，把此行比成吞下水浒的钓鱼钩。卢登高望见喽啰赶车畜在前，把李固一干人串缚在后，鸣锣擂鼓押走，立即追去。朱仝、雷横拦路，朱再说中了军师妙计，请上大寨；二人短战便退。卢想着“须是赶翻一个，却才讨得车仗”，拼命追转山坡。到这一步，推动他的除了好斗，还有人车被夺后的追讨。[本L90—94／原L6843—6847](00_正文.txt#L90)

山顶鼓板吹箫，杏黄旗绣“替天行道”，红罗销金伞下是宋江，吴用左、公孙胜右，二百余部从齐声问候。卢越怒，吴用则称宋久慕清德威名，特派自己到门下，“赚员外上山”，邀同替天行道，并请勿怪。这番解释没有换来同意。花荣从宋背后出来，先喝止逞能，再一箭射中卢毡笠红缨，惊得他回身便走；秦明、林冲从东山领军出，呼延灼、徐宁从西山领军出，呐喊逼得他无路。天色将晚，卢脚疼腹饥，只顾走偏僻小径，约黄昏到了鸭嘴滩，见满目芦花烟水，才叹“不听好人言”。[本L94／原L6847](00_正文.txt#L94)

<a id="story-water"></a>
### 求来一条渡船，最后失去的是立足处

芦苇中出来一个渔人，随之的八句诗写野渡、沽酒、全家乐、看山眠和水中月影，先铺出闲适的水乡生活。渔人问卢怎敢到梁山出没处，卢承认迷路，求人救助。对方说陆路到市井须三十余里，又杂而难认，水路只三五里，索十贯便渡。卢许若寻得客店便多给银；渔人靠岸，扶他下船，撑开水面。求宿者接受的这只船，接着成了新的包围之处。[本L94—104／原L6847—6857](00_正文.txt#L94)

行三五里，前方芦苇中先来一船，两人分前后，前者赤身持篙，后者摇橹。歌里唱“准备窝弓射猛虎，安排香饵钓鳌鱼”，卢惊得不敢出声。右边又来一船，仍是前持篙唱、后摇橹，歌词已直指“一心要捉玉麒麟”，卢只能叫苦。中间第三船赶来，船头人倒提铁锁木篙，唱的正是他在家写壁的那首卦歌。三船唱喏，叙述才点明中间阮小二、左阮小五、右阮小七，一齐撞来。两侧还有实际摇橹的无名人，水上圈套不只靠三阮三人完成。[本L104—122／原L6857—6875](00_正文.txt#L104)

卢自想不识水性，连叫渔人快靠岸。渔人却大笑揭名：自己是从浔阳江来梁山的混江龙李俊，若不降便送命。卢大惊，喝“不是你，便是我”，拿朴刀直搠李俊心窝。李拿棹牌翻身入水，船滴溜溜地转，朴刀又搠入水；张顺随即从船尾水底钻出，挟船梢、踏水浪，把船一侧，“船底朝天，英雄落水”。卢仍在反击，张顺却从水下侧翻了他立足的船；故事以两问性命收住。[本L122／原L6875](00_正文.txt#L122)

## 这场“赚”怎样改变了人物处境

<a id="analysis-divination"></a>
### 吴用把灾难与避灾办法一起交给卢

卢并不是听见灾言就全盘相信。他先以自身谨慎和家世作反驳，真正改变双方位置的是吴“急取原银付还，起身便走”：此后，质疑先生被说成拒听忠言，卢反而收回反驳，求对方别隐瞒。更早的一两高价也已被他当作有广学的凭据。卢先礼请、付资，吴则用灾言、算具和不肯阿谀的姿态取得信任；动作方向必须如此看，才能明白骗局为何由卢自己开门接受。[本L30、34／原L6783、6787](00_正文.txt#L30)

让人恐惧的百日死期，与看似可行的东南千里解法，都出自同一人口中。吴离城便说回寨设机关，陆路众将又明言中计、奉令，足见本回所谓“应验”中有人为铺设的部分。到水上，卦歌由家中白壁转为包围者口中的歌，前两舟又先唱钓鳌、再指玉麒麟，救命答案一层层显出诱捕用途。[本L34—40、88、106—122／原L6787—6793、6841、6859—6875](00_正文.txt#L34)

四句首字“芦、俊、义、反”，又可据“芦”“卢”同音读出“卢俊义反”的方向。这是字面可见的文字机关；本回没有人物公开拆说，也没写壁字被拿来控告。值得保留的正是卢亲写、四句留下、水上复唱这一条线，后续效力仍待正文回答。[本L34—40、118—122／原L6787—6793、6871—6875](00_正文.txt#L34)

### 卢的判断失误，与他的武勇都写得很实

卢能怕命数，也能安排旅途；知道自己不懂买卖，便要用李固的长处。他的问题不在于处处全无判断，而在梁山这个具体风险前，过信武艺能够换来进退自由：先把商旅改成捉贼请赏，继而用杀人威胁迫同行者承担后果，再把短战退让当成对手不足道。叙述承认他越斗越健，局势却让他失车、追车、失路、饥疲，最后落到自己不识的水上。武勇的真实性与判断的失准，在这里互相衬出。[本L50、54、68、76、88、94、122／原L6803、6807、6821、6829、6841、6847、6875](00_正文.txt#L50)

燕青恰好构成另一面。他有语言、市井和技艺经验，又被写得“百伶百俐”，但提出梁山伪装说时仍用“倒敢是”，承认昨夜不在场；这份判断既敏锐，也有知情边界。他先劝不走，再请自己护送，始终没能改变家主的决定。李固、燕青同受卢家救养，却各有买卖、守家的分工；贾氏虽是“琴瑟谐和”的妻子，也因妇人身份被挡回意见。家内的养育、信任和权力差等一同起作用，聪明与亲近都没有自动变成决定权。[本L42—54／原L6795—6807](00_正文.txt#L42)

### 礼貌、忠义声名与强迫，可以出现在同一行动里

开篇词赞吴“殚竭忠诚”，把玉麟归伏先写在赞语中；卢与燕的出场词也先盛写英雄才艺，连燕的“梁山上端的驰名”都超出了本回留守家中的现场。叙述还以天罡合聚解释卢请相者的机会。可是夹诗又明说“不自由”，回末更以“铺排打凤牢龙计，坑陷惊天动地人”写落水。这些声音共同组成了本回：赞许组织本领与英雄聚合，并没有消去被赚者的拒绝、愤怒和身体危机。[本L6、30—32、48、90—94、122／原L6759、6783—6785、6801、6843—6847、6875](00_正文.txt#L6)

山顶称兄长、唱喏、请勿怪罪，继之以射缨和军马驱逼；水上扶人登船的援手，继之以不降便死的威胁。礼貌的外形与控制行动相接，有具体前后动作可查。受影响者也不仅是卢：北京城外小二已经吐血，临泊小二怕被连累，车脚夫先被主人威胁、后见人伴被缚押，家中燕青、贾氏则留在尚未再写到的等待中。吴的善后钱、卢往日救养家人，以及梁山的慕名，都不能替这些人抵销当下后果。[本L12、42、46、52—62、70—78、94、104、122／原L6765、6795、6799、6805—6815、6823—6831、6847、6857、6875](00_正文.txt#L12)

到本回结束，已经确定的是卢落水、李固一干人被押、车畜受梁山控制；落水后的性命、这次招人的结局，被拘者的释放与货物终处置，都还未写。贾氏求信、卢许归期、燕青接钥匙留守也仍停在出门时的交代。题中的“金沙渡”、送行的金沙滩和末路的鸭嘴滩各保留原称，不先将它们定为同一地点。[本L1、10、50—62、88、94、122／原L6754、6763、6803—6815、6841、6847、6875](00_正文.txt#L1)
