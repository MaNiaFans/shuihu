# 第四十九回：捕虎的人怎样被逼入牢，救亲的人怎样走向梁山

解珍、解宝奉官限捕到老虎，本应带虎交差，却被毛家夺去猎物、倒诬抢劫，拷打成招后关进死囚牢。救他们的力量从一个小牢子的通风报信开始，经顾大嫂、孙新、邹氏叔侄逐步聚合，又用假病和刀逼，把军官孙立及妻子卷了进来。兄弟终于获救，但事情没有停在脱险：众人返庄杀尽毛家老小，取财焚庄，沿途又夺庄户马匹。到了投梁山的门前，孙立再把自己同栾廷玉的师门关系变成可献的破庄计。救亲、强迫、复仇和求取功劳，就这样连成一条路。（[正文L20—104](00_正文.txt#L20)）

<a id="story"></a>
## 从捕虎交差到死囚牢

本回开头仍接着祝家庄战事。吴用对宋江说，已有来投者献出计策，五日之内可行，宋江才从忧愁转为欢喜。说书人暂不揭计，转去讲登州一件与初打祝家庄同时发生的事；到回末才让两条线合拢。因此，读者先看见献计的希望，再回头看这群人怎样走到这里。（[正文L8—10、96—100](00_正文.txt#L8)）

登州山上多有猛兽出来伤人，知府给猎户下杖限，山前山后的里正也必须交虎，过期便受责枷号。解珍、解宝是当地出众的猎户：哥哥号两头蛇，弟弟号双尾蝎，都是七尺以上的大汉，父母已亡，尚未婚娶，均使浑铁点钢叉。兄弟的武艺得到猎户推服，处境却仍受官府期限支配；他们担心的正是“三日内要纳大虫”，迟了便要吃责。（[正文L10—20](00_正文.txt#L10)）

两人带窝弓、药箭等上山，先守一日无获，次日又携干粮夜候，移弓西山仍等不到。第三夜疲倦欲睡，忽然听见窝弓发响，一只虎中了药箭。他们持叉追赶，虎因药力滚下山，解宝认出下面是毛太公庄后园。天刚亮，兄弟便去毛庄求借路取虎。叙述写第三夜伏至四更，解珍向毛家复述时说“今早五更射得”；照两种表述理解其先后即可，不必替故事另外校出一个统一时刻。（[正文L20—22](00_正文.txt#L20)）

毛太公初时十分客气。兄弟放下钢叉，行礼称“伯伯”，解珍说明官限和虎的落处；毛称“贤侄”，说取虎不妨，却先留他们吃早饭。吃罢再次求取，又被劝坐喝茶。二人“不敢相违”，等到茶毕，太公才带他们到后园。庄客拿钥匙开不开锁，太公说怕是锁簧久锈，又叫铁锤来敲开。众人入园，却不见虎。（[正文L22—24](00_正文.txt#L22)）

<a id="tiger-dispute"></a>
毛太公先怀疑兄弟看错，解珍坚持自己在此生长，怎会不认得地方；毛这才说：“你自寻便了，有时自抬去。”解宝随后指出草被滚倒、上面还有血路，认为必是毛家庄客抬了虎。太公却以刚刚当面敲锁、共同入园为理由反驳。解宝点出毛家也在当里正、受着捕虎文书，指责其想拿现成虎邀功，反让兄弟吃限棒。这里毛家的里正身份是解宝当场说出的，争执的核心则很清楚：谁拿虎去交差，谁就免受限责。（[正文L24](00_正文.txt#L24)）

毛太公从劝饭的长辈转成喝骂者，说“你吃限棒，干我甚事”，又骂二人为“教化头”，不许随意搜家。解宝搜不见虎，先在厅前打砸；解珍也搬折阑干，二人打坏桌椅。毛大叫白昼抢劫，兄弟见庄上已有准备，才退到门外，扬言告官。毁物是他们确实做过的；抢掳财物却是毛家后来加上的罪名，不能混为一件事。（[正文L24](00_正文.txt#L24)）

正骂时，毛仲义带骑马者和伴当回来。他听解珍申诉，假称父亲必被村人瞒过，答应领二人进去讨还。兄弟谢过再入庄，门立刻关上；毛仲义一声“下手”，两廊二三十名庄客与马后带来的做公人齐出，绑住猝不及防的二解。他转口说虎是毛家昨夜自射的，二人却来赖虎抢财，要将他们解州除害。（[正文L30](00_正文.txt#L30)）

叙述到此补明，毛仲义五更已经先把虎送到州里，随后带做公的来捕人。毛太公把钢叉、一包称为“赃物”的东西及打碎家什一同押送，又将兄弟剥光反绑。州中六案孔目王正是毛家女婿，早向知府禀说；二人到厅便遭刑讯，受拷不过，只得依“混赖大虫”“抢掳财物”的话招认。知府命戴各重二十五斤的死囚枷，钉入大牢。这是刑讯成招和死囚拘押，正文未另交代正式判决程序。（[正文L32](00_正文.txt#L32)）

毛氏父子仍不放心，又回州嘱王正斩草除根，自称另去替知府“打关节”。牢中节级包吉已经收毛家银两、听王正的话要害二解，一见面便借绰号恐吓，要将两头蛇变一头蛇、双尾蝎变单尾蝎。州厅把兄弟关进牢后，毛家的私下灭口安排仍在继续。（[正文L32—34](00_正文.txt#L32)）

## 一封消息怎样聚成一支救人队伍

带二解入牢的小牢子趁无人问他们认不认得自己，说是“你哥哥的妻舅”。解珍先答只有亲兄弟两个；对方说出孙提辖，他才想到姑舅哥哥，猜出这位未曾见过的亲戚是乐和。乐和自述祖贯茅州、先祖迁来，姐姐嫁孙提辖，自己在州做小牢子，因唱得好号铁叫子，又从姐夫学过枪法。叙述另写他通乐品、聪慧、爱武艺，见二解是好汉便有心救，只是独力难成。（[正文L36—42](00_正文.txt#L36)）

乐和把包吉受钱害命的危险说给兄弟，解珍请他暗中报顾大嫂。顾是他所说父系房分上的姐姐、姑母的女儿，嫁给孙新；孙立、孙新则是解氏母亲这边的姑舅哥哥。亲戚不少，解珍偏偏点顾，因为“只有那个姐姐和我弟兄两个最好”，而且她有三二十人近不得的本事，连丈夫也输她。乐和应下，先取烧饼肉食给二人，再借故让别的小节级看门，才出城往十里牌。（[正文L42](00_正文.txt#L42)；“爷面上的”“姑娘”词义见[注释L7、9](00_注释.txt#L7)）

顾大嫂的酒店前挂牛羊肉，后屋聚赌，她坐在柜上。乐和入店，顾先问沽酒、买肉还是赌钱，听见他姓名后，认出面貌像嫂嫂，才迎入拜茶。乐和讲明夺虎、强扭为贼及牢中害命，说自己既为亲缘也为义气来报，单人难救。顾叫苦，立刻遣火家找回孙新，再将事由告诉丈夫。（[正文L42—46](00_正文.txt#L42)）

孙新号小尉迟，祖贯琼州，出身军官人家，因调来登州驻扎而在此定家，学得哥哥的鞭枪本事。他请乐和先回牢照看，夫妻另商长策。顾置酒款待，又交一包金银，请乐和散给狱中众人和小牢子，周全兄弟；乐和带回使用。夫妻私下谈时，孙新认为毛家有钱有势，必不让二解活着出来，只能劫牢。顾说当夜便去，他却笑她粗卤：人救出以后，还须有去向，有哥哥和另外两位帮手才行。（[正文L48—58](00_正文.txt#L48)）

这两位是登云山聚众打劫的邹渊、邹润，与孙新相好。顾让丈夫去请，自己命火家杀猪备宴。黄昏二人来到：邹渊号出林龙，莱州闲汉出身，好赌，有武艺，叙述一面称其忠良慷慨，一面写气性高强、不肯容人；邹润是侄子，年纪却与叔叔相仿，脑后肉瘤使他得独角龙之号，撞折松树则是另插的旧事。（[正文L58—70](00_正文.txt#L58)）

顾说完求救经过，邹渊指出山上虽有八九十人，心腹只有二十来个；干成此事，登州便不能安身。他早有投梁山之心，那里有杨林、邓飞、石勇三个相识，便提议救人后一道去。顾只求救出兄弟，去哪里都肯，又说谁不去便乱枪戳死。邹润补问登州军马追来怎么办，孙新才把最难的一环提出：哥哥孙立是本州提辖，他说几次草寇临城都是哥哥杀散，必须使他应允。众人饮至半夜，次晨派火家带一两人推车入营，假报顾病重，请哥嫂来；顾还追加“临危”和只有一番相见嘱付的话催促，孙新则在门前候接。（[正文L72](00_正文.txt#L72)）

<a id="sun-li"></a>
## 假病、刀逼与孙立的转向

饭后，乐大娘子乘车，孙立骑马，十数军汉跟来。孙立号病尉迟，八尺以上，善鞭枪弓马，是一名已有威名的军官。孙新先让火家请军汉去对门店喝酒、牵去马匹，再领哥嫂入内，等候后说去看病。二人进房却不见病人；顾大嫂这才和邹氏进来，说自己害的是“救兄弟的病”。她质问孙立怎会不知道二解是自家兄弟，孙立先称“我并不知因由”，顾随后将陷害、劫牢、投梁山的已定计划当面说明。可以确定他在这里被明白告知，不能只凭双方问答就判其此前确无听闻，或早已知而装聋。（[正文L74—84](00_正文.txt#L74)）

顾先以事发连累相劝：走的人倒没事，留在原处的亲人要替他们吃官司，“近火先焦”。这是她为说动孙立提出的风险判断。孙立以“我是登州的军官，怎地敢做这等事”拒绝，她便说先同他拼个死活，掣出双刀，邹氏也各拔短刀。孙立叫她稍缓，乐大娘子已经惊得半晌不能出声。顾又以先送“姆姆前行”继续逼迫；孙立提出回家收行李、看虚实，她仍不肯放他回去，说劫牢、取行李一并做就行。（[正文L84](00_正文.txt#L84)）

孙立叹气，认为众人既已如此，自己推不开，也不愿日后独替他们吃官司，连说三声“罢”，答应共议。应允之后，实际派遣的就是他：先叫邹渊回寨收财物、带二十个心腹来，再遣孙新入城找乐和讨信、约会，暗通二解。次日邹寨人手到齐，连孙家七八名心腹火家、孙立带来的十数军汉，共四十余人。孙新宰猪羊使大家饱食，顾贴肉藏刀扮作送饭妇人先走；孙氏、邹氏带人分两路入城。军汉和火家没有逐人表态的场面，不能把列入队伍写成人人自愿落草。（[正文L84—86](00_正文.txt#L84)）

<a id="prison-rescue"></a>
## 内外接应救出兄弟，出城以后再决定报仇

乐和守在狮子口里，听铃认得顾，开门放她入来，又关门带她过廊。包吉不许妇人进去探囚，喝令牢子代送饭。乐和便取饭开囚室，二解问夜里所约的事怎样，他说姐姐已入，只等前后相应，并替他们开了匣床。外面小牢子报孙提辖敲门，包吉不肯开；再报孙焦躁打门，包吉才怒而下亭。顾已转到亭旁，拔刀大叫问兄弟所在。（[正文L92](00_正文.txt#L92)）

包吉逃走，迎面碰上提枷钻出牢眼的二解，被解宝一枷梢打得脑盖粉碎。乐和打开的是匣床，兄弟仍有枷可用；不能把这一环写成已经卸枷。顾另刺倒三五个小牢子，众人发喊冲出；“戳翻”写明杀伤，却没有逐人的最终伤亡名单。孙立、孙新把住牢门，接出顾、乐、二解四人；邹氏则已从州衙提出王正首级，具体入衙和斩首分工未另展开。（[正文L92](00_正文.txt#L92)）

街市大喊，行人奔出城，住户关门不敢出来。孙立骑马弯弓搭箭压后，做公的人认出提辖，谁也不敢拦。众人出城到十里牌，扶乐大娘子上车，顾大嫂上马，才继续赶路。救人能成，既有乐和的牢内接应，也有顾与二解的近身杀伤、孙氏守门和旧官身的威慑，衙门方向还有邹氏配合。（[正文L92](00_正文.txt#L92)）

<a id="revenge"></a>
已经脱出城后，二解提议不能不报毛太公之仇，孙立答“说得是”，让孙新、乐和护车先行，自己率二解、邹氏及火家伴当奔毛庄。毛父子正在庆寿饮酒，毫无提防。来人杀入，将毛太公、毛仲义以及“一门老小尽皆杀了，不留一个”。随后搜得十数包金银，牵七八匹马，用其中四匹驮载；二解挑好衣服穿，众人焚庄而去。不到三十里赶上车仗，一路又从庄户家“夺得三五匹好马”，星夜往梁山。（[正文L94](00_正文.txt#L94)）

这一段的受害范围远大于毛氏父子。毛家老小没有被逐个写为夺虎、诬告或买凶者，沿途庄户更没有已写出的共谋关系。兄弟受冤与得救是事实，返庄灭门、取财焚庄和夺别家马也是事实；它们须同时留在这次英雄脱险的经过中。（[正文L32—34、92—94](00_正文.txt#L32)）

<a id="offered-plan"></a>
## 八人投托，把熟人关系变成破庄计

不一二日，一行到石勇酒店，邹渊相认后打听杨林、邓飞。石勇说宋江两次攻庄失利，二人都跟去，“听得报来说”俱陷在那里，又说“不知如何”；这是消息的转报，不是他亲见二人当前受审、羁押或脱身。他另说祝氏三子豪杰，还有教师铁棒栾廷玉相助。（[正文L96](00_正文.txt#L96)）

孙立听后大笑，说众人投寨“正没半分功劳”，不如献破庄计作为“进身之报”。他自陈与栾廷玉同师，彼此武艺尽知，可以假作由登州对调郓州、途经探望的军官，料栾必出迎，入内后与梁山里应外合。这是借官军身份和同门信任进庄的计划，栾怎样实际回应尚未写出。（[正文L96](00_正文.txt#L96)）

正谈时，小校报吴用下山救应，石勇急命请来，随即吕方、郭盛、阮氏三雄与吴用五百人马到店。石勇引见、说明投托献计，吴用大喜，请他们暂不上山，先成这段功劳；新来者皆允，议定吴军先行、他们随后。这正是上回已写抵达宋营的那拨援军，本回补叙其途中会店得计，并没有另来五百人。（[正文L96—98](00_正文.txt#L96)；[第四十八回L78](../第048回/00_正文.txt#L78)）

吴用先入宋营，把八人来投、孙栾同师及里应外合之计告诉宋江，宋江释愁设宴。孙立安顿伴当、车仗，只与孙新、顾大嫂、解珍、解宝、邹渊、邹润、乐和，合计八人来见。乐大娘子及其余随从不在这八人名单中。受宴后，吴用暗授第三日、第五日怎样行，八人领计，复与车仗人马往祝家庄“进身行事”。因此计策已经接纳、部署并开始赴庄；假扮来访怎样实施、栾的迎接、内外接应及破庄结果，正文尚未展示。（[正文L98—100](00_正文.txt#L98)）

吴用末了又命戴宗回山取四个头领，说另有用处，四人姓名和实际取到、用途仍留待下文。回末许诺“打破了祝家庄，壮观得梁山泊”，是预告，不能提前算成本回战果。（[正文L102—104](00_正文.txt#L102)）

<a id="official-net"></a>
## 虎、供词与门锁：有本领的人为什么仍会受制

在山上，钢叉、药箭和守候让二解取得虎；进入庄园和州厅，这些本领却不能保护他们。虎是免限责的凭证，谁先控制实物、先向官府给出解释，谁就能占据有利位置。毛家把真实的毁物、二解所携钢叉与所谓“赃物”一起押送，王正先禀，州厅再用刑逼出承认，最后包吉在牢中接续害命。私人庄园的控制、姻亲的官府位置与狱中受赂，构成了连续的压迫。（[正文L20—34](00_正文.txt#L20)）

毛家的客气也是这条链的一部分。酒饭、茶和“贤侄”使二解两次求取后仍坐着等；毛仲义的“讨还你便了”更把已退出的人重新引进门。连读后来揭明的先送虎、带公人布局，可理解为有意拖住并控制兄弟。不过，正文没有给出每次茶饭与运虎的精确时刻对应，不必替骗局补造“专等虎运完”的内心和路线。（[正文L22—32](00_正文.txt#L22)）

<a id="kinship-force"></a>
## 亲缘能够救人，也能够用来逼人

乐和首先有救好汉的心，却承认“单丝不成线，孤掌岂能鸣”。他不是一报信便退出：认亲、送食、托人看门、出城传话、带银回来使用、按约开门、开匣床，每一步都让狱内外的人能接上。诗说“乐和不去通关节，怎得牢城铁瓮开”，点的正是这份有限职位与亲身周旋。毛家用钱谋害，顾用钱周全，同一牢务关系能被相反目的使用；成功也不等于全体牢子都已知谋或赞同。（[正文L36—56、84、88—92](00_正文.txt#L36)）

亲缘本身还须辨认和说明。解珍先不明白“哥哥的妻舅”，顾也多年未与乐和相会；称谓、姓名和相貌才将既有关系变成当下可用的联系。顾是解氏父亲这边的房分姐姐，二孙是解氏母亲这边的姑舅哥哥，方向要随解珍的说法读。更起决定作用的是“最好”：他相信顾会来，顾听后也确实立即行动。乐和明说亲缘之外还有义气，不能把他全部行动只归为亲戚义务。（[正文L36—46](00_正文.txt#L36)）

顾的急迫和孙新的筹划互相补足。她先要救人，去处可以随人；孙新不断补进帮手、退路和追兵，邹润的问题又让孙立成为必须争取的人。可是到了哥哥这里，亲缘也被改作共同承担风险的理由，最后直接由刀来强迫。乐大娘子原是来探病的人，却在丈夫受逼时惊得失声；顾在持刀场面里又说先送她“前行”，明显继续施压。本句未明说目的地或杀害，不能擅断为已经害妻，也不能弱化成普通的温和护送。（[正文L58、72、84](00_正文.txt#L58)）

孙立的变化尤其需要两面都看。他起初不愿以军官身份劫牢，最后因推不开和怕连累而答应；此后却亲自遣人、以官身护逃、认可返庄复仇，并主动向梁山献计。他既不是从头自愿谋劫，也不是直到结尾仍只有被动。所处压力与后来做出的行动，共同构成这一回的孙立。（[正文L84—100](00_正文.txt#L84)）

## “英雄”的称赞，与救人以后发生的事

开篇词说“夺虎机谋可恶，劫牢计策堪观”，各人的赞诗又以忠良、英豪、武勇为他们定调；顾的赞语甚至以打丈夫、伤庄客的惯常动作突出其母大虫气势。这些是叙述的评价方式，不等于当日每个比喻动作都实际发生。邹渊既被写成“不肯容人”，又获诗赞“度量宽如海”，也提醒读者：赞体为人物增添声势，具体行为仍须逐段辨认。（[正文L6、14、18、44、60—64](00_正文.txt#L6)）

救人之后的毛庄一段，使这层辨认尤其必要。包吉、王正、毛氏父子在陷害链中的责任各有依据，毛家其余老小却没有逐人同罪的叙述；街坊只留下奔逃闭户，别处庄户则失去马匹。将这些人保留下来，并不撤销二解受冤或乐和救人的事实，而是让“劫牢计策堪观”之外的全部后果仍可看见。旧官身帮助众人出城，官府受害者随后又能对别人施加武力，这种变化比单用“被逼上梁山”更能说明本回的复杂经过。（[正文L32—34、92—94](00_正文.txt#L32)）

到了梁山门前，同样的“关系能开门”再次出现。邹渊的熟人使一行先到石勇面前，孙立再把与栾同门的熟悉变成可献的资本。吴用接受其计，并商议先功后上山；这说明此番投托怎样与当前战事结合，尚不是一条无功者一律不得入伙的制度。篇末把新来的八人与两次失利的主军接在一起，既补出上一回所许的机会，也把真正的检验留在他们已经前往、而读者尚未见到的祝家庄里。（[正文L72、96—104](00_正文.txt#L72)）
