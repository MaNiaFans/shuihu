# 第六十三回：救人之兵围住北京，解围之计却指向梁山

<a id="custody"></a>
## 被截下刑场的人，又进了死囚牢

石秀从法场拖走卢俊义，终究没有把人救出北京。两人在城内无路可走，公人用挠钩搭住、套索绊倒，一并押到梁中书面前。石秀仍在厅下高声辱骂，说梁山军早晚会来，自己只是奉哥哥将令先作通报。厅上众人被骂得发呆，梁中书沉吟后命取大枷，将二人收入死囚牢。这一刻，石秀的勇救保住了卢俊义的眼前刀下性命，却使自己也成了囚徒。（“两个当下尽被捉了”；[本L24／原L7073](00_正文.txt#L24)）

牢内的实际处境比“死囚”二字稍有转机。蔡福“要结识梁山泊好汉”，把二人关在一处，每日给好酒好肉，叙述说他们“不曾吃苦，倒将养得好了”。这是有结交意图的照顾，也是二人眼下实得的好处；它说明待遇改善，不替卢俊义此前的刑伤作全部痊愈的诊断。上一回的刑逼、杖配仍是已经发生的伤害。（[本L24／原L7073](00_正文.txt#L24)；前伤见[62本L32、70／原L6944、6982](../第062回/00_正文.txt#L32)）

城里的损失也被点出。梁中书叫新任王太守计点，杀死的有七八十人，跌伤、磕伤、撞折腿脚者不计其数；报名后，由梁中书支官钱医治、烧化。这里是一次变乱后的汇总，没有逐人列身份或加害经过，不能把七八十人全认作石秀亲手杀死的官军，也不能全改写成平民。官钱处理了医疗和遗体，却没有使这些死伤从故事中消失。（[本L26／原L7075](00_正文.txt#L26)）

次日，城内外呈上数十张“没头帖子”。文告以“梁山泊义士宋江”名义发话，声讨滥官污吏，声称卢俊义是受请上山、石秀是先来报知，接着提出条件：保住二人，交出“淫妇奸夫”，便“吾无侵扰”；如伤二人，则兴兵雪恨，“人兵到处，玉石俱焚”。末尾又安抚义夫节妇、孝子顺孙、好义良民和清慎官吏，各安职业。所谓“淫妇奸夫”，接前回妻仆出首的情节，指向李固和卢妻贾氏；本回没有写他们被交出或受惩。（[本L28／原L7077](00_正文.txt#L28)；姓名与出首见[62本L30—32／原L6942—6944](../第062回/00_正文.txt#L30)）

梁中书看得惊惧，找王太守议处。叙述称王“善懦”，他提出的办法却很具体：暂留二囚性命，一面申奏朝廷，一面报蔡太师，再让本处军马出城下寨。他担心的不止梁山来攻，还包括救兵不及、朝廷见怪、百姓惊慌与城中扰乱。梁认为有理，转而嘱咐蔡福：关得太紧怕囚犯丧命，放得太松又怕走脱，要“可紧可慢”，牢固候令。命令所称“你弟兄两个”可承接前回已具名的蔡福、蔡庆；暗喜、回牢安慰的动作，本回仍单写蔡福。（[本L30／原L7079](00_正文.txt#L30)；蔡庆身份见[62本L52、68／原L6964、6980](../第062回/00_正文.txt#L52)）

<a id="mobilization"></a>
## 一边出城设寨，一边把救人变成大举进兵

官府先行动起来。梁中书向兵马都监大刀闻达、天王李成说明告示与王太守的意见。李成自请领军离城，声称梁山若来，必使其片甲不回，以报国家俸禄之恩。梁大喜，赏二将金碗绣段。李成次日升帐，命急先锋索超先去城外三十五里；索超再于次日抵飞虎峪，靠山立寨。随后李成率正偏将驻离城二十五里的槐树坡，布枪刀、鹿角，三面掘陷坑。官军确有防御准备，轻敌的言语与扎实的寨栅同时存在。（[本L32—38／原L7081—7087](00_正文.txt#L32)）

叙事这才转回梁山，揭明告示出于戴宗。他打听到卢、石同被捕，为保二人性命而“虚写告示”，在无人处撇下，又贴放桥梁道路，再回山详报。署名宋江、实际写置者戴宗，是两层不同的事实。石秀当庭所说的奉令先报，也不能据此变成已经核实的预授劫场命令：上一回杨雄说二人受命“打听”，听燕青报告后才临时分路，杨、燕报山，石秀独自赴京遇上行刑。（[本L40／原L7089](00_正文.txt#L40)；前次消息与分路见[62本L104—110／原L7016—7022](../第062回/00_正文.txt#L104)）

戴宗带回的新消息是二人都落入官府手里。宋江大惊，打鼓集众；“大小头领各依次序而坐”是叙述交代，没有列出新的逐名席位。宋江对吴用说，当初好意请卢上山，如今反使他受苦，又陷了石秀，问怎样救人。这是宋江对请人动机的自我说明；前回众人轮宴、李逵与朱武以出事相逼，卢“抑众人不过”，强留后才获放归的经过仍须保留。眼下的救援不能倒过来把那次羁留写成卢自愿赴义。（[本L40／原L7089](00_正文.txt#L40)；[62本L18—26／原L6930—6938](../第062回/00_正文.txt#L18)）

吴用的回答把目标向外推了一层：“乘此机会，就取北京钱粮，以供山寨之用。”他建议留部分头领守山，其余出兵，宋江同意，唤裴宣派拨军卒。李逵请五百人先去，既要救卢、石，又要将梁中书、李固和贾氏碎尸。宋江提醒北京不同寻常，梁是蔡太师女婿，手下李成、闻达有勇，不可轻敌；李逵不服，立誓败不回山，吴用遂准他当前阵先锋。救人、报复和取得钱粮在同一场议兵中并行，不能只留下其中一种。（[本L40／原L7089](00_正文.txt#L40)）

当晚宋江、吴用定人数，裴宣另写调兵告示送到各寨，命按拨次执行；这不是戴宗先前的威胁文告。时在秋末冬初，叙述把征夫便于披挂、战马易得肥满，同久未临阵的军卒想战、想报仇连在一起，写他们得差遣便欢喜整械。平明各部依次出发：李逵五百在前哨路，解珍等四人领第二拨一千，扈三娘、孙二娘、顾大嫂领第三拨一千，李应、史进、孙新领第四拨一千；宋江、吴用统中军，四面军、炮手及粮草接应各有分派。山上实际留下公孙胜、刘唐、朱仝、穆弘统马步军守三关，李俊等守水寨，不能把大举出征理解成全寨无人防守。完整分拨名录附于文末。（[本L42／原L7091](00_正文.txt#L42)）

<a id="first-battle"></a>
## 第一阵：轻敌之后，每向前一步都使退路更难保

飞虎峪报马先告索超，宋江人马已在二三十里外。索超飞报槐树坡，李成一面报入城，一面赶到前寨听详情。次日五更造饭、平明出营，二人在庾家疃列一万五千人马，远见约五百余梁山军来；李成示意，军健“脚踏硬弩，手拽强弓”，双方摆阵。紧接的红巾、绯袄、枪刀、红旗赞写把梁山先锋写得鲜明，却没有给全军另立一个精确总数。（[本L48—50／原L7097—7099](00_正文.txt#L48)）

李逵举双斧叫阵，李成、索超却取笑这副模样。索超说杀鸡不必用牛刀，身后的首将王定随即率一百马军冲来。李逵纵然勇猛，一队仍抵不住马军冲击，四下奔走。索超追过庾家疃，山坡后忽出两队接应：左为解珍、孔亮，右为孔明、解宝，各领五百。索超看见伏兵，吃惊止追，回报难以下手；李成仍道不足惧，带前部尽数杀过庾家疃。索超已经出现一次警觉，不能把两人的反应一概说成始终不知有险。（[本L52／原L7101](00_正文.txt#L52)）

接着，扈三娘引军来到，红旗上标“女将一丈青”，左顾大嫂，右孙二娘。她们领的是一千余军马，兵众被称为“七长八短汉，四山五岳人”，不是一千女兵。李成又从外形上轻视对手，命索超迎敌，自己分兵四下勒捕。索超拍马杀来，扈三娘勒马回头，“望山凹里便走”；正文到这里没有再明写索超已经追进山凹。（[本L54—56／原L7103—7105](00_正文.txt#L54)）

官军正分头赶杀，一彪未署将名的军马又疾追而来。李成急退十四五里，首尾不能相顾；退进庾家疃，左右又被解珍、孔亮与孔明、解宝夹击，三女将掉转马头随后追杀。想回寨时，李逵再拦前路。李成、索超冲开人马夺路而走，回寨已“大折一阵”；宋江军则暂不追赶，收兵扎营。这一胜有连续接应、追逼和截路支撑。原文没有交代完整诱敌军令，所以李逵被冲散不宜直接改成预定诈败，那支未署名来军也不宜仅凭出征名单就补成李应部。（[本L56／原L7105](00_正文.txt#L56)）

<a id="second-battle"></a>
## 第二阵：二十余合未分高下，韩滔一箭改变战局

李成、索超入城报败，梁中书连夜遣闻达率本部来援。闻达到槐树坡商议，却把对手称为“疥癞之疾”，愿翌日再决一阵。军士四更造饭、五更披挂，平明进军；到了正式对阵时，闻达摆开军马，以强弓硬弩“射住阵脚”。这次才明写了弓弩射击，不能把它前移成首阵已发生的动作。（[本L58、86／原L7107、7135](00_正文.txt#L58)）

梁山推出秦明，旗上写着“霹雳火秦明”。秦明先喊话，称早想攻城，只因“诚恐害了百姓良民”，要求送出卢、石和奸夫淫妇，便退兵不侵；如不答应，就“玉石俱焚”。闻达闻言大怒，索超出阵，反问秦明本是朝廷命官，“国家有何负你”，为何落草为贼。叙述点明两人都性急，索超的斥责使秦明如炉中添炭，二人随即交手。装束赞词分别铺写秦明的狼牙棍与索超的大斧，实战则是二十余合“不分胜败”。（[本L86—94／原L7135—7143](00_正文.txt#L86)）

打破相持的是韩滔。他从先锋队拈弓发箭，射中索超左臂；索超撇斧回马，宋江立即挥军总攻，官军大败，战场写到“尸横遍野，流血成河”。宋军追过庾家疃，夺了槐树坡小寨。闻达当晚退到飞虎峪，点兵“三停去一”：这是减员规模，并非逐一确认三分之一全已死亡。宋江屯槐树坡，吴用劝趁败军气怯继续进逼，免得对方养回勇气。宋江采纳，当夜将精锐得胜军将分四路进发。（[本L94／原L7143](00_正文.txt#L94)）

<a id="night-siege"></a>
## 夜袭把败军逼回城里，围城又把民夫推上城头

飞虎峪的闻达尚在议计，小校来报近山起火。他领兵出看，东山火把遍布，花荣带杨春、陈达从山后横杀来；闻达措手不及，退回飞虎峪，西面又遇呼延灼、欧鹏、燕顺冲击，后面秦明、韩滔、彭玘并力杀到。凌振带未具名副手从小路转到飞虎峪那边放炮，军中大乱，拔寨逃走；归路上又有林冲、马麟、邓飞拦截。传令所说四路，与正文另写的炮队应一并保留，不能为了凑数漏掉一路或抹去凌振。（[本L94、96／原L7143、7145](00_正文.txt#L94)）

火光、炮声、战鼓与各方夹击使官军各自逃生，但闻达仍挥刀杀开一路，碰上李成，合兵且战且走，直到天明才到城下。梁中书赶紧点军出城接败兵，关门坚守。次日宋军追来，在东门扎寨准备攻城。这里明确写李、闻逃回，不是已经被俘；山上火起和战中烈火也没有细列烧的是哪些房屋或村落。（[本L96／原L7145](00_正文.txt#L96)）

李成再献三策：写告急家书遣心腹上京，求蔡太师奏调精兵；关报邻近府县求援；让大名府起差民夫上城，备擂木炮石、踏弩硬弓、灰瓶金汁，昼夜守御。梁中书当日派王定带密书、数骑马军出城，兼报东京与邻府，又令王太守征集民夫。前阵冲散李逵的王定，如今承担把败局消息送到京师的任务；传讯兵与当初所率百骑的规模不同。（[本L102／原L7151](00_正文.txt#L102)）

宋江随后在东、西、北三面下寨，只空南门，每日攻打。李成、闻达连日出战不能取胜，索超养箭疮，仍未痊可；邻府援兵尚未写到，南门为何留下也未解释。诗中的“城内军民俱被困”，与正文征民上城相接，让这一仗不只剩下将领胜负：民夫也被官命纳入守城。具体各人伤亡、生计如何，文本未详。回末的事实仍是北京被围而未破，卢、石尚未获释。（[本L98—104／原L7147—7153](00_正文.txt#L98)）

<a id="court"></a>
## 王定把危急送入蔡府，宣赞把关胜推到台前

王定一行三骑到东京，经门吏转报，到后堂呈密书。他把卢俊义之事和庾家疃、槐树坡、飞虎峪三处交战一一告知。蔡京先令他到馆驿安歇，待会官商议；王定又催，北京危如累卵，若陷城，河北县郡将怎么办。蔡京叫他先退，随即却遣当日府干去请枢密官。遣使暂退与实际召官是前后动作，不能截取一句就说蔡京完全不办救援。（[本L106／原L7155](00_正文.txt#L106)）

童贯引三衙太尉到来，蔡京问用什么计、派什么将，众官相觑而有惧色。这时，步司太尉身后站出掌管兵马的衙门防御保义使宣赞。叙述先补他的处境：武艺出众，曾以连珠箭赢番将，被郡王招婿，号丑郡马；郡主嫌其貌丑，怀恨而亡，他因此不得重用。叙述又直评童贯“阿谀谄佞”，写童、宣不能相下、常有嫌疑。这些前史与评价来自叙述，没有另演郡主的自述或完整的排挤经过。（[本L106／原L7155](00_正文.txt#L106)）

宣赞“忍不住”出班，荐乡中旧识、蒲东巡检关胜，称他为关羽嫡派子孙，读兵书、通武艺，有万夫不当之勇，只是屈在下僚；若礼请拜将，便能平水寨、保国安民。蔡京听后大喜，遣他携文书鞍马连夜往蒲东。私人旧识在这里形成可见的荐举通道，不过谱系与勇力首先是荐辞的内容，本回随后直接展示的是关胜献策，还没有展示他的临阵战绩。（[本L106／原L7155](00_正文.txt#L106)）

宣赞带三五从人抵蒲东，关胜正同郝思文论古今兴废，二人一起迎使。关胜问故人来意，宣赞转达北京被围及自己保举之事，又称奉朝廷敕旨、太师钧命；文本没有另外展开颁敕过程。关胜大喜，介绍郝思文是拜义弟兄，说其母梦井木犴投胎才有此绰号，又说他十八般武艺皆能，希望同赴京报国。宣赞答应并催程。梦兆和全能武艺在这里有明确的介绍者，不是母亲现身，也不是现场演武。（[本L108／原L7157](00_正文.txt#L108)）

<a id="strategy"></a>
## 解北京之围，先去打梁山

关胜分付家中老小，和郝思文带十余关西汉收拾刀马盔甲行李，随宣赞连夜赴京。老小没有被写成同行者。又经门吏转报，宣赞引二人入见；蔡京见关胜形貌堂堂而喜，问年龄，关胜答三十二岁。问到解围之策，关胜认为直接救北京徒费力气，应趁梁山主力离寨，“先取梁山，后拿贼寇，教他首尾不能相顾”。他以“久闻”指责梁山侵民劫城，是这番出兵主张的理由；不能把这句话当成已在此逐案核明的罪状。（[本L110／原L7159](00_正文.txt#L110)）

蔡京称此为“围魏救赵”，命枢密院调山东、河北精锐一万五千，关胜任领兵指挥使，郝思文为先锋，宣赞合后，步军太尉段常接应粮草。关胜所请是“精兵数万”，实拨数目则是一万五千；这支新军也不是先前庾家疃那支一万五千人马。犒赏、限日起行之后，官军已向梁山出发，尚未写到抵寨、交锋或取寨成功。（[本L110／原L7159](00_正文.txt#L110)）

这一转向使本回前半的胜利带上新的危险：宋江越向北京进逼，本寨就越成为关胜想用来牵动他的目标。不过山上有三关、水寨留守，关胜能否得手、宋江何时获讯以及怎样应对，都还留在回末悬问中。“龙离大海”“贪观天上中秋月，失却盘中照殿珠”是对顾此失彼的警示，不能写成本回梁山已经失守。现代注释说明战法典故，所列田忌、孙膑、魏赵齐与桂陵属于注释的历史解释，也不增加本回战果。（[本L42、110／原L7091、7159](00_正文.txt#L42)；[注L3／原L7169](00_注释.txt#L3)）

## 几处值得回看的细节

**告示先产生效果，叙事后揭出它的制造者。**读者先随梁中书看见宋江署名、进兵威胁，再听王太守权衡，最后才知道戴宗“虚写”的目的只是保命。这个次序让戴宗的作用格外具体：他没有正面打破牢门，却用梁山的名声改变了官府计算。蔡福原有结交愿望，听到“可紧可慢”又“正中下怀”；文告威慑、王的建议、梁的采纳与狱吏的照顾共同维持了二囚的性命，并非某一个人独力完成营救。（[本L24—40／原L7073—7089](00_正文.txt#L24)）

**保护百姓并不是哪一方已经兑现的结论。**王太守以“军民不伤”说服梁，梁也实际出了医葬官钱；戴宗告示安抚良民，秦明解释自己怕伤百姓，但文告与阵前讲话又都以“玉石俱焚”相逼。宋江本人表达了救人忧虑，吴用明说兼取钱粮；告示由戴宗制造，交人退兵由秦明在阵前提出，不能把这些话都算成宋江本人反复发言。死伤者、败卒、被征民夫构成这些话语之外的实际承受者，保护的承诺与战争的代价必须一并读。（[本L26—30、40、90—104／原L7075—7079、7089、7139—7153](00_正文.txt#L26)）

**勇猛受制于人数、配合和时机。**石秀在城中败于众，李逵部败于马军；秦明、索超二十余合相持，真正改变阵势的是韩滔一箭，随后还有宋江总攻、吴用催追和多路夜袭。官军诗称“一心忠赤”，梁山长诗又称“人人只欲尽忠义”，索超却以国家恩义斥秦明为贼。这些不同声音使忠义成为双方争说的理由，而非可以替代战况的单一标签。长诗的“十万貔貅”是军威铺陈，“乱兵俘获”“聚义堂上重相逢”有预示性；它们都不能覆盖正叙中闻达、李成已经逃回城内的明确动作。开篇“他时”出囹圄，同样没有把卢、石提前放出牢门。（[本L22、24、36—38、52、62—84、94—96／原L7071、7073、7085—7087、7101、7111—7133、7143—7145](00_正文.txt#L22)）

**扈三娘的战力与被观看的容貌同时写在纸上。**词中有“玉雪肌肤”“玉手纤纤”，也有宝刃、汗湿、杀气和斩馘；正文则落实为领一拨军、回马望山凹走、随后同两位女将掉头追杀。只谈容貌会丢掉她的指挥位置，只用词中的得胜形象也不能替她补一场单挑索超获胜。旗帜标识的是将领身份，原文没有说旗由她亲手拿着。这里最实在的变化，是她被派为主将，并在整段进退接应中有明确动作。（[本L42、54—56／原L7091、7103—7105](00_正文.txt#L42)）
