# 第五十四回 入云龙斗法破高廉 黑旋风探穴救柴进

罗真人准公孙胜下山援救宋江，另传“五雷天罡正法”，要求他保国安民、替天行道，仍须守住学道之心。他又许诺派人早晚照看老母，把公孙胜说成“上界天闲星”，交下八字：“逢幽而止，遇汴而还。”公孙胜拜受，回家收拾道衣、宝剑、铁冠、如意，辞母启程。师父所说的星命、使命和未来条件都已经交代，照护如何执行、八字何时应验，则还没有展开。（本回L14／原书L5994）

<a id="road"></a>
## 从买枣糕到招来一个铁匠

走出三四十里，戴宗提出自己先去报信，再回来接公孙胜和李逵；公孙胜同意。戴宗嘱李逵好生服侍，若有差池便教他受苦。李逵回答：“他和罗真人一般的法术，我如何敢轻慢了他！”叙述也明写他畏惧法术，一路十分小心。上一回受训、受罚的经历，在这里有了暂时收敛的后续。（本回L16—18／原L5996—5998；前情见[第五十三回](../第053回/05_追踪与交接.md#delta-q07-e)）

三日后，两人到武冈镇歇脚。公孙胜要吃素酒素面，酒店没有素点心，过卖指点市口有人卖枣糕。李逵取钱买了一包，回程却被一阵喝彩吸引：众人围着一个大汉，看他使约三十来斤的铁瓜锤，一锤打碎压街石。李逵把糕揣进怀里，伸手拿锤，又贬损对方的本事。大汉许他试使，约定若使不动就打他一顿；李逵却使得如弄弹丸，放下仍面不红、气不喘。大汉服了，倒身下拜，引他到家。（本回L18—20／原L5998—6000）

李逵见屋里铁砧、火炉、钳凿齐备，想到山寨“正用得着”，才问起姓名。大汉自称汤隆，因满身麻点，号金钱豹子；父亲原任延安府知寨，早年因打铁得老种经略相公叙用，后来在任身亡，自己则因贪赌流落，在此以打铁度日。他喜欢枪棒，也仰慕梁山名声。李逵邀他入伙，许他做头领，汤隆明确愿随，拜李逵为兄。原想饮酒歇一夜的汤隆，听说宋江正交战、急等公孙胜救应，便携盘缠和兵器，弃旧屋及粗重家火随行。父亲的官职、汤隆的手艺和他本人的江湖处境，在这段自述中各有归属。（本回L22—28／原L6002—6008）

公孙胜已经等得不耐烦，说再迟便回去了。李逵不敢回话，转而引汤隆拜见、说明结义；公孙胜听他打铁出身，心中也喜。三人吃糕饮酒、结清酒钱后继续赶路。汤隆的加入先由争强引起，随后落到手艺、结义与山寨需要上；直到回山时叙述明确说新增两个头领，李逵的邀约才有了结果。（本回L30、80／原L6010、6060）

<a id="battle"></a>
## 公孙胜破法，也谋阵

三人走过大部分路程，戴宗迎面来接。公孙胜先问战况，戴宗说高廉箭疮平复，每日挑战，宋江坚守等候。李逵引汤隆拜见戴宗，把备细说知，四人再一同赴高唐；到寨前五里，又由吕方、郭盛率百余骑迎接。宋江、吴用及众头领接风，李逵继续引见汤隆。（本回L32／原L6012）

次日，宋江、吴用、公孙胜议战。公孙胜提出拔寨前进，看看敌军动静，再由他处置。宋江传令，众军移到城壕下寨；再次日五更造饭披挂，出军临城。高廉率三百神兵及将校迎敌。梁山阵前左列花荣、秦明、朱仝、欧鹏、吕方，右列林冲、孙立、邓飞、马麟、郭盛；宋江居中，吴用、公孙胜分列左右。叙述分别称吴用为“掌握兵权军师”、公孙胜为“掌握行兵布阵副军师”，随后铺写冠甲、马匹与兵器。高廉也有华服宝剑和二三十军官簇拥，两方声势都先被展现出来。（本回L34—50／原L6014—6030）

高廉喝骂挑战，宋江问谁出马，花荣挺枪应战；高廉唤将，薛元辉持双刀迎上。斗数合，花荣佯退，薛元辉“不知是计”，追赶中被回身一箭射下马。正文只交代射落，未写其死活。高廉大怒，以剑击聚兽铜牌三下，黄砂裹着虎豹毒虫卷出；梁山众军正要逃，公孙胜拔剑念咒，喝声“疾”，金光射去，兽虫纷纷坠地，众人看见原来都是白纸剪成。宋江这才挥军掩杀。高廉退城，城上收桥闭门，以擂木炮石阻追，宋江便鸣金收军，谢公孙胜、赏劳三军。（本回L52—54／原L6032—6034）

公孙胜接着判断，三百神兵已退入城内，攻得紧，高廉料会夜来劫营。他提出白日攻城、随后收军，夜深四面埋伏，只扎空寨，以霹雳和寨火为进兵信号。宋江一方按计攻到未牌收兵，营中吹打饮酒，傍晚诸将暗中分伏。底本此处让公孙胜说“昨夜虽是杀败敌军大半”，而前段是从清早出阵连续写来的；这里保留这处时间用语，不改作“昨日”，也不补一场未写的夜战。（本回L56／原L6036；前战见L34—54／原L6014—6034）

二更前后，高廉果然率三百神兵出城，后随三千余骑。神兵背铁葫芦，内藏硫黄焰硝等药料，持钩刃铁扫帚、衔芦哨；高廉施术起黑气狂风，神兵点火鸣哨，乘势冲营。公孙胜在高处仗剑作法，空寨平地起霹雳，继而火光乱飞。神兵欲退无路，四面伏兵围杀，三百人无一逃脱。高廉带三十余骑奔回，林冲追来，最后只八九骑随他入城，其余这支退兵被连人带马生擒。三百神兵全死与退骑有俘有逃，是两种不同结局，不能把三千余骑每个人的生死都由此算齐。（本回L58／原L6038）

高廉回城后“尽点百姓上城守护”，无名居民也被卷入守城。夜战里既有法术，也有火药器具、号令和伏兵；公孙胜的功劳包括判断敌情、安排空营和选择进兵信号，并非只在阵前念咒。故事直接写金光、雷火和腾云，其法术在叙事中有实际力量；纸兽显形也不能反过来把全场改解释成普通骗局。（本回L54—58、68／原L6034—6038、6048）

<a id="false-relief"></a>
## 吴用放走信使，高廉把假援当真

围城愈紧，高廉修书两封，差两个帐前统制由西门杀出，往东昌、寇州求救。他说两地知府都是自己哥哥抬举的人，寄望于这层关系。众将要追，吴用先命放行，再向宋江解释：另用两路人马诈作救军，在路上混战，诱高廉开门，一面取城，一面把他引入小路擒获。宋江采纳，命戴宗回梁山另取两路军马。后文显示计策实施了，戴宗取兵的往返却没有另行展开。（本回L64／原L6044）

高廉每夜在城中堆柴，举火为号盼援。几日后，守军见梁山军“不战自乱”，急忙报告；高廉登城，看见两路军马杀来、围城兵四散，便认作援军，尽点城中军马出门掩杀。读者已经知道假援之计，高廉却把眼前表象当成真相。本回没有展开两封信送达、两州议援的过程，后来两地上表报失城，也不能倒推他们此前每一步都做过或全未行动。（本回L66、82／原L6046、6062）

宋江带花荣、秦明往小路走，引高廉追赶。坡后连珠炮响，高廉生疑掉头，吕方、郭盛已各率五百人左右夹击，部下折去大半。他夺路出来，才看见城上换成梁山旗号，四望也无真援军，只得带残兵走山僻路。不到十里，又遇孙立挡前、朱仝截后，步军四面赶来。高廉弃马上山，念咒驾黑云腾空，公孙胜指剑破法，使他倒撞下来；雷横抢上一朴刀，挥成两段，提首级下山，并先遣人飞报主帅。（本回L68、74／原L6048、6054）

这一场胜利有完整分工：吴用造假援之势，宋江等诱追，吕郭侧击，孙朱断路，公孙胜破遁，雷横最后斩杀。叙述对高廉仍有“可怜半世英雄汉”的感叹，随后诗又评他弄妖兵、终于不敌公孙胜；败亡者的声势与全回的道德褒贬同时留在文字里。（本回L64—72／原L6044—6052）

<a id="prison"></a>
## 入城之后，还要找到井底的柴进

柴进陷狱的前因不能略去：第五十二回，叔父柴皇城被殷天锡夺产殴辱，临终托柴进赴京告状而死；殷再来逼搬、喝令打柴进，李逵冲出将殷打死。柴进知道会受牵累，仍催李逵逃走，自己留下支吾官司，却被高廉刑逼招成指使杀人，戴死囚枷入狱。殷夫人又促高廉抄叔家财产、禁人口、占房园。高廉与高俅的关系，当时由柴皇城继室说明为“叔伯兄弟”，本回再称哥哥、兄弟，不宜改写成已证同父母的亲兄弟。（第52回L24、28—40／原L5770、5774—5786）

宋江入城，先令不伤百姓、出榜安民，再到大牢找柴进。狱吏已经逃走，他一方把三五十名罪囚尽数开枷释放，却没有柴进。随后在两处牢房，分别找到已故柴皇城的家人，以及从沧州提捉来的柴进一家老小；后者被提来高唐，是本回新补出的前事。两家因连日战事尚未取问发落，他们的被囚与获救也属于此役的结果。（本回L74／原L6054）

吴用命召集狱卒追问，当牢节级蔺仁才禀报。他说高廉原令自己专守柴进，“但有凶吉，你可便下手”；三日前又要提人施刑，自己因见柴进是好男子不忍，先推称病至八分，不必再下手，后来催得紧，便谎报已死。高廉差人查看，他怕获罪，昨日才领柴进到后面枯井，开枷推入躲避，现在也不知存亡。这是蔺仁的供述：井中后来确实找到柴进，能互证地点和存活，不能把他所说的每一步过去言行及不忍之心都改成旁人亲见。（本回L74／原L6054）

宋江急令蔺仁带路，见井中黑洞洞，呼叫无人应答；放索探得约八九丈深，便落泪说柴大官人恐怕没了。吴用劝先找人下去探看。李逵主动应声，宋江答：“当初也是你送了他，今日正宜报本。”这句话接住了李逵救护柴进却又累他入狱的前情，使下井带有补救旧事的意味。李逵却笑着防备众人割绳，吴用说他“忒奸猾”，救人的紧张里先插入一段带戒心的玩笑。（本回L76／原L6056；第52回L30、36—38／原L5776、5782—5784）

众人接长索、扎架、系篾箩，在索上缚两只铜铃。李逵赤身拿双斧下井，出箩摸到一堆骸骨，又觉井底湿滑无处下脚；放下双斧，用两手摸，才在水坑里触到蜷作一团的人。叫柴进不见动，再摸时觉得口内微微有声，李逵才说“还有救性”，摇铃先把自己送上井报告。骸骨是谁，正文没有说明；柴进是否活着，也正是在这次实探后才得到确认。（本回L76／原L6056）

<a id="rescue"></a>
## 两次下井，一次被忘

宋江命李逵再下，把柴进先送上来，然后放箩接他。李逵说自己在蓟州已“着了两道儿”，不愿再撞第三遍；宋江笑着催他，保证不会弄他。李逵只得再下井，抱柴进入箩，摇铃送上。众人见柴进得救大喜，宋江却看见他头破额裂、两腿皮肉打烂、双眼略开又闭，凄惨地叫请医士。（本回L78／原L6058）

井上忙于柴进，井底李逵却喊叫起来。宋江听见，才急令放箩接人。李逵上来发作，宋江承认：“我们只顾看顾柴大官人，因此忘了你。”他的戒心在这里有了喜剧性的回响，也有实际危险：下井者的性命依赖井上的绳箩。正文确写一时失顾，也给出照顾伤者而忘人的解释，没有写成故意割绳或弃他不救。（本回L78／原L6058）

李逵的勇敢与畏惧在本回并行。他因罗真人法术收敛，仍会争锤骂人、自作主张；面对深井则主动承担风险，又反复防备被捉弄。上一回的训戒已有短期效果，不能据此宣布他彻底改性。能使重锤、行军和下井，也只是旧刑伤之后的新活动，不等于此前“两腿肉烂”已完全痊愈或蓟州官案已经销除。（本回L16—30、76—78／原L5996—6010、6056—6058；第53回L114—120／原L5955—5961）

柴进得救时的具体伤状，与第五十二回“皮开肉绽，鲜血迸流”的刑伤相接，但原文没有逐一确定每处伤口何时形成。蔺仁把人藏井，按其自述免了眼前施刑，也让重伤者置身湿井、存亡难知。救援最后靠的是查问、指路、量井、两次下探、提索和抱扶，法术大战之后，人的身体与众人的劳动仍决定能否真正把他救出来。（本回L74—78／原L6054—6058；第52回L38／原L5784）

<a id="aftermath"></a>
## 两家获救，高家良贱被斩

宋江令把柴进扛扶上车，让李逵、雷横先护送两家老小及夺回的许多家财上梁山，共有二十余辆车。紧接着，正文写高廉“一家老小良贱三四十口，处斩于市”，又把高家私财、府库财帛、仓廒粮米尽数运上山。执行处斩者没有点名，不能因为李逵、雷横前面出现，就把这次行刑归给二人。（本回L78／原L6058）

入城时“不伤害百姓”、出榜安民，以及返程经过州县“秋毫无犯”，都是叙述明确保存的保护；高家老小良贱被整体处斩也是明确后果，正文没有逐人交代他们的罪责。开篇诗用“行仁柴进”“无德高廉”安排生死褒贬，实际经过却还涉及两边家属和无名人口的不同命运。理解胜利时，既须保留罪囚获释、柴氏两家脱险，也须看见高家连属者被杀和公私财粮被取走，不能让一句“安民”覆盖全部处置。（本回L10、74、78—80／原L5990、6054、6058—6060）

数日后，大军回山，柴进扶病向晁盖、宋江及诸头领称谢。晁盖安排在山顶宋江歇所处另建房屋，供柴进和家眷安歇；这是居处安排，未叙新屋建成。柴进、汤隆成为新增两头领，寨中设宴庆贺。公孙胜此前已明确到军参战，末段“大小将校……回到大寨”的集合叙述支持他随军返梁山，但没有单独点名他的回寨；也没有写戴宗履行此前禀师时“破了高廉，便送还山”的承诺，把他送回二仙山。（本回L32—34、80／原L6012—6014、6060；第53回归约旧界见[三子交接](../第053回/05_追踪与交接.md#delta-q42-02)）

<a id="court"></a>
## 庆功之后，败讯进入朝廷

东昌、寇州得知高唐失陷、高廉被杀，写表遣人上奏；另有逃难的高唐官员入京报告。高俅得知叔伯兄弟之死，次日五更候朝。叙述以晓钟、千官、剑佩与旌旗铺开朝仪，战场上的地方危机由这些报信者进入中央决策。（本回L82—90／原L6062—6070；叔伯关系见第52回L24／原L5770）

高俅奏称晁盖、宋江聚党作恶，提到济州、江州、无为军，又说高唐“官民杀戮一空”、库藏尽被掳去，将梁山指为将来甚于北方敌国的心腹大患。这里须分开声音：搬取仓库有本回正叙支持，全城官民皆被杀却不合前面的放囚、救家与安民描写；也不能因此否认高家良贱确实被杀。亲属之丧与掌握公权的奏报在此相连，正文没有把他的一切判断都解释成唯一的私仇动机。（本回L74、78、92／原L6054、6058、6072）

皇帝闻奏大惊，下旨交高俅选将剿捕，务要扫清水泊、“杀绝种类”。高俅又说不必兴举大兵，保荐汝宁郡都统制呼延灼，称其为河东名将呼延赞嫡派，使双铜鞭，有精兵强将，请授兵马指挥使。皇帝准奏，枢密院遣军官赍敕限期宣召。（本回L92／原L6072）

呼延灼从门人处听报，与本州官员出郭迎旨，在统军司开读、设宴待使，再收拾盔甲鞍马，带三四十从人随使臣赴京。“一同使命”里的“使命”，注释释为使臣、使者，是同行的人。到京又经门吏通报，高俅召见、赏赐，次日带他见天子；徽宗喜其仪表，赐踢雪乌骓，正文以黑身白蹄和日行千里赞写名马。（本回L94—100／原L6074—6080；注释本L1／原L6090）

呼延灼回帅府议征，却先说梁山“兵多将广，武艺高强，不可轻敌小觑”，请举两将作先锋，并愿承担误举重罪。他的谨慎给将门身世、英武赞词和宝马之外又添一层实际判断；所谓“观探”的渠道并未展开，不能另补侦察场景。高俅问二将是谁，回目就在名字说出前结束。末尾“梁山泊大破官军”“身体先登聚义厅”仍是未来预告：柴进之救已完成，新的征剿与人物去向尚待展开。（本回L100—102／原L6080—6082）
