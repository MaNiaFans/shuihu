# 第四十六回：翠屏山对质，祝家店起火

杨雄和石秀的兄弟信任在这一回恢复了。杨雄先认自己错怪了人，后来又亲耳听见妻子撤回诬告；但事情没有停在辨明是非、给出休书。两名被许诺说实话便能活命的女子最终被杀，恢复的兄弟关系转而成为共同逃亡的关系。三人投奔梁山的路上，一只报晓鸡又把他们卷入祝家庄的追捕：到回末，时迁被押，杨雄、石秀逃进另一家村店，遇见一个尚未报出姓名的旧识。

<a id="case-start"></a>
## 双尸到了官府，也到了街头

开篇诗先劝人少纵“气酒财花”，以李白、绿珠等名目警告缙绅；接下来的故事却先让一个卖糕粥的人承受前夜杀人的后果。邻舍抓住王公，到蓟州首告，说他的一担糕粥泼在两具裸尸旁，头陀身边还有刀。王公申说自己只是五更赶早市，和口中所称“铁头猴子”的随行者只顾走，被尸体绊倒，碗碟摔碎，惊叫起来，反被扯来见官。随行者在上一回称“小猴子”，姓名和与王公的关系没有交代。[正文L4—14](00_正文.txt#L4)；[第045回L96](../第045回/00_正文.txt#L96)。

知府先取供词，再差当方里甲带仵作行人，押王公、邻舍等回现场检验。验报确认死者是报恩寺阇黎裴如海和寺后胡道：和尚有三四处刀伤，胡道颈有一道勒伤，刀在胡道身边，于是推测“想是胡道掣刀搠死和尚，惧罪自行勒死”。知府拘问寺中首僧，也问不出缘由。当案孔目便从裸体推到两人做过“不公不法”的事，建议不牵王公，让邻舍召保听候，令住持备棺收殓，立一个互相杀死的文书。知府应了“也是”，发落众人。这里落实了王公摆脱本次嫌疑，明确须召保听候的是邻舍；住持被指定收殓，正文没有另写其实际执行。[正文L14](00_正文.txt#L14)。

读者已在上一回见到另一套经过：石秀刀胁胡道问供，索衣、夺木鱼，胡道正在脱衣时被杀；石秀再冒穿其衣，敲木鱼诱出裴如海，剥衣刺死，把刀放在胡道身旁。官府因而是在安排过的尸场上作判断，“互相杀死”不是叙述者确认的死因。[第045回L94](../第045回/00_正文.txt#L94)。

街上的解释又换了面目。好事子弟作曲讥讽破戒，拿立雪、投岩、目连救母等宗教名目反衬僧人因女色丧身；书会再作《临江仙》，唱到“睡来同衾枕，死去不分离”，又说胡道害了海阇黎。曲词把裸尸变成笑料，却不能据以证明二人同寝或胡道杀僧。满城传唱的实在效果，是潘巧云“惊得呆了”，不敢对外说，只在心中叫苦。[正文L16—24](00_正文.txt#L16)。

<a id="mountain-confrontation"></a>
## 石秀要说清，杨雄把妻子带进古墓

杨雄在府里听到双尸消息，已猜到七八分，想准是石秀所为，也意识到前日错怪了他。他正过州桥寻人，石秀从后叫住，邀进客店小房。杨雄承认酒后失言、反被妻子瞒过，说来“负荆请罪”；这是一句请罪话，没有另写背负荆条的行动。石秀以“顶天立地的好汉”自明，取出两死者衣服作表记。杨雄一见，便要当夜碎割妻子。[正文L24](00_正文.txt#L24)。

石秀此时反而以“法度”劝住：杨雄既是公门中人，未拿真奸，怎能杀人；倘若只是自己胡说，岂不错杀？他提出的办法是翌日借烧香，把妇人与迎儿带到僻静的翠屏山，当面对清，再给休书弃妻。杨雄已经说相信兄弟清白，石秀仍坚持要他知道往来的真实经过，并保证赴约。辨清诬告在这里既是查事，也是石秀恢复名誉的要求。[正文L24](00_正文.txt#L24)。

杨雄回衙办事，夜归一切如常。次晨他把借口说得更具体：梦见神人催还旧愿，东门外岳庙那炷香是当初说亲时许下的，所以必须夫妻同去。妇人本说他独去即可，听了这层解释才同意吃素、洗浴、梳妆。杨雄买纸烛、雇轿，又到客店和石秀约定；石秀要求半山下轿，只让杨、潘、迎三人步行上山，“不要带闲人上来”。迎儿也插戴停当，潘公留家看守，叮嘱多烧香、早去早回。出了东门，杨雄才低声向轿夫加钱，改抬翠屏山。[正文L26—28](00_正文.txt#L26)。

山中不是庙宇，而是满目荒坟。写景先说“一望并无闲寺院”，随后叙述再点明，此山距东门二十里，上面并无庵舍寺院。到半山，妇人问为何来此，杨雄只催她上去，把轿夫留下，许稍后打发酒钱。登过四五层山坡，她仍问香纸，杨雄谎说已先送上；再把她扶到古墓，石秀正等在那里。烧香的说辞到此仍在延续，旁人却已被隔在山下。[正文L30—34](00_正文.txt#L30)。

杨雄当面重述妻子对石秀调戏、摸胸、问有孕的指控。妇人想以“过了的事”搪塞，石秀不许，取出裴如海和胡道的衣服撒在地上。她脸红，无言可对；石秀拔刀，提议问迎儿。杨雄便揪丫头跪下，直接报出僧房入奸、香桌为号、木鱼报晓等环节，许诺实说便饶命，瞒一句就剁成肉泥。这不是让一个无拘束的证人从头自由讲述，而是在掌握若干线索后，以死亡威胁索取更细的供述。[正文L34—36](00_正文.txt#L34)。

迎儿先求“不要杀我”，再讲入寺吃酒、上楼看佛牙、被遣下楼照看醉潘公，以及后来如何取钱布施头陀、摆香桌、开后门。她说和尚扮俗人夜来，五更头陀敲木鱼，她再放人出去；主母许钏镯衣裳，她“只得随顺了”。这条联络链与上一回直接写出的设谋、置撤香桌及开门相合；次数却须分声保留：上一回叙述为月余“十数遍”，本回迎儿口供称“数十遭”，没有逐夜账目可把两处强并成一个精确数。[正文L36](00_正文.txt#L36)；[第045回L62—70](../第045回/00_正文.txt#L62)。

她还说，主母后来给几件首饰，要她向杨雄证实石秀调戏；但“这个我眼里不曾见，因此不敢说”。参与密会与愿意替每一项说辞作证，因而不是同一回事。她的供述包含亲手参与、所受告知和自辩，不能一律写成独立亲眼目击；也不能把“只得随顺”抹去，变成对其内心毫无余地的全知判词。[正文L36](00_正文.txt#L36)。

石秀强调这些话不是自己教的，又催杨雄问妻子。杨雄也许诺说实情便饶命。潘巧云先求他念旧夫妻情面饶恕，石秀不许含糊，她才从做道场夜里一直交代后来往来，又亲口撤回对石秀的指控：丈夫醉骂，她猜是石秀看破告发，到五更又问兄弟，才编这番话“支吾”；“实是叔叔并不曾恁地”。本回对诬告已有提出者自认的答案，不能仍把调戏说当作双方各执一词。[正文L36](00_正文.txt#L36)。

石秀宣布“三面说得明白了”，说任从哥哥措置，却没有就此退到一旁。他按杨雄要求剥去妇人头面衣服，杨雄割裙带，亲手把她绑在树上；石秀又去迎儿首饰，递刀劝“一发斩草除根”。杨雄应允，亲手将欲叫的迎儿挥作两段。潘巧云被绑后转求石秀“叔叔劝一劝”，他只答“哥哥自来伏侍你”。她先求丈夫念夫妻旧情，后求石秀劝阻，两次求助都未能止住杀害。[正文L36](00_正文.txt#L36)。

杨雄先割掉她舌头，使她叫不得，再骂她坏了兄弟情分，且“久后必然”害己，便剖腹取心肝五脏挂在树上，继而分尸，收拾头面衣物。通奸、诬告由她认了；将来杀夫则仍只是杨雄为先下手所作的预断，不能拿来补成已经查出的谋杀计划。先前谈过的休书没有交付，两次饶命话也没有兑现。石秀直接参与剥衣、递刀、劝杀，杨雄亲手杀人与肢解，两人的责任沿具体动作相接。[正文L36](00_正文.txt#L36)。

<a id="flight-and-shiqian"></a>
## 两个杀人者要投梁山，时迁求搭上这条路

事毕，杨雄才问何处安身。石秀说早已寻思，二人都杀了人，自应投梁山；插诗也把梁山说成“好潜身”的所在。杨雄仍有两层顾虑：没有熟人，未必肯收；自己又是公人，恐对方起疑。石秀先举宋公明招贤纳士的声名及二人武艺，再以宋也是押司出身解其心疑，并报出此前相识的戴宗、杨林，说当时所得十两一锭银子还在包里。[正文L38—44](00_正文.txt#L38)。

这番门路有前情：戴宗曾说可以相荐，并叫杨林从包中取十两银赠石秀；石秀正欲投托，杨雄带一群做公的人来寻，叙述写戴、杨“见人多，吃了一惊”，慌忙走了；石秀后来向杨雄解释，他们“只道相闹，以此去了”。投托的话因此没有说成。如今石秀把这条中断的道路重新提出，杨雄才放心；但熟人、赠银和口头引荐都不等于梁山已经准入。[第044回L78—88](../第044回/00_正文.txt#L78)；[正文L44](00_正文.txt#L44)。

杨雄想回城取盘缠，石秀以事发遭拿、无法脱身为由阻止，指出包中钗钏首饰及自己的银两已足，不应为钱再冒险。二人带包裹和刀棒，准备从山后走，松树后却出现一人，说他们杀人投梁山的话已听多时，随即拜倒。杨雄认出鼓上蚤时迁。叙述交代他祖贯高唐州，流落此地，以飞檐走壁、跳篱骗马为业，曾在蓟州吃官司得杨雄救助；赞诗把他的潜行本领写成穿墙绕屋、行步如飞。这是人物身手与声名的介绍，尚不是本回已为梁山偷营立功。[正文L44—54](00_正文.txt#L44)。

时迁自述近来没有道路，在山中掘古坟找东西，见杨雄行事不敢出来，听说投梁山，便求带挈：总做偷鸡盗狗，“几时是了”。石秀答梁山正在招纳壮士，不差他一个，准他同行；时迁熟小路，引二人从后山离开。曾在官司中救过时迁的是杨雄，答应他同行的是石秀，三人的联系在这里才落成实际旅程。[正文L46、56](00_正文.txt#L46)。

<a id="case-return"></a>
## 山下等候的人终于上来

叙述这时转回两轿夫。他们在半山等到红日平西，因吩咐不敢上去，终于挨不过才寻人；看见成群老鸦争食脏腑，才发现惨尸。他们惊逃回报潘公，并同往蓟州首告。等候并非空白：杨雄的命令使发现延后，也让被留在半山的轿夫最终承担了见尸、传信和报官的工作。[正文L58](00_正文.txt#L58)。

知府另差县尉带仵作行人检验，报出潘巧云被割在松树边，迎儿死在古墓下，坟边遗有一堆“妇人、头陀衣服”。知府因此联到前日案，再问潘公，后者交代僧房醉酒和石秀离家的缘由。不能因潘公此刻说得出这些前情，就倒推他先前已知女儿全部私情或参与诱杀；山上之事是轿夫回来才报给他的。[正文L28、58](00_正文.txt#L28)。

知府这次判断潘巧云与和尚通奸、女使和头陀做脚，石秀杀了两个男人，杨雄杀了两个女人，随即发文、出赏捕杨雄和石秀。判断比首次“互相杀死”接近实际行凶者，但他仍说“只拿得杨雄、石秀，便知端的”，未捕到人，也未获两人讯供；所称石秀“路见不平”，更不能代替具体的兄弟与私人缘由。轿夫等被放回听候，潘公买棺殡葬。开始盼着女儿、女婿烧香早归的父亲，到这里成了供前情和办理葬事的人。[正文L58](00_正文.txt#L58)。

<a id="inn-and-fire"></a>
## 祝家店先接客，后来丢了报晓鸡

杨雄、石秀、时迁离开蓟州，夜宿晓行，不止一日才到郓州地面，过香林洼，黄昏投进靠溪客店。店景先写临官道、傍大溪，门联迎“五湖宾”“三岛客”，是接四方来人的样子。小二正待关门，仍放三人进来。时迁说当日走了一百里以上，询问酒肉；小二答早起的肉已被近村买去，只余一瓮酒，却肯供灶锅和五升米。时迁淘米做饭，石秀安顿行李，杨雄给一只钗先换酒，约明日总算；小二开酒、端熟菜，时迁又提汤让二人洗脚手，摆四只大碗，邀小二同饮。后来的敌对有此前接待作为起点。[正文L60—64](00_正文.txt#L60)。

石秀看到檐下十余把朴刀，问主人是谁、存刀何用。小二介绍独龙冈、祝家庄和庄主祝朝奉，称其三个儿子为“祝氏三杰”；庄前庄后有五七百佃户，各分两刀，店内也因常有数十家人宿夜而备刀，是防离得近的梁山人来“借粮”。庄域、户数和设防缘由由小二讲出，不能把“借粮”自行扩成此地已发生过一次抢掠。[正文L66](00_正文.txt#L66)。

石秀提议付钱换一把刀，小二立即拒绝：器械编着字号，自己吃不起主人棍棒，“主人法度不轻”。石秀笑称取笑，叫只顾饮酒，小二却退去歇了。刀的编号、佃户配刀、家人宿店和仆人的畏罚，使尚未登场的庄主权力先经物件与使役关系显出来。“朝奉”据现代注释在宋时是对绅豪的尊称，不能因此给他另派一个现任官职；三子姓名本回也未报出。[正文L66](00_正文.txt#L66)；[注释L1](00_注释.txt#L1)。

小二走后，时迁提出一只熟公鸡。他说去后面净手，看见鸡在笼里，想到哥哥没肉下酒，便悄悄捉到溪边杀了，再烫洗煮熟。杨雄骂他仍“贼手贼脚”，石秀笑他不改本行，三人笑过仍撕鸡吃。时迁刚说偷鸡盗狗无出路，转眼又以同样的手艺照应同行人，求出头的愿望没有立即改掉本行。[正文L68](00_正文.txt#L68)。

小二略睡又起巡看，见鸡毛、鸡骨和半锅肥汁，再查空笼，才来质问。时迁先谎称路上买鸡，继而推给野猫、黄猩子、鹞鹰。石秀起先提出赔钱，小二拒绝用银两补偿，坚持这是店内少不得的报晓鸡，说“你便赔我十两银子也不济，只要还我鸡”。十两是他极言鸡不可替代，并非已开出的索赔数；店小二拒绝受偿之后，石秀才转怒，改口“老爷不赔你便怎地”。[正文L68](00_正文.txt#L68)。

小二接着搬出庄势，笑说本店不同别店，可拿他们到庄上，做梁山贼寇解送。石秀反骂“便是梁山泊好汉”，杨雄也怒称不赔又能如何。小二呼贼，三五大汉径奔杨、石，被石秀一拳一个打翻；时迁一掌打肿小二脸，使其不能作声，大汉们从后门走了。三人尚在投奔途中，石秀已借梁山名号相抗；此处的打人不是梁山已经授权的一次行动。[正文L68](00_正文.txt#L68)。

杨雄料逃走者要去报人，催快吃饭走。三人吃饱，分腰包裹，穿麻鞋、跨腰刀，又各从枪架上拣一条好朴刀。石秀还说“不可放过了他”，另到灶前取草点火，向店内四下焠着；风助草房，火顷刻大起，三人才奔大路。纵火有单独的取草、引火、点燃过程，不是打斗自然延烧；本回真正着火的是祝家店草房，不能据回题便说整座祝氏庄园已经烧毁。[正文L68](00_正文.txt#L68)。

<a id="pursuit-and-recognition"></a>
## 时迁被钩走，二人在另一村店遇见旧识

逃了两个更次，前后约一二百庄客持火把追来。石秀欲择小路，杨雄却说来一个杀一个，待天明再走；话未说完便已合围。杨雄当先，石秀在后，时迁居中，持朴刀战庄客。杨雄戳翻五七人，石秀再赶入搠翻六七人，庄客听见“杀伤了十数人”，怕送命而退。这里保留的是约数和“杀伤”，不能把所有戳翻、搠翻者一概计成死者；后文还明写庄客救走带伤的人。[正文L74](00_正文.txt#L74)。

三人得一步赶一步，枯草里却伸出两把挠钩，拖走时迁。石秀急回身救，背后又出两钩；杨雄眼快拨开，再往草里戳，伏者发喊走散。于是既有石秀回救时迁，也有杨雄救开袭向石秀的钩，不能把后来脱走简写成从未援救。但二人怕深入重地，终究“顾不得时迁了”，转而寻路，见东边火把乱明、小路又无丛林树木，便向东走。庄客追不着二人，救伤，把时迁背剪绑起，押送祝家庄。[正文L74](00_正文.txt#L74)。

到天明，杨、石进一所村落酒店，想买酒饭兼问路。酒保铺菜盪酒，二人方欲吃，一个长大粗貌、身穿茶褐绸衫的男子奔来，传“大官人”话，催店内挑担入庄。店主人回说“装了担，少刻便送到庄上”，来人又催“快挑来”。所催是送担，回话有少刻送到的承诺；担内何物、是否后来送达，都尚未写出。[正文L76](00_正文.txt#L76)。

那人将走，经过二人面前，杨雄认出，叫“小郎”，问为何不看自己。对方回头才认出，称“恩人”，向杨雄、石秀拜下。“恩人”的明确受称者是杨雄，同拜不能证明来人此前也认识石秀。其姓名、旧恩详情、“大官人”及所纳之庄都悬在这里；这家村店也不能自动合并成前面烧掉的祝家店。回末正以此人的出现截住故事，留待以后揭名。[正文L76—78](00_正文.txt#L76)。

## 这一回把什么说清了，又把什么推远了

“法度”“备细缘由”“三面说得明白”构成山上山下的一条语言线索。它确实洗清石秀的调戏嫌疑，使杨雄认错，不能把这一结果抹掉；却没有约束随后的杀害。更尖锐的是“伏侍”：杨雄说要亲自伏侍，石秀又用同一日常照料用语答妇人的求劝，紧接的却是割舌剖腹。可以据此看到言语与行动的落差，但本回没有明写石秀初提休书时已决定后来全部杀法，不必为了解释结果而补出一套全程预谋。[正文L24、36](00_正文.txt#L24)。

本回也不容把石秀固定成一贯冷静、杨雄固定成一贯鲁莽。石秀能布置对质、估量回城风险，也会为鸡钱和名号大怒、主动纵火；杨雄会追问熟人门路和公人身份，却在围追时坚持先战。时迁既偷鸡抵赖，也会认小路、做饭、提汤、筛酒。能力、照应和侵害并存于具体场面，不能由一个好汉称号包办评价。[正文L24、44、56、64、68、74](00_正文.txt#L24)。

两次官府判断则展示了知情的限度。第一次从刀、伤与裸尸组成互杀文书，第二次加入遗衣和潘公前情，才转向杨、石；后者较接近实际，却还待拿人证实。曲词、供述、叙述者直接描写以及官府推理各有来源，不能因都写得响亮便互相替换。迎儿的口供也一样：它在关键联络办法上得到前情支持，仍发生在刀胁之下，且没有消除次数声音的差别。[正文L14、16—24、36、58](00_正文.txt#L14)。

衣物尤其显示这种限度。石秀撒出裴、胡衣服作证，杨雄又把妇人头面衣服拴进包裹，后来随身钗钏被谈作盘缠，并有付钗取酒的实际用途；验尸却仍报古墓边留着“妇人、头陀衣服”。带走与留置未逐件分明，不宜把验报改成别的衣物，更不宜虚构一个搬动者。可以确认衣物同时进入证见、资财和官府线索三条链，不能据此编出每件首饰的唯一原主及全程清单。[正文L34—36、44、58、64](00_正文.txt#L34)。

最后，纵火后的诗以“小忿”衔接“兵燹及黔黎”，预告智多星连环计、祝氏庄园毁坏；回末又预指英雄被恼、祝庄三番闹、梁山大队到来。一只鸡怎样牵到更多庄户，已成为叙事要读者留心的方向。到本回止点，落地的仍只是店火、追战杀伤与时迁被押；将来的全庄毁坏和大队行动尚未实行。王公的损失、轿夫的等待与报案、潘公的葬事、小二和大汉的受伤、庄客救伤，都让这些主角的决定有了别人实际承受的代价。[正文L14、58、68—78](00_正文.txt#L14)。
