# 第五十回：吴学究双用连环计，宋公明三打祝家庄

祝家庄最后败在已经迎进门的援手。孙立借同门关系取得信任，再用假擒石秀把这种信任坐实；庄中守将出门迎敌时，内应夺门、放俘、纵火，宋江才完成第三次攻打。胜利又接出另一场计谋：李应被假官拘走，再被梁山“救下”，等他要求回家时，家眷、财物已经上山，庄院已经烧毁。他和杜兴进入了新头领的名单，所经历的却是一步步失去退路。[正文L18—48](00_正文.txt#L18)

<a id="hu-contract"></a>
## 扈成求妹，吴用改换条件

吴用先叫戴宗连夜回山，取裴宣、萧让、侯健、金大坚，带来所需“行头”，当时只说“自有用他处”。戴宗离去，读者要等到回末才知道这几个人将扮成官员。[正文L14](00_正文.txt#L14)

此时扈成牵牛担酒来求放妹妹。寨外军士先通报，宋江令请入；扈成拜求宽恕，把妹妹助祝、被擒说成“年幼不省人事”，又说明她原许祝家，愿依宋江需要奉上物品。宋江先要求以王矮虎换妹，扈成却说王矮虎已被送到祝家庄，自己不敢前去索取。吴用问明所在，劝宋江不要再坚持这项交换，另定两个条件：扈庄“切不可令人来救护”祝家，若有祝家人来投，须绑住交来，捉到人后再送还妹妹。扈成逐项应承，宋江称这样比送金帛更好，他才拜谢离去。[正文L16](00_正文.txt#L16)

求和因此变成了断援、截逃的协约，妹妹并未当场获释。吴用说她前日已送梁山，安置在宋太公处“奉养”；这说明了他对去处的交代，还没有写出宋太公怎样接收、如何回话。此时扈成争取的是妹妹日后得还，他自己的承诺随后也确实付诸行动。[正文L16、L32](00_正文.txt#L16)

<a id="sun-trust"></a>
## 孙立怎样让祝家越来越相信他

孙立把旗号改作“登州兵马提辖孙立”，带同行人马来到祝家后门。墙内人望见旗号报入，栾廷玉听说是自幼同师学艺的孙立，先向祝氏三杰说明，再带二十余人开门放桥迎接。孙立假称总兵府调他往郓州防梁山，因前门屯兵，才问小路绕到庄后探望。栾廷玉正盼助力，把他看成“锦上添花，旱苗得雨”；孙立也许诺相助擒贼，成全这位同门的功劳。[正文L18](00_正文.txt#L18)

众人进庄，吊桥重新拽起，庄门关上。孙立一行安顿车仗人马、更衣后，到前厅与祝朝奉、祝龙、祝虎、祝彪相见。栾廷玉替他说明官职与调防来意，他又谦称以后还仰仗祝朝奉指教。顾大嫂带乐大娘子到后堂见宅眷；孙立将孙新、解珍、解宝介绍成自己的兄弟，把乐和说作郓州差来的公吏，把邹渊、邹润说作登州送来的军官。老小、行李、车仗和栾廷玉的信用一起消除了疑心，祝家遂杀牛宰马，设宴款待。[正文L20](00_正文.txt#L20)

这些介绍有真关系，也有假身份。前回已写孙新是孙立的弟弟，乐大娘子是孙立之妻、乐和的姐姐，解氏与孙氏有姑舅亲缘；本回的官府来意和同行者职名却服务于骗局。孙立前回先受顾大嫂等人逼迫，随后主动提出借栾廷玉入庄的计策；到了本回，他已实际利用旧谊调度内应。受胁加入与主动成事，是相接的两段经历。[49回L36、L42、L56、L72—84、L96](../第049回/00_正文.txt#L36)

住过一两日，叙事来到第三日。祝彪听报宋军来，带一百余骑出庄，迎战花荣率来的约五百人。两人斗十数合，花荣卖破绽退走引他追，一名认得花荣的军人忙劝止，提醒此人善射。祝彪听从，勒马回庄，花荣也收军。这个没有姓名的人改变了追击的走向；这一回花荣的诱敌并未如愿。[正文L22](00_正文.txt#L22)

祝彪回厅却说斗了“五十馀合”，与叙述所写“十数合”不同；他仍说清因为军人提醒弓箭才止追。文本留下战况与自述的差距，没有明说他是否有意夸大。孙立听罢，接话称次日由自己捉几个；当天乐和在筵席唱曲，众人欢喜，至晚散席，又过一夜。[正文L22](00_正文.txt#L22)

第四日午牌，宋军再至。祝朝奉坐在门楼，栾廷玉、孙立分列左右。祝龙受林冲叫骂而出战，斗三十余合不分胜负，鸣锣各退；祝虎怒而挑战宋江，穆弘迎战，又斗三十余合；祝彪再带二百余骑出阵，由杨雄接住。孙立于是叫孙新取鞭枪、衣甲、头盔，骑乌骓马、悬钢鞭出战，石秀从宋军阵中迎上。两人斗五十合，孙立虚让闪避，把石秀轻轻擒过马来，掷下叫绑；祝氏三子乘势赶散宋军，庄中众人对孙立愈加钦服。[正文L24—26](00_正文.txt#L24)

孙立随即问共捉到几人。祝朝奉列出时迁、杨林、黄信、王矮虎、秦明、邓飞，加上石秀，共七个，还指石秀正是烧店之人。孙立嘱“一个也不要坏他”，要造七辆囚车、给酒饭养身，以日后连宋江一同解往东京、替祝家三子传名为理由。祝朝奉道谢，石秀“自把囚车装了”。紧接着，叙述者向读者揭明：石秀武艺“不低似孙立”，是故意被擒，让祝家“一发信他”。这次擒拿因此不能用来证明二人真实武力的高下。[正文L26—28](00_正文.txt#L26)

信任一旦做深，察路和通消息便能进行。孙立暗遣邹渊、邹润、乐和看后房门户，杨林、邓飞见二邹而暗喜；乐和等到无人时，才把消息透给众人。顾大嫂与乐大娘子也已看过内宅门径。这里既写了俘虏中明确的识人反应，也写了等无人再传信的防备，尚未抄出每个人得到的全套消息。[正文L28](00_正文.txt#L28)

<a id="breakthrough"></a>
## 夺门、放俘与三子的不同死路

第五日辰牌，早饭后报宋军四路来攻。孙立先以“分十路待怎地”安定庄人，又教备挠钩套索，只算活捉，不算拿死的。门楼望见东面是林冲、李俊、阮小二，西面花荣、张横、张顺，南面穆弘、杨雄、李逵，各有约五百人马；叙述称四路，却只在三面逐一列了将名。栾廷玉说要出后门攻正西北人马，祝龙出前门攻东面，祝虎出后门攻南面，祝彪出前门拿宋江。祝朝奉大喜赏酒，各将带兵出门，其余人守庄呐喊。[正文L30](00_正文.txt#L30)

庄内也已各守要点：二邹藏斧守监门，二解藏暗器近后门，孙新、乐和守前门两侧；顾大嫂先拨人保护乐大娘子，自己拿双刀在堂前等信号。庄兵擂三通鼓、放一炮，开前后门和吊桥出战，孙立最后带十数军兵留在桥上。孙新插起原带旗号，乐和提枪唱入，二邹听唱唿哨，才抡斧砍翻数十守监庄兵，打开陷车。七名俘虏得释，各自寻找兵器喊杀。[正文L30—32](00_正文.txt#L30)

与此同时，顾大嫂冲进房中，将“应有妇人，一刀一个尽都杀了”。她先保护同行的乐大娘子，再杀庄内妇人，两种行动必须并记；被杀妇人的逐名身份与人数没有列出，不能直接把她们改写成持械战兵。祝朝奉见势坏，欲投井，被石秀一刀剁翻、割下首级；其余好汉分头杀庄兵。解珍、解宝到马草堆放火，外军看见黑焰，才合力向前。内应不是等火起才开始动作，而是夺门、放俘、杀人、纵火逐环相接。[正文L32](00_正文.txt#L32)

祝虎先见火回援，到了吊桥却被孙立喝住，只得拨马再奔宋江阵上，遭吕方、郭盛双戟连人带马搠翻，众军乱上剁杀。祝龙斗林冲不住，奔向庄后，见二解把庄客尸首撺下，火焰中又向北逃，撞上李逵；马脚先被砍倒，人跌下来，再被斧劈。祝彪听逃出的庄兵报信，不敢回庄，投向扈家。三人各有败退和受杀的环节，李逵杀的是祝龙、祝彪，祝虎之死须保留孙立拦路、吕郭搠倒与众军继杀。[正文L32](00_正文.txt#L32)

<a id="hu-killing"></a>
## 扈成履约，扈家却没有得到保全

扈成没有庇护投奔的祝彪。他照约叫庄客捉绑，正押去见宋江，恰遇李逵，一斧杀了祝彪，押解庄客四散。李逵再砍向扈成；扈成见势不对，拍马落荒，弃家逃往延安。叙述又提前交代他后来在“中兴内”做军官武将，本回没有展开那段经历。[正文L16、L32](00_正文.txt#L16)

李逵抢入扈庄，将庄内扈太公一门老幼杀尽，又叫小喽啰牵马，将财赋装成四五十驮，烧了“庄院门”回来献纳。“不留一个”所写的是这场庄内屠杀；近处已有扈成逃走，妹妹也早被送山，不能扩成扈氏所有成员无人生还。装财者在这里是奉令的小喽啰，亦不能一概认定每人都亲手参与杀全门。[正文L16、L32](00_正文.txt#L32)

宋江已在祝庄正厅受献，获生俘四五百、好马五百余，牛羊无数。他大喜之中叹“只可惜杀了栾廷玉那个好汉”。栾廷玉出战后的死讯只在这句话得到概述，杀者、时地与经过没有叙出。[正文L34](00_正文.txt#L34)

听报李逵烧扈庄献首，宋江质问：扈成此前已来投降，谁叫杀人烧庄？李逵浑身血污来请功，自报杀二祝、走扈成、尽杀扈太公一家，又说明自己遇见扈成押祝彪的经过。宋江以扈成已降为由，斥他擅杀，认定他“故违了我的将令”。这是宋江的问责；本回没有叙出约定或命令怎样事先传到李逵，不能由责问替补李逵逐项知情的过程。[正文L34](00_正文.txt#L34)

李逵反拿一丈青前日追赶宋江说事，嘲笑宋还没娶她，便想起阿舅、丈人。宋江否认要这妇人，称“我自有个处置”，再问拿了几个活人。李逵答“见着活的便砍了”。宋江说他本应斩首，最后以杀祝龙、祝彪之功折过，警告下次违令不饶；李逵反笑称，虽没了功劳，也“杀得快活”。宋江的斥责是真实说出的，战功相抵、李逵未见悔意也同样在场。[正文L34](00_正文.txt#L34)

<a id="village"></a>
## 石秀替老人说话，村坊才从洗荡中获免

吴用率人来贺喜后，宋江又与他商议，要洗荡祝家庄村坊。石秀这时禀明锺离老人指路、救济之恩，说村中也有善心良民，不可屈坏，宋江才令他去寻老人。前回老人请石秀吃酒饭、告诉白杨转弯的活路，石秀临别许“即当厚报”；本回由石秀引见，宋江赏一包金帛，使旧恩有了具体回报，并非仍全然未报，也不是另写石秀私财给付。[正文L36](00_正文.txt#L36)、[47回L56](../第047回/00_正文.txt#L56)

老人来到，宋江直言：若不是看他有恩，便要把村坊尽洗、不留一家，如今因他一家为善而饶这一境人民。老人只是下拜。宋江又说连日搅扰百姓，此番为村中除害，下令每家给米一石，让老人为头发散。这里的转折先经过石秀进言，才有寻找、赏报和给粮，不能写成梁山起初就只欲杀祝氏、从未要波及村坊；给粮命令也不等于逐户领粮过程已经一一展示。[正文L36](00_正文.txt#L36)

祝家余粮装车，金银财赋犒赏三军，其余牛羊骡马运回山用。底本记得粮“五千万石”。孙立等八人、七名获救者归队，孙立一行捎带自己的马匹财赋，和乐大娘子等老小随军上山；乡民扶老挈幼，持香花灯烛沿路拜谢。凯旋赞语写满车粮草、满军降兵，随后宋江将祝家庄兵收在部下，军队出村，百姓又“自把祝家庄村坊拆作白地”。拜谢、收编和拆庄各有主体，不能合成一幅只见头领获胜的画面。[正文L36—40](00_正文.txt#L36)

<a id="li-trap"></a>
## 李应：被救下以后，回家反而成了不可能

叙述分头写李应。他箭疮刚平复，闭门不出，暗派人探信，已知祝庄被破而“惊喜相半”。庄客报本州知府带三五十人到来，他命杜兴开门放桥，自己白绢络手，迎入前厅。知府居中坐，孔目、押番、虞候分列，阶下站节级牢子，官府排场先把问事变成了拘提。[正文L42](00_正文.txt#L42)

假知府问破庄之事，李应答因左臂有伤一直闭门，“不知其实”；知道祝庄已破，与知道破庄详情并非一回事。假官随即称祝家有状子，指他结连梁山、引兵破庄，又说他早受鞍马羊酒、采段金银。李应否认，仍被绑走；杜兴也因“状上也有你名”而被锁上。前回李应明确拒见、拒受宋江礼物，杜兴回传时也说“不敢祗受”，是这番受礼指控不能越过的前情，不能把假官说辞写成已经查实的事实。[正文L42](00_正文.txt#L42)、[48回L20、L26](../第048回/00_正文.txt#L20)

押出三十余里，宋江、林冲、花荣、杨雄、石秀一班人拦住去路。林冲喝称梁山好汉，假官丢下李、杜逃走，宋江令追；众人追一程回来，声称“我们若赶上时，也把这个鸟知府杀了”，又称不知去向。杀知府在他们的话里带着“若”的条件，没有写成险些杀到，更没有真知府死亡。李应随后却以“知府是你们杀了，不干我事”拒绝上山，须保留叙述动作、同谋者回报与李应当时所信的区别。[正文L44](00_正文.txt#L44)

宋军替二人解缚开锁、牵马给骑，宋江请李应到山上暂躲。李应说使不得，宋江便说官司不会如此分辨，梁山走后必牵累他，可先住几日，探明无事再下山。叙述却直接点出“不由李应、杜兴不行”，二人在大队军马中间无法回头。所谓暂避，已发生在武力包围的处境里。[正文L44](00_正文.txt#L44)

晁盖等下山迎接，接风后众人到聚义厅相见。李应见礼完仍请求下山，理由是担心老小；吴用笑说宝眷已取到，贵庄也已烧成白地，问他还回哪里。李应起初不信，待自家庄客、老小随车队上来，才问妻子。妻子说他被捉后，又有两巡检、四都头带二百来土兵抄家，把他们“好好地教上车子”，搬尽箱笼、牛羊骡马，又放火烧庄。她形容上车的方式，并不是替抄家焚庄作自愿承诺；李应听完只叫苦。[正文L46](00_正文.txt#L46)

晁盖、宋江于是下厅伏罪，称久闻其好处，才设下这条计，请他原谅。李应“只得随顺”，看见别的头领也带家眷，才对妻子说“只得依允他过”。宋江安置李家宅眷后，又笑着唤假官来见：知府是萧让，孔目是裴宣，虞候是金大坚、侯健；两巡检为戴宗、杨林，四都头为李俊、张横、马麟、白胜。押番、其余牢子土兵未逐名揭出。开回吴用取来的四人，到此都有角色，而李应看得“目睁口呆，言语不得”。这份惊愕接在叫苦和两次“只得”之后，不能被众人庆功的喜悦代替。[正文L14、L46](00_正文.txt#L46)

<a id="marriage"></a>
## 新头领、婚配与仍未揭开的来客

宋江令小头目杀牛宰马，替李应陪话，庆贺十二位新头领。名单中的男子是李应、孙立、孙新、解珍、解宝、邹渊、邹润、杜兴、乐和、时迁；女头领扈三娘、顾大嫂与乐大娘子、李应宅眷另坐后堂。两名女头领与其余家眷身份有别；乐大娘子虽同席，并未因此被列为第三位女头领。正厅大吹大擂，饮宴至晚。[正文L48](00_正文.txt#L48)

次日又作席，宋江主张一丈青配王矮虎，结为夫妇。第三十五回他曾许王“日后别娶一个好的”，如今另娶的结果已有兑现；王是否满意没有发言可据，女方同样没有婚配对白。扈三娘已列头领、已成婚，是本回给出的处置；她何时得知扈太公等被杀，对婚姻如何选择，仍未写明。众头领称宋江“仁德之士”，赞词属于他们，不能拿来代她表示情愿或感恩。[正文L48、L50](00_正文.txt#L48)、[35回L16](../第035回/00_正文.txt#L16)

饮宴间，山下来报朱贵酒店有一名郓城县人要见头领，晁盖、宋江大喜，称恩人上山入伙，遂了平生之愿。来客在本回尚未具名，求见也只是报信者传来；回末转以枷梢、大斧、路柳墙花与“幼童稚子”预告后事，又提一个军师隐情。欢宴之后，最后留下的是将发生什么暴力、来者到底是谁的悬念。[正文L50—52](00_正文.txt#L50)

## 信任、保护与“仁德”的不同立场

本回两场计谋，一场让祝家主动开放要害，一场令李应再也无法回家。前者借同门、官身、老小车仗、共宴和假战绩逐层取得信用；后者先用官府拘提制造危局，再以救援、官司牵连和搬家焚庄收紧退路。回题将“双用”归于吴用，前回却明写孙立主动献同门内应计、吴用接纳部署，因此不必把每一个现场动作都补成吴用事先逐句授意。[正文L18—28、L42—46](00_正文.txt#L18)、[49回L96—100](../第049回/00_正文.txt#L96)

保护也始终有具体关系：孙立用祝家扬名的盼望为七俘保命，顾大嫂先护乐大娘子而后杀庄内妇人，石秀以老人旧恩替村坊求免。扈成已履协约，父家留庄者却仍遭屠杀；宋江问责，最后又让战功折过。可见合作条件并未保障扈家，受保护的范围也不均等；但这些结果不足以证明吴用预谋灭扈，或李逵事先已经听清全部约定。[正文L16、L26、L30—36](00_正文.txt#L16)

引首说“千般巧计，不如本分为人”，叙述又判祝家“恶贯满盈”，凯旋却靠巧计成事。“旱苗得雨”先是栾廷玉欢迎孙立的喜语，后又变成梁山归寨的赞语；前一次所盼的援手，正给祝家带来灾祸。同一比喻转移了受益者的站位。道德格言、凯歌、乡民拜谢和头领赞“仁德”，都与妇人、老幼、被逼入伙者的具体遭遇并存。保留这些声音，才能看见胜利由谁享受、代价由谁承担；至于是否要把全部赞语读成反讽，文本尚不足以限定唯一解释。[正文L10、L18、L28、L32、L38、L46、L50](00_正文.txt#L10)
