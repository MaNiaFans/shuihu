## 底本与定位

底本为仓库内的《水浒传 (施耐庵  罗贯中).txt》。该文件自载为人民文学出版社百回整理本，以容与堂本为底本参校整理；尚未与纸本逐字校勘。每回来源说明区分正文、引首和现代注释。

第一回及导入的第五至七回历史材料中保留原工作区 `F:/水浒/` 路径，第二至四回主要使用 `E:/水浒/` 或项目内相对链接。当前工作区为 `E:/水浒/`；第五至七回的AGENTS入口已作盘符适配，固定研究稿和验收记录不为改路径而覆写，可按文件名及原书行号核查。GitHub网页不能直接打开本地绝对路径。为保持来源及复核文件的哈希，仓库关闭自动换行转换。

后续 agent 从 [AGENTS.md](AGENTS.md) 开始，读取当前skill并按已授权范围执行。未知与有据的解释分歧可以保留，遗漏、事实错误和独立性缺口必须处理。
