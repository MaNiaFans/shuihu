# 查阅入口

需要了解一回的经过、查一个人的原文记录，或者确认某个疑问有没有答案，可以从下列入口进入。

| 想查什么 | 入口 | 内容 |
| --- | --- | --- |
| 从头连续读完整故事 | [百回阅读目录](../05_百回阅读/00_百回目录.md) | 一百回各有经过、可读成稿、原文与追踪链接。 |
| 按姓名找梁山人物 | [一百零八人查阅](01_一百零八人查阅.md) | 星名、绰号、第九十九回分类和原文姓名出现的回目导航。 |
| 查梁山之外的人、家属与无名群体 | [人物称谓与身份](../../全书追踪/人物称谓与身份.md) | 按回保存身份、关系、行动方向与受影响者；可按姓名或称谓检索。 |
| 确认一个疑问后来怎样了 | [问题与未解处](02_问题与未解处.md) | 178个累计入口的完整有效状态及各自依据，已答与仍未详分开。 |
| 追一封信、一项许诺、一件物品或一句预告 | [线索与原文怎么查](03_线索与原文怎么查.md) | 1990条线索的入口、状态和关系级别说明。 |
| 回到小说本身核对 | [项目底本](<../../水浒传 (施耐庵  罗贯中).txt>) | 本项目百回正文及另列资料；文章的本地行号与原书行号用于定位。 |

人物出现在某回的名单或转述中，不等于当场在场；同样，某件事在追踪表里保留为“未详”，也不表示正文漏读。遇到一个影响判断的细节，先读引文前后的动作、条件和说话人，再看前后关系是否真的成立。
