# 读者版编辑入口

遵守项目根[规则](../AGENTS.md)。本目录依据2026-10-31用户整合授权建立，不改原章节研究与历史。

读者文章采用人物深读、专题发现、交锋与异见、深思与哲学四辑，另有百回阅读和查阅入口。人物动机与跨回联系必须有可回查的原文；事实、说辞、诗赞、注释与分析推断分清。文章先讲出可理解的判断，再以具体动作和原文支持；保留反证与重要未知，避免用“秘密真相”把候选关系写成定论。

新整合线索按[合同第九节](../阅读规则/shuihu-close-reading/references/逐回执行合同.md#九全书整合与伏线复审)独立复审。先固定中性位置链，复审者先读原文并固定自己的判断，再开放作者文章。执行者不得再次委派。角色、资料接触和版本放资料与全书追踪记录，读者正文不堆管理标签。
